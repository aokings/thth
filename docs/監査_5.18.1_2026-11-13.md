   - 直す案: 問い合わせの文から欄の名前を抜き出し、許した名前の集まりと同じであることを見る柵（点数の試験の `_parse` をそのまま使える）。privacy の「読む物」の文もその集まりに結ぶ。

## 気づき

1. 【動】`remove.execute` は、一段目の一覧に無かった状態の置き場を、中に人の置いたファイルがあっても確かめ無しで消す（探り: `note-by-human.txt` を置いた置き場が消え、`done` は `token・state・ledger`）。設計どおり（機械が既定の置き場に書く物）で、文字の表示は「一段目のあと、取り直しの途中に書かれた物」と言う。状態の置き場に人が物を置くことは無い前提。
2. 【動】状態の置き場が symlink に替わっていると `store_remove_unsafe` で断るが、鎖のファイル `access.lock` が symlink の先に 1 つできる。5.18.0 の `locked(create=False)` も `os.path.isdir` が symlink を追うので同じ（この版の後退ではない）。
3. 【動】`MAX_COST_EXCEEDED` で断るとき、符丁は `store_api_changed` で、「なぜ」は「要る欄が無いか、型が変わっていました」のまま（「通すには」と「もっと良く」は点数の話）。なぜも `by_detail` で言い分けると 3 つがそろって読める。
4. 【読】`wire.PRODUCTS_FIRST_MAX` は 50 のまま。種類を 20 読む今の文では、50 件の頁は 2 ＋ 50 × 29 ＋ 1 ＝ 1,453 点で上限を超える。`shopify.py` は 25 までしか頼まないので今は起きないが、柵は 25 に締められる。
5. 【動】`sale_started` は、予約販売（`preorder`）→ 販売中でも出る（リリースノートのとおり）。前の売り方が空文字・知らない語でも出る。0 円や負の値への変わりも `price_down` になり下書きにできる（値は本文に書かない）。
6. 【読】版を戻すとき: 5.18.1 が書いた退出の途中の記録（`preserved` に `principal_token`）を、5.18.0 の `_valid` は形が違うと読む。記事の口座の退出が途中の間は、5.18.0 へ戻さない。
7. 【読】STORES の種類の id を英数字 1〜64 字と決めている（`rows.VARIANT_ID`）。本物の id にほかの字（`-` など）があれば、5.18.0 では読めていた店の読みが全部 `store_api_changed（item_variations）` で止まる。本物の店で最初に見る所に足すとよい。
8. 【読】Mastodon のインスタンスも台帳が決める宛先で、鍵つきの要求を出すが、`public_opener` は使っていない（この版の範囲の外。5.16.0 監査の同じ筋の残り）。
9. 【動】試しの印 `THTH_TEST_ALLOW_HTTP=1` があると、名前で書いた宛先でも答えが loopback ならつなぐ（`::ffff:127.0.0.1` も）。私用の網は印があっても断る。印は今までの平文の柵と同じ 1 つで、本番の環境には立てない前提。
10. 【読】台帳の検査は、全角の数字のホスト（`１２７.０.０.１`）・`localhost.localdomain`・`ip6-localhost`・`127.0.0.1.nip.io` を通す。送る時点で名前の答えを見るので、内向きなら断る（リリースノートの「名前で書かれて内向きを指すものは送る時点で断る」のとおり）。全角の正規化そのものは、名前を引くのを偽にしたので動かしていない。
11. 【動】リリースノートの「6to4（2002::/16）はすべて内向きとして断る」は、`2002:808:808::`（中身は 8.8.8.8）でも内向きになることで確かめた。Python の表による（直したほうがよい 3 の版の話）。

## 柵にしたもの

監査で新しく作った柵は無い（監査する者はコードと試験を変えない決まり）。危ないは 0 件。直したほうがよいを直すときに作る柵:

- 直したほうがよい 1: 主体の鍵（と consumer）が口座の state の中にあれば leave は消さずに止まり、鍵が残る。env が主体の鍵と同じパスでも止まる。
- 直したほうがよい 2: どの頁も混んでいる店でも、1 回の読みで眠る合計と打ち直しの回数に上限がある。
- 直したほうがよい 3: 内向きの一覧に `::10.0.0.1`・`::127.0.0.1`・`fec0::1`。
- 直したほうがよい 6: 商品の問い合わせの文の欄の名前が、許した集まりと同じ。

この版で作った者が入れた柵のうち、監査で**わざと壊して赤を見た**もの【動】（壊し方 → 赤になった試験。repo のファイルは触らず、読み込んだあとの値を差し替えた）:
