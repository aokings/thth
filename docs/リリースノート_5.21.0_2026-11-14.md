# THTH 5.21.0（2026-11-14）

台帳の器を、こぴちゃの向き替え（段 10）の形で使えるようにする直しです。向き替えでは、repo の中に台帳のフォルダ（正本）を置き、repo の根の `src/content/` と `data/knowledge/` を、受け入れ（`accept`）が書き出す写しにします。5.20.1 の器では、この形に穴が 2 つありました（`docs/受け入れ_台帳の器_段10_2026-11-14.md`）。

| 件 | 中身 |
|---|---|
| 同じ書き出し先の名指し | 内の道具の出し口が `dest_shared_with: ["<読者の出し口>"]` で名指ししたときだけ、読者の出し口と同じ書き出し先を分け合える。条件は、同じ道（入れ子でない）・種類が重ならない・置き場の型が重ならない（読者が型でまとめて取るフォルダの中に、内の材料を置かせない）。名指しの無いときは、これまでどおり宣言の読みで断る。互いの材料は相手の旧い材料に数えない。相手の置き場の型に当たる出力は、書く前に断る（`register_write_unsafe`・`shared_dest`） |
| 旧い材料の見張りの範囲 | 台帳が書き出し先の中にあるときだけ、見張るのは出し口（と分け合う出し口）の置き場の型が載るフォルダと、前の封の出力の道のフォルダ。repo の道具や文書を `ignore` に並べずに済む。台帳が書き出し先の外のときは、これまでどおり書き出し先の全部を見る |
| こぴちゃの宣言（`tools/register_decls/kopicha/`） | 出し口 `site`・`tools` の書き出し先を repo の根に。こぴちゃの台本の点検の変更（11/14 `58534e991`）にそろえた: `k4_9` は支える根拠だけで数える・`k4_6b`・`k4_8_warn` |
