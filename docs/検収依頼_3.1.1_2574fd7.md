## 見てほしいところ（判断が要る点）

1. 件 5 は `thth replies` の口だけを絞りました。**`thth who`（`who_cli`）も `replies.load(account)` で置き場の全ファイルを読むので、同じ repo を共有する account では他 account の返信を数えている可能性があります**（実機では未確認）。直すなら所有の母集団を渡す形で別件に。
2. 件 7 の実測は「言及が 145 時間前」とありますが、毎朝の一枚の言及（`_mentions_rows`）は `mentions(since=None)` で窓を持たず、7 日の窓が掛かっていたのは返信の台帳の未回答（`unanswered`）の側です。145 時間前の行がどちらだったかは未確認です。窓と `window_edge` は未回答の返信の側に付けました。
3. 件 2 の 401 は依頼書どおり `PermissionMissing`（「`write:statuses` がトークンに乗っていません…`thth auth` をやり直して」）にしました。401 は token 自体が無効な場合も含みます。承認の口で scope 不足を断ったときの公開の job 状態は `failed`（理由は既存の畳み方で `approval_no_longer_valid`）で、`permission_unavailable` という語は job の状態には出ません（3.1.1 より前からの形）。
4. 件 3 の `own_accounts.unreadable` は、登録簿のうち読めなかった台帳の数も含みます（読めない台帳はどの project かが分からないため）。
