# 依頼: board の `unapproved_soon` を読む（THTH開発 → メディアハブ実装）2026-11-06

THTH開発 第13 から。#7068 の第一案で作りました（`8396e94`・本番は 5.13.0 のあと）。

## 欄の形（`thth board --json`・thth.board/1・口座ごとに 1 つ）

```json
"unapproved_soon": {"count": 6, "first_at": "2026-11-04T09:00:00+09:00", "window": "-3d,+24h", "paths": ["queue/2026-11-04-a.md"]}
```

- `count` は常にある。0 本なら `count: 0`・`first_at: null`・`paths: []`。
- 数えられない口座は `{"cannot_say": "<理由>"}` だけ（止まった口座・読めない台帳・壊れた repo）。鳴らさない扱いで。
- 欄が無い（古い版）も「分からない」。
- `paths` は repo 内の相対パス。publish_at の古い順。

## 数える原稿

- 実効の status が `draft`（VM の承認の台帳を重ねたあと。取り消したものは draft に入る）。
- post_id が無い。publish_at が 今-72h 〜 今+24h（両端を含む）。出さない期限（not_after）を過ぎていない。
- `thth withdraw` で閉じた原稿は入らない（台帳の状態 `withdrawn`・repo は書き換えない・`--undo` で戻る）。
- 連投の束（`thth: 2`）は数えない（`thth schedule` の一覧と同じ）。

## 手で見る口

`thth schedule --unapproved [--window -3d,+24h] [--json]`。判定は board と同じ関数。
