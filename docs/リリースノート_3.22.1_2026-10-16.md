# リリースノート 3.22.1（thth.me の鍵の道を手元と同じ意味に・3.22.0 と一緒に出す）

2026-10-16。3.22.0（[リリースノート](リリースノート_3.22.0_2026-10-15.md)）は単独では出していないので、この版で一緒に出る。

- **thth.me の鍵の道の `thth retract` も二段にした。** 一段目（`--confirm` 無し）は対象の本文と確認の番号（digest）を見せて何もしない。二段目で番号が一致したときだけ消す。それまでは help の「二段確認」と違い、一回で消していた（[調べ_道ごとの意味の差](調べ_道ごとの意味の差_2026-10-15.md) §4 の 1）。MCP の `thth_retract_request` は今までどおり呼べば消す（中で番号を付ける）。
- **thth.me の鍵の道が読まない旗は、黙って捨てずに断る**（`remote_unsupported`）。それまでは `retract --already-gone`（記録だけのつもり）が本当に消し、`send --community` が普段のタイムラインに出ていた。対象: `retract --already-gone`、`send --community`・`--goal`・`--found-by`・`--reply-to-root`・`--reply-to-author-key`・`--confirm`。

## 出し方

3.22.0 と同じく Worker を先に deploy し、VM はあと。3.22.1 の直しは利用者の手元の CLI 側なので、効くのは利用者が 3.22.1 を入れてから。
