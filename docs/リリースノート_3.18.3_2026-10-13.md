# リリースノート 3.18.3（X の返信の制限を符丁に）

2026-10-13。3.18.2 で関東の 403 の文面が取れた（L1）: type=not-authorized-for-resource / title=Authorization Error / detail="You can only reply to or quote posts where you are mentioned or are the author."。自己サーブ（pay-per-use）の X API からは、**自分がメンションされた投稿か自分の投稿にしか返信・引用できない**。この文面を `x_publish_http_403: x_reply_not_engaged` に当てる。

関わりの無い相手の会話に X で返信する道は、THTH（API）からは無い。代わりの口は調べ中（関東 #1926）。Threads には関係しない。
