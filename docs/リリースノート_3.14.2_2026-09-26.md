**配る順: Worker が先（masaru の手）→ tag（PyPI）。** VM の release は変更なし（枝は揃える）。3.14.2 の `thth login` は Worker の `/login` が無いと動かないので、tag は Worker の deploy のあとに押す。

## 何が変わったか

1. **`thth login` がブラウザ式に**（`gh auth login` と同じ形）。`thth login` → ブラウザで `https://thth.me/login/XXXX-XXXX` が開く → 口座名と口座の secret を入れて「この機械に鍵を渡す」→ ターミナルに「保存しました」。鍵の貼り付けは無い。鍵は画面に出ない。`--no-browser`（URL だけ）・`--stdin`／`--paste`（貼る道・残す）。
   - Worker: 新しい DO `Login`（migration `v8-login`）・`/login/<code>`・`/api/v1/login/{start,poll}`。code は 8 字、poll は別の 43 字の token で守る。鍵は Login DO に最長 10 分・CLI が受け取った時点で消す。発行は今の rotate と同じ（前の鍵は無効・VM は変えない）。
   - 口座の決め方: 入れた名前の口座。無ければその人の口座が 1 つだけならそれ。2 つ以上なら 409。
2. `/activity` の「設定を変える」の値の欄に、パスワード管理が入れないための印（secret の欄を先に・`data-1p-ignore` 等）。実機のスマホでは未確認。
3. masaru の Mac のラッパ `bin/thth-remote`（`~/.local/bin/thth`）: `login`・`logout` だけ手元の `thth`（pip・無ければ `python -m thth`）に渡し、それ以外は VM。自分自身を呼ばない印つき。**masaru の `~/.local/bin/thth` は repo の版と中身が違う（手で直したもの）ので、こちらでは上書きしていない。差し替えは朝の報告に。**
4. privacy: ブラウザでのサインインで鍵を最長 10 分預かる 1 文（英日）。施行日 2026-09-27（deploy の日）。

## 運営者が deploy のあとにすること

1. Worker の deploy（`env.LOGIN (Login)` が出る。新しい secret・変数は無い）。
2. tag `v3.14.2`（Claude が押す）→ `pip install -U thth`。
3. 通し: `python3 -m thth login`（ラッパを差し替える前は `python3 -m thth` で）→ ブラウザで許可 → 数十秒 → `python3 -m thth account status inv-jiangshi-lab-fce905`。
