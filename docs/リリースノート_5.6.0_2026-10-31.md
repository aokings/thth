## 変わったこと（d77d952・f5b68d8）

- `thth ads boost`: 既にある投稿から、キャンペーン・広告セット・クリエイティブ・広告を **全部 PAUSED** で作る。終了日は必須・1 操作の上限・`days_max`・JPY 以外は作らない。対象は日本・18 歳以上。お金は動かない。MCP からも打てる。
- `thth ads activate`（CLI だけ）: 2 段（digest → `--confirm` と hub の番号）。2 段目で Meta から木を読み直し、違えば `ads_tree_changed`（変わった欄を添える）。月の上限の予約・`spend_cap` が 0 でない・鍵の残り 14 日以上・`ads_enabled`・`production`・時間帯の一致。ACTIVE にするのは digest の id だけ。
- `thth ads extend`（CLI だけ・2 段）: 期間を延ばす・予算を増やす。
- `thth ads pause|stop|end|budget lower`: 承認なし・止めた口座でも通る・量の制限で待たない。`stop` は pause → 読み直し → `spend_cap` を使った額へ → THTH の止め。「止まった」と言うのは木を全部読み直せたときだけ。確かめられなければ `ads_stop_unconfirmed` と hub に送る 1 行。
- `spend_cap`・月の上限・1 操作の上限・`ads_enabled` を **上げる口は CLI にも MCP にも無い**（試験で縛る）。上げるのは管理画面か VM の台帳の直書き。
- 月の上限は「口座の今月の実支出の全部 ＋ 終わっていない予約の残り」で数える（監査 1-1）。THTH が止めた物を外で再開すると `ads_active_outside_thth`（監査 1-2）。
- `thth ads doctor`・`show`: 期限なしの鍵を「期限なし」と言う（`expires_at=0`）。最低額は口座の通貨の分だけ。
