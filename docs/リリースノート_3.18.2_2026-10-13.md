# リリースノート 3.18.2（X の投稿の知らない断りの文面を残す）

2026-10-13。3.18.1 の符丁に当たらない 403（関東の返信・run f35727ad73f0）が `x_publish_http_403` だけを残した。関東（SageSpring）の依頼で、知らない形の断りは X の problem の `type`（末尾の語）・`title`・`detail`（無ければ `errors[0].message`）を `x_unknown_refusal（…）` として理由に残す。`redact` を通し 200 字で切る。自分の要求への X の断りの文で、他人の投稿の本文は入らない。

確かめたこと（L1・docs.x.com Create Post）: 引用（`quote_tweet_id`）は "requires an Enterprise plan" "not available on self-serve (pay-per-use) tiers"。返信の制限の記述は無い。
