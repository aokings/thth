## 触ってはいけないもの・決まり

- `CLAUDE.md` のとおり。release は `git push origin <sha>:refs/heads/release`（`${sha}` と書く）。試験は `python -m pytest -q -n auto` の終了コードを見る
- VM の台帳の書き換え（`ssh wt` で JSON を直す）は auto mode が止める → masaru に 1 行を頼む。止められたら別の書き方で通さない
- 同じ checkout で別セッションが作業していることがある。`git add` はパスを明示
- 書き手（サブエージェント）の報告は、自分で試験を回して確かめてから取り込む。docs のリンクの検査（`tests/test_docs_links.py`）は文書だけの commit でも走る
