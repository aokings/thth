## 使う人の側から見て入ったこと

### 新しい命令

- `thth register adopt・restore・diff・keep・merge・resume・row` — 元のファイルから台帳を作り（元には 1 バイトも書かない）、元どおり戻し、変えた跡を見て、まとめて入れ替える。止まっても前か後のどちらかに見え、混ざらない。
- `thth register judge・take・export・accept・verify・key・use --outlet` — 記録の版への判断を残し、判断の届いた物だけを出し口ごとの材料にし、受け入れて鍵つきの封をし、公開の直前にもう一度確かめる。
- `thth register used・published` — どの記録がどの材料・公開に使われたか（`published` は `--previous` か `--no-previous` が要る）。
- `thth register erase` — 消す求め。封の署名も外し、結果の記録は署名を確かめた封に載った物だけ信じる。
- `thth register health`・`sisters` — 台帳の健康（期限・止め・古い判断）と、複数のメディアをまたいだ見え方。
- `thth register add --common` — 共通の台帳（持ち主に 1 つ）。台帳の `.thth/kinds/` に備え付けの宣言を 3 つ書く。
- `thth project leave`・`thth owner leave` — 外す範囲を project・持ち主で選ぶ。

### 変わったこと

- `thth account leave` は、最後の口座でも台帳の控えを消さなくなった（外すのは `project leave`・`owner leave` で選ぶ）。
- 公開の場所に出す写し `thth-seal.<出し口>.json` の形が変わった（台帳ごとの秘密の塩を混ぜた要約・頭・行ごとの組）。前の写しとは比べられないので、最初の配りは `--no-previous`。**台帳の repo を公開していると塩も公開になる。**
- 種類の宣言で読める形が増えた: 区切りの表（カンマ・タブ）・頭に YAML のある .md・JSON と YAML の並びと鍵の辞書・ASCII でない番号と置き場の型・TypeScript の `export const` の値（`ts_const`）・見出しの無い区切りの行（`lines`）。新しい 2 形式は読むだけ（書く口・記録ごとの出口は断る）。

### privacy

- 台帳の節に、器が台帳のフォルダに書く物（判断の記録・封・控え・束・消す求め・公開の写し・種類の宣言）と、封の秘密の鍵の置き場（`~/.config/thth/register_seal.pem`）、消す範囲を足した。施行日 2026-11-14（出す日がずれたら `tools/build_site.py` の `PRIVACY_EFFECTIVE` を直して頁を作り直す）。
- 叩き台 `docs/叩き台_privacy_台帳の器_2026-11-14.md`。置き場の名前と消す範囲は `tests/test_privacy_matches_code.py` がコードと結ぶ。
