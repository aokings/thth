# 依頼: THTH の observe を並び順でなく名前で読んでほしい（2026-10-16・THTH開発 第2 → メディアハブ・H2D）

THTH 3.23.0 で、`observe --json` に版と名前つきの節を足した。今の並び（`sections[1]`・`sections[4]`）はそのまま残しているので、**今すぐ壊れるものは無い**。並びは 4.0（11 月前半の予定）で、移行の確認と予告のあとに外す（[計画_4.0](計画_4.0_2026-10-15.md) §7 の 8）。

## 足したもの（3.23.0）

- `observe --json`: `schema: "thth.observe/1"` と `sections_by_name.<名前>`（tool・unanswered・yesterday・world・today・next_steps）。中身は並びの節と同じ。
- `board --json`: `schema: "thth.board/1"`。
- `thth events <口座|project> --after <next_cursor> --json`: 出来事（公開・返信・言及・止まり・予算・inflight）。各行に `event_id`・`occurred_at`・`recorded_at`・`schema`。`next_cursor` で続きから取りこぼさず読み直せる。**重複は受け手が `event_id` で除く**。
- `thth summary <口座|project> --json`（`thth.summary/1`）: 24h・7d の公開数・反応の和・返していない返信・フォロワーの最新と前日差・止まっているか。

## H2D に頼みたいこと

1. `config/sensors/thth-kanto-inflight.json`・`thth-kanto-overdue.json` の `sections[4]` を `sections_by_name.today` に、`thth-kanto-replies.json` の `sections[1]` を `sections_by_name.unanswered` に書き換える。`h2d/catalog.py` の例（889 行あたり）も。以降は `schema == "thth.observe/1"` を確かめてほしい。
2. 出来事を起点にしたいときは `thth events --after <next_cursor> --json` を `command_json` の probe にできる（重複は `event_id` で）。

## メディアハブに頼みたいこと

1. `hub/snsobs.py` の `sec = {s["section"]: s for s in obs["sections"]}` を `obs["sections_by_name"]` に替え、`schema` が `thth.observe/1` でなければ黄色に。
2. board は `schema: "thth.board/1"` を確かめるだけでよい。
3. 朝の数に `thth summary --json` が使える。

## 終わったら

新しい形を実際に読めたこと（1 回の実行の記録）を返してほしい。4.0 で並びを外す条件の 1 つにする（外部レビューの指摘 12）。
