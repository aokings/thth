# リリースノート 3.18.1（X の投稿の 403 に理由の符丁）

2026-10-13。関東の X の返信が `x_publish_http_403` だけを残して断られ、理由が分からなかった件。

- X の投稿（文字だけ）が 4xx で断られたとき、応答の本文（`detail`・`title`・`errors[].message`）を 1 回だけ読み（4KB まで）、知っている形なら**静的な符丁**を理由に足す: `x_publish_http_403: x_reply_not_engaged`（返信先の投稿者からメンション等の関わりが無い）・`x_not_permitted`（アカウントか app の制限）・`x_duplicate_content`。provider の文面そのものは理由に混ぜない（`rate_limit()` と同じ流儀）。知らない形は今までどおり `x_publish_http_403`。
- 文面は X の開発者フォーラムでの報告の形（docs.x.com の Create Post の頁には返信の制限の記述が無い・L3）。実機で次の 403 が出たとき、どれに当たるかで分かる。
- 画像つきの投稿（`x_media`）は変えていない。
