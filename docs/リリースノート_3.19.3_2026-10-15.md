# リリースノート 3.19.3（`where --question` の表示を正直に）

2026-10-15。

- `thth where --question` の説明と表示を「問いかけだけ」から「「？」のあるものだけ」に改めた。判定は今までどおり、検索語を外した本文に「？」か「?」があるかだけ。独り言や反語の「？」も入り、**相手が返信を求めているかは見ていない**ことを、help・表示・SKILL に書いた。
- きっかけ: 10/15、kopicha の X で人の手で返信する候補をこの絞り込みで探したところ、どれも返信を求めている投稿ではなかった（masaru「元の投稿自体が返信を求めている風では無かった」）。返信するかは、全文を読んで決める。
- 判定そのもの・JSON の欄・数え方は変えていない。
