# 招待されたら（招待された人の 1 枚）

THTH は、自分の SNS アカウントで調べる・投稿する・予約する・振り返るためのコマンドラインツールです。
招待されたアカウントは、運営（gotoq）のサーバーで動きます。あなたはサーバーも Meta アプリも git も持ちません。

あなたが `thth` コマンドを打っても、あなたの AI アシスタント（Claude Code など）が打っても、同じことができます。
アシスタントには日本語で「これを Threads に出して」と頼むだけです。
承認のページはありません。その代わり、アシスタントが誤って走ったときに止まるガードがあります（4 節）。

## 1. 用意するもの

1. Threads のアカウント。
2. パスワードマネージャー。1 度だけ表示される 2 つの値を保管します。
   - **アカウントのシークレット**: `https://thth.me/activity` に入る・アカウントを止める・キーを発行し直すときに使います。
   - **API キー**: `thth` コマンドが使います。ふつうは `thth login` が受け取るので、手で使うことはまずありません。
3. Python 3.12 以上のあるターミナル。アシスタントを使うなら、そのアシスタント。

これ以外は要りません。トークン、サーバー、git、SNS 側のアプリ登録には触りません。

## 2. 始めるまで（招待リンク・Threads）

運営から `https://thth.me/invite/…` の URL が届きます。

1. URL を開きます。「THTH への招待」のページに、何が起きるか・求める権限・プライバシーポリシーと利用規約へのリンクが出ます。
2. 「Threads で認可する」を押します。数十秒で次へ進みます。
3. 「Threads の認可ページを開く」を押すと、新しいタブで Threads が開きます。**あなた自身のアカウントでログインした状態で**許可してください。
4. 「受け付けました」と出たら、最初のタブに戻ります。数十秒で「用意ができました」に変わります。
5. 「アカウントのシークレットを表示する」を押します。**表示は 1 度だけです。**次のページのアカウント名（`inv-…`）と、アカウントのシークレット・API キーを、パスワードマネージャーに Web サイト `thth.me` として保存してください（シークレットとキーは別の項目に）。
6. ターミナルで次の 2 行を打ちます。

   ```bash
   pip install thth
   thth login
   ```

   ブラウザで `https://thth.me/login/…` が開きます。アカウント名とアカウントのシークレットを入れて「このデバイスにキーを渡す」を押すと、ターミナルが「保存しました」と言います。
   - ブラウザが開かなければ、ターミナルに出た URL を開きます。
   - 別のデバイスのブラウザで開くなら `thth login --no-browser` です。
   - ブラウザが使えなければ `thth login --stdin` で、5 の API キーを貼ります（引数には書きません）。
7. `thth account status <アカウント名>` が返れば準備できています。
8. アシスタントを使うなら、`claude mcp add thth -- thth-mcp` とスキル（`skills/thth/`）を入れます。アシスタントは同じ `thth` コマンドを代わりに打つだけで、キーはアシスタントに渡りません。

Threads のトークンは、Threads から運営のサーバーへ直接入ります。招待のページは通りません。
シークレットとキーは招待のページが作り、あなたの画面に 1 度だけ出します。運営もアシスタントも見ません。残るのはハッシュだけです。
シークレットとキーは、アシスタントにも原稿にも渡さないでください。キーを失くしたり漏れたと思ったら、`thth login` をやり直すか `https://thth.me/activity` で発行し直します。前のキーは使えなくなります。

### こういうときは

- 「この招待リンクは使えません」: 使用済み・期限切れ・取り消しのどれかです。運営に新しい招待を頼んでください。
- 「準備が進んでいません」: 運営のサーバーが止まっている可能性があります。[プライバシーポリシーの連絡先](https://thth.me/privacy/)から知らせてください。ページは開いたままで構いません。
- 「その Threads アカウントは既に THTH にあります」: 別のアカウントで押し直すか、運営に連絡してください。
- 「認可の時間が過ぎました」: 10 分の期限です。少し待つと、もう一度押せるようになります。
- シークレットを失くした: 運営に再発行を頼んでください。前のシークレットは使えなくなります。
- `thth` が `key_expired`・`invalid_key` と言う: `thth login` をやり直します。
- `thth login` が `login_expired` と言う: 10 分のうちに許可されませんでした。`thth login` をやり直します。

## 3. 使う

`<アカウント>` はアカウント名（`inv-…`）です。

### 調べる

```bash
thth topics <アカウント> --search <語>        # その語の件数・投稿者の数・最新の投稿
thth mentions <アカウント>                    # 自分への言及
thth profile <アカウント> <username>          # 公開プロフィール
thth location search <アカウント> <語>        # 場所の候補
```

検索結果の本文と投稿者は、その場で見せるだけで保存しません。

### 出す・消す

```bash
thth send <アカウント> --text "…"                          # 今すぐ出す（投稿 ID とリンクが返ります）
thth send <アカウント> --text "…" --reply-to <post_id>     # 返信
thth schedule <アカウント> --text "…" --at 2026-10-01T09:00+09:00   # 予約（予約の timer があるアカウントだけ）
thth retract <アカウント> <post_id>                        # 消す
```

出す前に自分で読みたいときは、アシスタントに「出す前に本文を見せて」と頼んでください。
画像の添付は、いまの版ではアシスタントの道具（`thth_media_upload_url`・`thth_media_complete`）からだけです。

### 振り返る

```bash
thth posts <アカウント>                       # 自分の投稿の一覧
thth replies <アカウント> --refresh           # 返信を読む
thth collect <アカウント>                     # 返信とインサイトを取得する
thth measured <アカウント>                    # インサイト（表示・いいね・返信などの数）
```

### アシスタントの道具

MCP の道具は CLI の写しです。名前は `thth_send_request`・`thth_schedule_request`・`thth_retract_request`・`thth_posts`・`thth_replies`・`thth_measured`・`thth_collect`・`thth_mentions`・`thth_topics_search`・`thth_profile`・`thth_location_search`・`thth_account_status`・`thth_settings`、下書きの `thth_draft_put`・`thth_draft_list` です。

再投稿といいねは、まだできません。

## 4. ガード

アシスタントが誤って走っても、次の数値で止まります。数値はあなたが決められます。
アシスタント（`thth_settings`・`thth account set`）から変えられるのは、厳しくする向き（上限を下げる・間隔を延ばす）だけです。
緩めるのは `https://thth.me/activity` からシークレットで行います。暴走したアシスタントが自分でガードを外せないようにするためです。

| ガード | 既定 | 超えたとき |
|---|---|---|
| 投稿の最短間隔（返信には掛けない） | 6 時間 | `too_soon`（次に出せる時刻つき） |
| 1 日の投稿 | 8 件 | `daily_limit` |
| 1 日の削除 | 5 件 | `retract_limit` |
| 急な連投 | 10 分に 3 件（投稿と削除の合計） | **アカウントが止まります**（`account_stopped: burst`） |
| 夜間 | 22:00〜07:00 | 今すぐの投稿は `quiet_hours` |

```bash
thth account status <アカウント>              # ガードの数値・今日の数・止まっているか・キーの期限
thth account set <アカウント> <項目> <値>      # ガードを厳しくする
```

止まったアカウントは、アシスタントからは戻せません。あなたが `https://thth.me/activity` で戻します（5 節）。

## 5. 見る・止める（`https://thth.me/activity`）

アカウント名とシークレット（パスワードマネージャーが入れてくれます）で入ると、あなたのアカウントで出たもの・消したもの・予約・待機中のもの・止まった理由が新しい順に並びます。

ここでできること（どれもシークレットで確かめます）:

- アカウントを止める（アシスタントの様子がおかしいと思ったらすぐ）。
- 止まったアカウントを戻す。
- 待機中・予約中の投稿を取り消す。
- API キーを発行し直す・取り消す。取り消したキーは、すぐ使えなくなります。
- ガードの数値を変える（緩める向きはここからだけ）。

シークレットを 5 回続けて間違えると、入口は 15 分閉じます。15 分たてば自然に戻ります。

## 6. やめるとき

運営に「やめます」と伝えるだけです。
運営がサーバー側でアカウントを止め、あなたのデータを消します（退会）。
Threads との接続の解除は、あなた自身の Threads の設定（アカウント → ウェブサイトのアクセス許可）で行ってください。

## 7. エラーコード

断るときは、決まった英語のエラーコードで返ります。

| エラーコード | 意味 | すること |
|---|---|---|
| `too_soon` / `daily_limit` / `retract_limit` / `quiet_hours` | ガード | 添えられた時刻まで待つか、数値を変える |
| `account_stopped: burst` | 急な連投でアカウントが止まった | `thth.me/activity` で中身を確かめてから戻す |
| `schedule_unavailable` | アカウントに予約の timer が無い | 今すぐ出すか、運営に timer を頼む |
| `invalid_draft: hashtags_disabled_by_ledger` | ハッシュタグが禁じられているのに本文に `#` がある | `#` を外して置き直す |
| `account_leaving` | 退会の処理の最中 | 待つ |
| `key_expired` / `invalid_key` | キーが切れた・無効 | `thth login` をやり直す |
| `remote_unsupported` | そのコマンドは招待のアカウントでは使えない（運営のコマンド・手元のファイルを読むコマンド） | 使えるコマンドは 3 節の一覧 |
| `remote_unavailable` | thth.me に届かない | 少し待ってやり直す。続くなら運営に連絡 |

## 8. 約束しないこと

- 公開したあとに SNS 側で起きることは戻せません。
- アカウントのシークレットはパスキーではありません。フィッシングへの強さは同じではありません。
- `/activity` の要約（本文の先頭 60 字）は 1 時間で論理的に消しますが、Cloudflare の Durable Object には最大 30 日の復元期間があります。物理的に消えたことは保証しません。
- SNS そのものの退会やアカウント削除は、あなたの SNS の設定で行ってください。

招待する側の手順は `docs/運用_招待する側.md` にあります。
