# 招待されたら（招待された人の 1 枚）

THTH は masaru のサーバで動きます。
あなたは VM もアプリも git も持ちません。
あなたは、ふだん使っている LLM（Claude Code など）に日本語で頼むだけです。
LLM が書いて、あなたの口座に出します。

THTH は CLI ツールです。あなたが打っても、あなたの LLM が打っても同じことができます。
承認ページはありません（3.13.0 で無くしました）。その代わり、LLM が誤って走ったときに止まる安全装置があります（3 節）。

## 1. 用意するもの

1. 投稿する媒体のアカウント。
2. パスワードマネージャ。1 度だけ表示される 2 つの値を保管します。**口座の secret**（`https://thth.me/activity` に入る・止める・鍵を発行し直すときに使います）と、**アシスタントの鍵**（`thth` 命令に登録します）。
3. Python 3.12 以上のあるターミナル（`pip install thth`）。LLM（Claude Code など）を使うなら、その LLM。

これ以外は要りません。
トークン、サーバ、git、媒体側のアプリ登録には触りません。

## 2. 始めるまで（招待リンク・Threads）

masaru から `https://thth.me/invite/…` の URL が届きます。

1. URL を開きます。何が起きるか・求める権限・プライバシーと利用規約へのリンクが出ます。
2. 「Threads で認可する」を押します。数十秒で次へ進みます。
3. 「Threads の認可ページを開く」を押すと、新しいタブで Threads が開きます。**あなた自身のアカウントでログインした状態で**許可してください。
4. 「受け付けました」と出たら、最初のタブに戻ります。数十秒で「用意ができました」に変わります。
5. 「口座の secret を表示する」を押します。**表示は 1 度だけです。**次のページの口座名（`inv-…`）と、口座の secret・アシスタントの鍵を、パスワードマネージャに Web サイト `thth.me` として保存してください（secret と鍵は別の項目に）。
6. ターミナルで `pip install thth`、続けて `thth login` と打ちます。ブラウザで `https://thth.me/login/…` が開くので、口座名と口座の secret を入れて「この機械に鍵を渡す」を押します（3.14.2 から。ブラウザが開かなければ、ターミナルに出た URL を開きます。別の機械のブラウザで開くなら `thth login --no-browser`。ブラウザが使えなければ `thth login --stdin` で 5 の鍵を貼ります。引数には書きません）。鍵は数十秒後から使えます。`thth account status <口座名>` が返れば準備できています。
7. LLM を使うなら、`claude mcp add thth -- thth-mcp` と skill（`skills/thth/`）を入れます。LLM は同じ `thth` 命令を代わりに打つだけで、鍵は LLM に渡りません（`thth login` が手元に置いた鍵を `thth` 命令が使います）。

トークンは Threads から masaru のサーバへ直接入ります。招待のページは通りません。
secret と鍵は招待のページが作り、あなたの画面に 1 度だけ出します。masaru も LLM も見ません。残るのはハッシュだけです。
secret と鍵は LLM に渡しません。原稿にも書きません。鍵を失くしたり漏れたと思ったら、`thth login` をやり直すか `https://thth.me/activity` で発行し直すと、前の鍵は使えなくなります。

### こういうときは

- 「この招待リンクは使えません」: 使用済み・期限切れ・取り消しのどれかです。masaru に新しい招待を頼んでください。
- 「準備が進んでいません」: masaru のサーバが止まっている可能性があります。masaru に連絡してください。ページは開いたままで構いません。
- 「その Threads アカウントは既に THTH にあります」: 別のアカウントで押し直すか、masaru に連絡してください。
- 「認可の時間が過ぎました」: 10 分の期限です。少し待つと、もう一度押せるようになります。
- secret を失くした: masaru に再発行を頼んでください。前の secret は使えなくなります。
- `thth` が `key_expired`・`invalid_key` と言う: `thth login` をやり直します（ブラウザで許可すると鍵を発行し直します）。
- `thth login` が `login_expired` と言う: 10 分のうちに許可されませんでした。`thth login` をやり直します。

## 3. 書いて出す

**THTH は CLI ツールです。** あなたが打っても、あなたの LLM が打っても同じことができます。`<口座>` は口座名（`inv-…`）。

```
thth posts <口座>                          # 自分の投稿の一覧
thth send <口座> --text "…"                # 今すぐ出す（投稿 ID とリンクが返ります）
thth send <口座> --text "…" --reply-to <post_id>
thth schedule <口座> --text "…" --at 2026-10-01T09:00+09:00   # 予約（口座に予約の timer があるときだけ）
thth retract <口座> <post_id>              # 消す
thth replies <口座> --refresh              # 返信を読む
thth collect <口座> && thth measured <口座> # 数字（インサイト）
thth mentions <口座> / thth topics <口座> --search <語> / thth profile <口座> <username> / thth location search <口座> <語>
thth account status <口座>                 # 安全装置の数・止まっているか・鍵の期限
thth account set <口座> <項目> <値>         # 安全装置を締める（緩めるのは /activity から）
```

LLM には「これを Threads に出して」「さっきの投稿を消して」と頼むだけです。LLM が使う道具（MCP）は命令の写しで、名前は `thth_send_request`・`thth_schedule_request`・`thth_retract_request`・`thth_posts`・`thth_replies`・`thth_measured`・`thth_collect`・`thth_mentions`・`thth_topics_search`・`thth_profile`・`thth_location_search`・`thth_account_status`・`thth_settings`・下書きの `thth_draft_put`・`thth_draft_list` です。
出す前に自分で読みたいときは、LLM に「出す前に本文を見せて」と頼んでください。THTH の側に承認の関所はありません。添付（画像）は今の版では LLM の道具（`thth_media_upload_url`・`thth_media_complete`）からだけです。

### 安全装置

LLM が誤って走っても、次の数値で止まります。数値はあなたが決められます。LLM（`thth_settings`）から変えられるのは締める方向（上限を下げる・間隔を延ばす）だけで、緩めるのは `https://thth.me/activity` から secret で行います（暴走した LLM が自分で安全装置を外せないように）。

| 装置 | 既定 | 超えたとき |
|---|---|---|
| 最短間隔（返信には掛けない） | 6 時間 | `too_soon`（次に出せる時刻つき） |
| 1 日の公開 | 8 件 | `daily_limit` |
| 1 日の削除 | 5 件 | `retract_limit` |
| 急な連投 | 10 分に 3 件（公開と削除の合計） | **口座が止まります**（`account_stopped: burst`） |
| 夜間 | 22:00〜07:00 | 今すぐの公開は `quiet_hours` |

止まった口座は、LLM からは戻せません。あなたが `https://thth.me/activity` で戻します（4 節）。

## 4. 見る・止める（`https://thth.me/activity`）

口座名と secret（パスワード管理が入れてくれます）で入ると、あなたの口座で出たもの・消したもの・予約・止まった理由が新しい順に並びます。

ここでできること（どれも secret で確かめます）:

- 口座を止める（LLM がおかしいと思ったらすぐ）。
- 止まった口座を戻す。
- 猶予中・予約中の投稿を取り消す。
- LLM に渡した鍵（MCP の資格）を発行し直す・取り消す。取り消した鍵は、すぐ使えなくなります。
- 安全装置の数値を変える（緩める向きはここからだけ）。

secret を 5 回続けて間違えると、入口は 15 分閉じます。15 分たてば自然に戻ります。

## 5. やめるとき

masaru に「やめます」と伝えるだけです。
masaru がサーバ側で停止し、あなたのアカウントのデータを消します。
Threads の接続解除は、あなた自身の Threads の設定（アカウント → ウェブサイトのアクセス許可）で行ってください。

## 6. 断られ方

断りは静的な符丁で返ります。文面を読み替える必要はありません。

| 符丁 | 意味 | すること |
|---|---|---|
| `too_soon` / `daily_limit` / `retract_limit` / `quiet_hours` | 安全装置 | 添えられた時刻まで待つか、数値を変える |
| `account_stopped: burst` | 急な連投で口座が止まった | `thth.me/activity` で中身を確かめてから戻す |
| `schedule_unavailable` | 口座に予約の timer が無い | 今すぐ出すか、masaru に timer を頼む |
| `invalid_draft: hashtags_disabled_by_ledger` | 台帳がハッシュタグを禁じているのに本文に `#` がある | `#` を外して置き直す |
| `account_leaving` | 退出処理の最中 | 待つ |
| `key_expired` / `invalid_key` | 鍵が切れた・無効 | `thth login` をやり直す（ブラウザで許可すると発行し直す） |
| `remote_unsupported` | その命令は遠くの道では使えない（運営の命令・手元のファイルを読む命令） | 使える命令は 3 節の一覧 |
| `remote_unavailable` | thth.me に届かない | 少し待ってやり直す。続くなら masaru に連絡 |

## 7. 約束しないこと

- 公開したあとに媒体側で起きることは戻せません。
- 口座の secret は passkey ではありません。phishing 耐性は同じではありません。
- `/activity` の要約（本文の先頭 60 字）は 1 時間で論理的に消しますが、Cloudflare の SQLite Durable Object には最大 30 日の復元期間があります。物理的に消えたことは保証しません。
- 媒体そのものの退会やアカウント削除は、あなたの媒体の設定で行ってください。

招待する側の手順は `docs/運用_招待する側.md` にあります。
