# 招待されたら（招待された人の 1 枚）

THTH は masaru のサーバで動きます。
あなたは VM もアプリも git も持ちません。
あなたがすることは、4 回だけ画面を見て押すことです。

## 1. 用意するもの

1. 投稿する媒体のアカウント。
2. パスワードマネージャ。承認 secret を 1 つ保管します。
3. Claude Code のセッション。MCP の登録 1 行は masaru が渡します。

これ以外は要りません。
トークン、サーバ、git、媒体側のアプリ登録には触りません。

## 2. あなたが動く 4 回

### (1) 認可 URL を開いて承認を押す

masaru が URL を 1 本渡します。
その媒体に**あなた自身のアカウントでログインした状態で**開いてください。
表示されたアカウントと権限を見て、承認を押します。

トークンは媒体からサーバへ直接渡ります。
あなたも masaru も LLM も、その値を見ません。

別のアカウントでログインしていると `mastodon_identity_mismatch` で断られます。
このとき何も保存されません。
正しいアカウントでログインし直して、masaru に URL を出し直してもらってください。

URL は公開の場や LLM の会話に貼らないでください。
使い終わった URL は再利用できません。

### (2) 承認 secret を保管する

masaru が 43 文字の secret を 1 度だけ渡します。
その場でパスワードマネージャに入れてください。

macOS と iOS の「パスワード」アプリなら、次のように入れると承認ページで自動入力されます。

- ユーザ名: masaru が登録したあなたの名前の綴り。
- Web サイト: `thth.me`。

secret は LLM に渡しません。
原稿にも書きません。
masaru が再発行すると、前の世代の承認ページは無効になります。

### (3) 原稿の承認ページで押す

あなたのセッションの LLM が原稿を置くと、承認 URL が 1 本返ります。
開くと、種類・アカウント・本文・digest・添付・公開予定が出ます。

1. 本文を読みます。
2. 添付があれば、画像が**実際に表示されていること**を確かめます。表示されない添付は承認しないでください。
3. secret を入れて承認を押します。
4. 「原稿の承認を受け付けました」と出ます。ここで終わりではありません。サーバが本文と台帳をもう一度照合してから、承認を刻むか公開します。

ページは 10 分で切れます。
切れたら押せません。もう一度出してもらってください。
一度使ったページは「承認ページは無効です」になります。
secret を 5 回続けて間違えるとあなたがロックされます。masaru に解除を頼んでください。

### (4) やめるとき

masaru に「やめます」と伝えるだけです。
masaru がサーバ側で停止し、媒体側の権限を失効させ、あなたのアカウントのデータを消します。

Mastodon と X は道具が媒体へ失効を投げます。
Threads の接続解除と Bluesky の App Password 削除は、あなた自身の設定画面で行ってください。
道具がそう案内します。

## 3. 書くときの流れ

セッションの LLM が使う道具はこれだけです。
あなたは日本語で頼むだけで構いません。

1. 下書きを置く。`thth_draft_put`（本文と公開予定を渡すと draft_id と revision が返ります）。
2. 下書きを見る。`thth_draft_list`。
3. 承認を求める。`thth_approval_request`（承認 URL が返ります。10 分）。
4. すぐ公開する。`thth_send_request`（承認の直後に出ます）。
5. 消す。`thth_retract_request`。
6. どうなったか見る。`thth_request_status`。
7. 添付を付ける。`thth_media_upload_url` で置き場をもらい、`thth_media_complete` で確定します。

予約公開は、あなたのアカウントの timer が 10 分刻みで拾います。
夜間帯（`quiet_hours`）と最短間隔（`min_interval_hours`）は台帳の設定が優先します。
指定した時刻ちょうどに出るとは限りません。

## 4. 断られ方

断りは静的な符丁で返ります。
文面を読み替える必要はありません。

| 符丁 | 意味 | すること |
|---|---|---|
| `invalid_draft: hashtags_disabled_by_ledger` | 台帳がハッシュタグを禁じているのに本文に `#` がある | `#` を外して置き直す |
| `draft_not_editable` | 承認済みの原稿は凍る | 直さずに、新しい下書きを作る |
| `mastodon_identity_mismatch` | 認可のときのログイン先が違う | 正しいアカウントでログインして URL を出し直してもらう |
| `account_leaving` | 退出処理の最中 | 待つ |

## 5. 約束しないこと

- 承認ページと添付の置き場は 10 分で切れます。伸ばせません。
- 承認 secret は passkey ではありません。phishing 耐性は同じではありません。
- 承認ページの本文は論理的に消しますが、Cloudflare の SQLite Durable Object には最大 30 日の復元期間があります。物理的に消えたことは保証しません。
- 見えなかった添付は承認されていません。
- 公開したあとに媒体側で起きることは戻せません。
- 媒体そのものの退会やアカウント削除は、あなたの媒体の設定で行ってください。

招待する側の手順は `docs/運用_招待する側.md` にあります。

## 6. 招待リンクを受け取ったら（3.10.0・Threads）

masaru から `https://thth.me/invite/…` の URL が届いたときの道です。
2 の (1) と (2) を、あなたが自分で進めます。

1. URL を開きます。何が起きるか・求める権限・プライバシーと利用規約へのリンクが出ます。
2. 「Threads で認可する」を押します。数十秒で次へ進みます。
3. 「Threads の認可ページを開く」を押すと、新しいタブで Threads が開きます。**あなた自身のアカウントでログインした状態で**承認してください。
4. 「承認を受け付けました」と出たら、最初のタブに戻ります。数十秒で「用意ができました」に変わります。
5. 「承認 secret を表示する」を押します。**表示は 1 度だけです。**その場でパスワードマネージャに入れてください。ユーザ名は画面に出る口座名（`inv-…`）、Web サイトは `thth.me` です。
6. あとは 2 の (3) と同じです。承認ページの URL は masaru から届きます。

トークンは Threads から masaru のサーバへ直接入ります。招待のページは通りません。
secret は招待のページが作り、あなたの画面に 1 度だけ出します。masaru も LLM も見ません。

### こういうときは

- 「この招待リンクは使えません」: 使用済み・期限切れ・取り消しのどれかです。masaru に新しい招待を頼んでください。
- 「準備が進んでいません」: masaru のサーバが止まっている可能性があります。masaru に連絡してください。ページは開いたままで構いません。
- 「その Threads アカウントは既に THTH にあります」: 別のアカウントで押し直すか、masaru に連絡してください。
- 「認可の時間が過ぎました」: 10 分の期限です。少し待つと、もう一度押せるようになります。
- secret を失くした: masaru に再発行を頼んでください。前の secret は使えなくなります。
