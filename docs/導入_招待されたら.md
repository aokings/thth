# 招待されたら（招待された人の 1 枚）

THTH は masaru のサーバで動きます。
あなたは VM もアプリも git も持ちません。
あなたは、ふだん使っている LLM（Claude Code など）に日本語で頼むだけです。
LLM が書いて、あなたの口座に出します。

THTH は道具です。あなたとあなたの LLM を疑って、毎回の承認を求めることはしません（3.12.0 から）。
その代わり、LLM が誤って走ったときに止まる安全装置があります（3 節）。

## 1. 用意するもの

1. 投稿する媒体のアカウント。
2. パスワードマネージャ。承認 secret を 1 つ保管します（止める・取り消すときに使います）。
3. LLM のセッション（Claude Code など）。登録する 1 行は、始めるときにあなたが自分で発行します（2 節の 6）。

これ以外は要りません。
トークン、サーバ、git、媒体側のアプリ登録には触りません。

## 2. 始めるまで（招待リンク・Threads）

masaru から `https://thth.me/invite/…` の URL が届きます。

1. URL を開きます。何が起きるか・求める権限・プライバシーと利用規約へのリンクが出ます。
2. 「Threads で認可する」を押します。数十秒で次へ進みます。
3. 「Threads の認可ページを開く」を押すと、新しいタブで Threads が開きます。**あなた自身のアカウントでログインした状態で**承認してください。
4. 「承認を受け付けました」と出たら、最初のタブに戻ります。数十秒で「用意ができました」に変わります。
5. 「承認 secret を表示する」を押します。**表示は 1 度だけです。**同じページの口座名（`inv-…`）と secret を、パスワードマネージャに Web サイト `thth.me` として保存してください。
6. `https://thth.me/activity` に口座名と secret で入り、「LLM の鍵を発行する」を押します。LLM に登録する 1 行が 1 度だけ出るので、あなたの LLM に登録します。これで使えます。鍵を失くしたり漏れたと思ったら、同じところで発行し直すと前の鍵は使えなくなります。

トークンは Threads から masaru のサーバへ直接入ります。招待のページは通りません。
secret は招待のページが作り、あなたの画面に 1 度だけ出します。masaru も LLM も見ません。
secret は LLM に渡しません。原稿にも書きません。

### こういうときは

- 「この招待リンクは使えません」: 使用済み・期限切れ・取り消しのどれかです。masaru に新しい招待を頼んでください。
- 「準備が進んでいません」: masaru のサーバが止まっている可能性があります。masaru に連絡してください。ページは開いたままで構いません。
- 「その Threads アカウントは既に THTH にあります」: 別のアカウントで押し直すか、masaru に連絡してください。
- 「認可の時間が過ぎました」: 10 分の期限です。少し待つと、もう一度押せるようになります。
- secret を失くした: masaru に再発行を頼んでください。前の secret は使えなくなります。

## 3. 書いて出す

LLM に「これを Threads に出して」「さっきの投稿を消して」と頼むだけです。
LLM が使う道具は次のとおりです。

1. 下書きを置く・見る。`thth_draft_put`・`thth_draft_list`。
2. 今すぐ出す。`thth_send_request`（出た投稿の ID とリンクが返ります）。
3. 予約して出す。`thth_schedule_request`（口座に予約の timer があるときだけ。無ければ `schedule_unavailable` で断ります）。
4. 消す。`thth_retract_request`。
5. どうなったか見る。`thth_request_status`・`thth_account_status`。
6. 添付を付ける。`thth_media_upload_url` で置き場をもらい、`thth_media_complete` で確定します。
7. 設定を見る・変える。`thth_settings`（承認のしかたと安全装置の数値）。

### 安全装置

LLM が誤って走っても、次の数値で止まります。数値はあなたが決められます。LLM（`thth_settings`）から変えられるのは締める方向（上限を下げる・間隔を延ばす）だけで、緩めるのは `https://thth.me/activity` から secret で行います（暴走した LLM が自分で安全装置を外せないように）。

| 装置 | 既定 | 超えたとき |
|---|---|---|
| 最短間隔（返信には掛けない） | 6 時間 | `too_soon`（次に出せる時刻つき） |
| 1 日の公開 | 8 件 | `daily_limit` |
| 1 日の削除 | 5 件 | `retract_limit` |
| 急な連投 | 10 分に 3 件（公開と削除の合計） | **口座が止まります**（`account_stopped: burst`） |
| 夜間 | 22:00〜07:00 | 今すぐの公開は `quiet_hours` |

止まった口座は、LLM からは戻せません。あなたが `https://thth.me/activity` で戻します（4 節）。

### 承認ページを使いたいとき

一件ずつ自分の目で見てから出したい人、他人に下書きを任せる人は、承認ページを使えます。
`thth_settings`（LLM から）か `https://thth.me/activity` で承認のしかたを変えます。承認を外す向き（`all` → `none` など）は `/activity` からだけです。

| 値 | 意味 |
|---|---|
| `none`（既定） | 承認ページを使わない |
| `publish` | 公開だけ承認ページを通す |
| `all` | 公開も削除も承認ページを通す |

承認ページを通すときは、LLM が承認を求めると `https://thth.me/pending` に承認待ちが並びます。
口座名と secret で入り、「開く」で本文を確かめて、secret を入れて承認します。
ページは開いてから 10 分で切れます（一覧から開き直せます）。一覧に出た承認は最大 24 時間待ちます。

## 4. 見る・止める（`https://thth.me/activity`）

口座名と secret（パスワード管理が入れてくれます）で入ると、あなたの口座で出たもの・消したもの・予約・止まった理由が新しい順に並びます。

ここでできること（どれも secret で確かめます）:

- 口座を止める（LLM がおかしいと思ったらすぐ）。
- 止まった口座を戻す。
- 猶予中・予約中の投稿を取り消す。
- LLM に渡した鍵（MCP の資格）を発行し直す・取り消す。取り消した鍵は、すぐ使えなくなります。
- 承認のしかたと安全装置の数値を変える（緩める向きはここからだけ）。

secret を 5 回続けて間違えると、入口は 15 分閉じます。15 分たてば自然に戻ります。

## 5. やめるとき

masaru に「やめます」と伝えるだけです。
masaru がサーバ側で停止し、あなたのアカウントのデータを消します。
Threads の接続解除は、あなた自身の Threads の設定（アカウント → ウェブサイトのアクセス許可）で行ってください。

## 6. 断られ方

断りは静的な符丁で返ります。文面を読み替える必要はありません。

| 符丁 | 意味 | すること |
|---|---|---|
| `too_soon` / `daily_limit` / `retract_limit` / `quiet_hours` | 安全装置 | 添えられた時刻まで待つか、数値を変える |
| `account_stopped: burst` | 急な連投で口座が止まった | `thth.me/activity` で中身を確かめてから戻す |
| `schedule_unavailable` | 口座に予約の timer が無い | 今すぐ出すか、masaru に timer を頼む |
| `invalid_draft: hashtags_disabled_by_ledger` | 台帳がハッシュタグを禁じているのに本文に `#` がある | `#` を外して置き直す |
| `draft_not_editable` | 承認済みの原稿は凍る | 直さずに、新しい下書きを作る |
| `account_leaving` | 退出処理の最中 | 待つ |

## 7. 約束しないこと

- 公開したあとに媒体側で起きることは戻せません。
- 承認 secret は passkey ではありません。phishing 耐性は同じではありません。
- 承認ページの本文は論理的に消しますが、Cloudflare の SQLite Durable Object には最大 30 日の復元期間があります。物理的に消えたことは保証しません。
- 見えなかった添付は承認されていません（承認ページを使うとき）。
- 媒体そのものの退会やアカウント削除は、あなたの媒体の設定で行ってください。

招待する側の手順は `docs/運用_招待する側.md` にあります。
