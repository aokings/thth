## 決める前に masaru に伺うこと

- **⑤ の記録の置き場**: 推しは「承認の記録を VM の台帳（state）に持ち、利用者の repo には積まない」。代わりの案は「別の枝（`thth/records`）に積む」。前者は repo に記録が残らない（今は repo の commit が承認の証拠の 1 つ）、後者は枝が 1 本増え、利用者の repo の設定（保護・push 先）に触る。契約（利用者の repo に何を書くか）が変わるので、作る前に伺う。

## 版の出し方

各版とも、書き手（Opus・worktree）→ 手元の全件 → 柵を壊して赤 → main → CI → `hub approve ask` → 承認で release と tag。
