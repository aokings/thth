# 監査: 媒体の公式 API にあって THTH に無い口（2026-11-06）

THTH開発 第13 が Fable に頼んだ監査（読むだけ）。masaru 11/06「Threads の広告のような漏れが他にもないか」。repo のコードと docs を読み、媒体の公式の頁を 11/06 に読んだ（本物の API は叩いていない）。Bluesky は公式の HTTP reference が空で返ったので、`bluesky-social/atproto` の lexicon の一覧で代えた。

## 2. 漏れでないもの

| 媒体 | 口 | 理由 |
|---|---|---|
| Threads | いいね・投稿ごとのフォロー数・投稿の編集 | API に無い |
| X | 引用 | Enterprise だけ（pay-per-use に無い） |
| X | DM・フォロー・ブロック・Spaces・他人の数 | 設計 2026-10-08 の「しないこと」 |
| Bluesky | 表示数・投票・DM | protocol に無い／公開の投稿だけの方針 |
| Mastodon | 媒体側の予約・非公開の投稿 | THTH が自分で予約する／意図して断る |
| IG・FB | リール・ストーリーズ | 設計_MetaAPIを使い倒す計画 で後回し・やらない |
| はてなブログ | preview・scheduled・custom-url・固定ページ | 設計 S2 で意図して外した |
| フォトライフ | DELETE・PUT | 意図して作らない |
