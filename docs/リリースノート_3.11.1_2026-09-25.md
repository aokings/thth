# リリースノート 3.11.1 （observe に --counts-only と --no-world）

2026-09-25。材料: `docs/回答_media-hub_observeを毎朝読む件_2026-09-25.md` の 5（media-hub が毎朝
`thth observe <project> --json --no-mark` を VM の中に溜めて読みたいという相談への回答）。

版を 3.11.1 に上げた。Worker は変えていない。
`thth observe`（別名 `thth morning`）に足しただけで、既存の呼び方・出力は変えていない
（両方とも既定 false）。

## hub 向け: 呼び方は 1 行

```
thth observe <project> --json --no-mark --counts-only --no-world
```

これで本人・他人を問わず本文と個人を識別できる情報を一切含まない、数と状態だけの
1 枚が返る。世間の段（監視語の検索）は呼ばれない（API を叩くのは言及などだけになり、
検索の実行記録も残らない）。

## 何が変わったか

1. **`--no-world`**: 第 3 段（世間・監視語の検索）を一切呼ばない。`cannot_say:
   "world_skipped"` になる（`REASONS` に 7 語目として追加・失敗ではなく意図した
   見送り）。`where_cli.answer()` 自体を呼ばないので、`calls` に検索が出ず、
   `where` の実行記録（VM の `state/<account>/runs-YYYY-MM.ndjson`）も書かれない。
   言及などそれ以外の段は今までどおり動く。
2. **`--counts-only`**: 仕上がった 6 段から他人の情報と本文を落とし、数と状態だけに
   する（`morning._apply_counts_only()`）。JSON に `"counts_only": true`。
   - 落とすもの: 本文の先頭（`preview`・`head`）・報告と広場の書き込みの `title`
     （本文部分）・`permalink`・`author_key`・`reply_id`・`post_id`（数えるのには
     使うが出さない）・世間の段の「絡みに行く先」（`targets`）。
   - 残すもの: 各段の件数・分母（`n`／`denominator`）・昨日の投稿の主な指標の中央値
     と n（`metrics_median`）・予定の本数・確定待ち／保留の数と理由コード
     （`by_reason`／`by_category`）・inflight の理由コード・報告と広場の新着の数・
     `cannot_say`・`calls`。
   - 「次の一手」は候補そのものが `post_id`・`permalink`・file を運ぶので、件数
     `n` だけ残し候補（`steps`）は空にする。
   - text の表示（`--json` を付けない人向けの 1 枚）も同じ落とし方——`--json` の
     有無に関わらず効く。
3. **CLI**: `thth observe`／`thth morning` に `--no-world`・`--counts-only` を
   任意引数として追加（`--no-mark` の振る舞いは変えていない）。
4. **MCP**: `thth_observe`／`thth_morning` の `inputSchema` に同じ 2 つの boolean
   （`no_world`・`counts_only`）を任意で追加。既定はどちらも false。

## 確かめたこと

- 意味試験: `tests/test_v3111_observe_no_world.py`（9 件）・
  `tests/test_v3111_observe_counts_only.py`（14 件）。CLI・MCP（`validate_arguments`・
  `call_tool`）・人向けの 1 枚（text）まで確認。
- leak probe（`--counts-only`）: 出力の JSON を全部たどって `permalink`・
  `author_key`・`preview`・`head`・`post_id`・`reply_id`・`targets` の鍵が 1 つも
  無いこと、本文の全文・permalink の形・`author_key` の値そのものが文字列として
  出てこないことを確認。
- 単変異 2 本:
  - `--no-world`: 世間を呼ばない分岐を無効化（`if no_world:` → 常に false 相当）
    すると 9 件中 6 件が落ち、戻して byte 一致を確認。
  - `--counts-only`: 返信・言及の `items`（`permalink`・`author_key` を含む）を
    落とさないよう改変すると 14 件中 4 件（leak probe を含む）が落ち、戻して
    byte 一致を確認。
- 全件 `python -m pytest -q -p no:cacheprovider -n auto`: 7886 passed, 1 skipped
  （既存の 1 件・本変更と無関係）。
