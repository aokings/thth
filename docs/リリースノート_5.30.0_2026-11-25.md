# THTH 5.30.0（2026-11-25）

週ごとの振り返り（PDCA）の材料を、THTH が 1 回で渡す版です。運用の依頼（`docs/依頼_THTH開発_週次の振り返りの材料とskill_2026-11-25.md`・masaru 11/25「pdca を週次で回すスキル……材料を機械として thth が渡せるように」）から作りました。きっかけは、Threads の関東とこぴちゃが落ち込んだのに、どこからも相談が上がらなかったことです。危ない領域には触れていません。Worker（`callback/`）は変わりません。

| 件 | 中身 |
|---|---|
| `thth review weekly <口座\|project> [--week YYYY-MM-DD] [--json]` | 週の合計を前の 2〜4 週と並べ、1 本あたりの中央値と最大、当たりと外れの 5 本、層ごとの中央値、先週の宣言の結果を 1 つの束で出します。原因と次の手は出しません（決めるのは読む人です） |
| 落ち込みの印 | 表示かフォロワーの増えが前の 2 週の平均の半分を切ると `drop: true`、続いた週の数を `drop_streak` で出します。口座・シリーズ（札の無い原稿は「未分類」）・糸（キャンペーン）の 3 つの単位それぞれに付けます。閉じた糸は印の代わりに、宣言した段と結果を並べます。`scenario seeds` も同じ束に入ります |
| 数えない物 | 24 時間に満たない投稿と、数が採れていない投稿は 0 と数えず、別に並べます |
| `thth study add … --since YYYY-MM-DD --hypothesis … --change …` | 「この日からここを変えた」を期間で宣言できます。今までの投稿の id の列の形も残ります |
| skill `thth-weekly-review` | 回し方です。シリーズの輪は毎週、糸の輪は閉じたときに仮説と結果を照らして次の種を選びます。落ち込みの印が立ったら、その週のうちに伝えます |
| 断り | `review_target_unknown`・`review_week_invalid`（なぜ・通すには・もっと良く） |

本番の台帳で読むだけで確かめた結果: 11/16 の週は、asmon-kanto-threads が表示 7,526（前の 2 週の平均の 0.214 倍）とフォロワー +5（0.27 倍）で印が立ち、kopicha-threads が 626（0.322 倍）で 3 週続きでした。
