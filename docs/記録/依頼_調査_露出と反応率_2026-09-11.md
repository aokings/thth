# 依頼: Threads の露出と反応率について、独立に調べて報告してほしい — 2026-09-11

宛先: Codex
依頼者: masaru
書いた者: claude（THTH 開発セッション）

**これは検収の依頼ではありません。調査の依頼です。**

**先に断っておきます。この依頼を書くにあたって、こちらでは意図的に調査を
していません。** 先に集めると、こちらの当たりに合わせた報告になってしまうので。
**あなたが独立に引いたものを見たい。**

## 1. 何を知りたいか

THTH は 4 つの Threads アカウントへ予約投稿を出し、投稿ごとの数
（views・likes・replies・reposts・quotes、アカウント単位で clicks・followers_count）を
**公開からの経過時間 1h / 6h / 24h / 72h / 168h の刻み**で採って台帳に残しています。

いま知りたいのは、ざっくり言えばこれです。

> **露出（おすすめへの出方）は、何によって決まっていると考えられているか。
> そのうち、うちの台帳で確かめられるものはどれか。**

ただし**「こうすると伸びます」という助言は要りません。** 欲しいのは
**出所と日付と根拠の質が付いた地図**です。

## 2. 3 つの層を分けて報告してほしい

**混ぜられると、こちらで使えません。** 層ごとに分けてください。

### L1 公式（Meta 自身が書いているもの）

Transparency Center・開発者ドキュメント・DSA 等の規制対応で出している説明・
公式ブログ・Mosseri 等の公式アカウントの発言。**それぞれに更新日を付けてください。**

**こちらで既に 2 件記録しています**（`docs/資料_Meta公式_2026-09-11.md`）。
ランキングの説明と Insights API の定義です。**その文書を読んで、こちらの読み方が
間違っているところを指摘してください。** 同じものを読み直す必要はありませんが、
**こちらが見落としている一次資料**（API の更新履歴・規制対応の開示・仕様変更の
告知など）があれば、それが一番ほしいものです。

### L3 第三者の実測（数字が付いているもの）

誰かが実際に数えた結果。**必ず添えてほしいのは、何本を・いつ・どのくらいの規模の
アカウントで測ったか**です。n が書いていないものは L3 に入れないでください。


## 2.5 日本語圏と英語圏の両方を見てほしい（masaru 指示 2026-09-11）

**L3・L4 は、日本語圏と英語圏を分けて報告してください。**

- うちの 4 アカウントは**日本語で投稿している**ので、日本語圏で言われていることの
  ほうが、読者層と場の混み具合には近いはずです。
- 一方、**英語圏のほうが数字を出す人が多い**（n の付いた実測が見つかりやすい）
  と予想しています。**これも予想であって、確かめていません。**
- **両方で言われていることと、片方だけで言われていること**を分けてください。
  片方だけのものは、**その言語圏の運用事情（投稿時間帯・競合の厚さ・
  media 別の慣習）に依存している**可能性があります。
- 食い違っている場合は、**どちらが正しいかを決める必要はありません。**
  「食い違っている」という事実のほうが、こちらには使えます。

### L4 通説（いわゆる考察班の多数派）

数字の裏付けなしに広く言われていること。**これも価値があります**——理由は 2 つ。

1. 仮説の供給源になる
2. **正しいかどうかに関わらず、実在の効果を持つ。** 「この時間帯が伸びる」と
   皆が信じれば、その時間帯に投稿が集中して**場が実際に変わる**

ですから、**何が言われているか**だけでなく、**どれくらい広く言われているか**、
**いつ頃からか**、**元をたどると誰の 1 件の記事なのか**を書いてください。
「みんなが言っている」が 1 人の孫引きだった、は普通に起こります。

## 3. 分けてほしいこと

- **公式が言っていること**と、**公式の記述から人が推論したこと**を混ぜない。
- **予測（相手のモデルが何を当てようとしているか）**と、**報酬（それが露出に
  どう効くか）**を混ぜない。前者は公式に書いてあっても、後者は書かれていない
  ことが多いはずです。
- **古い話と新しい話を混ぜない。** 相手の仕組みは変わります。**いつ時点の話かを
  落とさないでください。**

## 4. こちらの条件（これが一番大事です）

**うちの母数は小さい。** 公開実績は 6〜7 本、フォロワーは 4 人、返信は今日
初めて 1 件付いたところです。**「1 日 1 本に絞れ」のような運用助言は、
検証できる母数が無い**ので、そのまま受け取れません。

そこで、**調べたことのうち、うちの台帳で確かめられる形に翻訳できるものを、
次の形で書いてほしい**です。

- **主張**（何が言われているか）
- **出所と日付**（L1 / L3 / L4 のどれか）
- **うちの台帳でどう見えるはずか**（views・likes・replies・clicks・followers_count と、
  1h/6h/24h/72h/168h の刻みだけで書けること）
- **何が観測されたら、その主張を捨てるか**（反証条件）
- **必要な本数**（何本たまれば判断できるか。**いまの 6〜7 本で言えるのかどうか**）

**翻訳できないものは「翻訳できない」と書いてください。** たとえば「外回りの
リプライが効く」は、THTH に他人へ返信する機能が無いので、いまのうちでは
検証できません。**そういうものを捨てずに、「検証不能」として残したい**ので、
理由ごと書いてください。

## 5. 見えている制限（こちらから先に出しておきます）

`docs/資料_Meta公式_2026-09-11.md` に書いたとおり、公式ドキュメントの記述として:

- 投稿単位の指標は **lifetime（累計）** で、刻みは累計のスナップショット
- **`clicks` は投稿単位では取れない**（アカウント単位のみ）
- **入れ子の返信の指標は取れない**（連投の 2 段目以降が見えない可能性・未確認）

**この 3 つがあると成立しない主張**が、通説の中にあるはずです。そこを指摘して
もらえると助かります。

## 6. 形式

- **「〜によると」で終わらせないでください。** 誰が・いつ・何を根拠に言ったか。
- **見つからなかったことは「見つからなかった」と書いてください。** 網羅を装うより
  そのほうが使えます。
- **あなた自身の推測**は、そう明記したうえで書いてください。**歓迎します**——
  ただし出所つきの事実と混ぜないでください。

この報告は、こちらで**仮説の棚**（`proposed → shadow → accepted` の記録）へ
登録します。**登録した仮説を反証するのは、引き続きあなたにお願いしたい**ので、
「これは自分が立てた仮説だから」と手加減しないでください。
