# 依頼: kopicha.org の AdSense の不合格（有用性の低いコンテンツ）を見てほしい（2026-11-16）

- 書いた者: THTH開発 第19
- 宛て: こぴちゃ 第12（masaru 11/16「こぴちゃに話聞いてもらえますか」）
- 決めるのは: こぴちゃ 第12 と masaru（サイトの中身はこぴちゃのレーンの持ち物。THTH は直さない）

## 1. 何が起きたか

- AdSense に kopicha.org で 11/07 に申し込んだ（THTH で AdSense の数字を読む機能のための申請。THTH の申し送り 第13 の ④）。
- 11/16 に masaru が画面を共有した。状態は「サイトは広告を表示できない状態です」。理由は「ポリシー違反が見つかりました — 有用性の低いコンテンツ」。所有権の確認は済んでいる。
- Google が並べた確かめの 3 点（画面の要約）: 信頼できる情報・道具・サービスを出しているか／継続的なキュレーションとサイトの手入れがあるか／利用者の関心を集めて保っているか。
- 画面の下に「問題を修正しました」の印と「審査をリクエスト」がある。**まだ押していない。**

## 2. 外から読んで分かったこと（11/16・curl で読んだだけ）

- `robots.txt` のサイトマップは 3 本。`sitemap-items.xml` が 2,467 頁、`sitemap-shops.xml` が 53 頁、`sitemap-index.xml` の先の `sitemap-0.xml` が 270 頁。合わせて約 2,800 頁。
- 商品の頁を間隔をあけて 4 枚開いた（`/items/amsu/004108da/`・`/items/kurasu/8ca9e9d2/`・`/items/ogawa/d5f03f14/`・`/items/silverpot/74b65bba/`）。どれも同じ型に数字を流し込んだ頁で、中身は値段の表・100g あたり・相場の中での位置・「観測開始から価格の変化はありません」。本文は 1,700〜2,300 字で、ほぼ表と定型の文。robots の meta は無い（検索に出す扱い）。

## 3. THTH開発 の見立て（推測を含む）

- Google はどの頁が理由かを言わない。ただ「よその店の値段を集めた型の頁が数千枚・人の書いた中身が少ない」は、AdSense がいちばん落としやすい形と考える。
- 直す向きの案（決めるのはこぴちゃ）:
  1. 人が読んで価値の分かる頁（読み物・選び方・比べた結果の解説など）を前に出す。
  2. 型だけの商品頁は、まとめるか noindex で数を絞る（値段の変化が無い頁・品切れの頁から）。サイトマップの点検は media-hub の `sitemap_check.py`（SKILL sitemap-check）が使える。
  3. 直しが済んでから「審査をリクエスト」を押す。直さずに出し直すと同じ理由で落ち、待ちが延びることが多い。

- この件を受けて、こぴちゃとしての見立てと直すかどうかを masaru と決めてほしい。
- 決まったら THTH開発 へ 1 行（hub msg）。THTH の側は、審査が通るまで作る物は無い（通ったら AdSense の報告の受け口を作る）。
