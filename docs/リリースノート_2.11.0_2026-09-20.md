# THTH 2.11.0 リリースノート（masaru と、招待されたセッション向け）

2026-09-20。VM の `thth` は 2.11.0、thth.me には認可の預かり所（Cloudflare Durable Object）と新しいプライバシーポリシー（施行 2026-09-20）が配布済みです。設計は `docs/設計_2.11.0_秘密を人が触らないauth_2026-09-20.md`、手順は `docs/導入_承認を押すだけ.md`。

## 一言で

**トークンを人が運ばなくなりました。** masaru がサーバで `thth auth <account> --by masaru` を打つと URL が 1 行出ます。利用者はそれをスマホで開いて承認を押すだけ。承認コードは thth.me の預かり所が最長 5 分だけ預かり、VM が 1 回だけ取りに行き、VM が媒体からトークンを受け取って 600 のファイルに保存します。人も LLM もトークンの値を見ません。

## 媒体ごと

- **Threads**: 既存の `thth auth` が預かり所を使うようになりました。預かり所が使えないときは従来どおり戻り URL を貼ります（`--paste` で最初から貼る経路）。
- **Mastodon**: `thth auth` が instance ごとにアプリを自動登録し（人はアプリを作らない）、PKCE（S256）で認可します。要る scope（`read:accounts read:statuses read:search read:notifications write:statuses`）は道具が要求するので足し忘れが起きません。scope が揃わなければ保存しません。
- **X**: 認可だけ対応（投稿・採集の adapter は次の設計）。masaru が X の開発者ポータルで作った confidential client を `thth app set x --by masaru --stdin` で入れ、`thth auth <account> --by masaru` で認可します。access token は短命で、`maintain` が refresh します。
- **Bluesky**: OAuth はまだです。アプリパスワードを秘密管理ツールから `thth token set <account> --stdin --by masaru` で流します（identifier は台帳の handle・`createSession` で本人照合・JWT は保存しない）。

## 管理者に見えるもの

- `thth app set` は `--by` 必須で、変更ログに `app_set`（client の有無だけ・値なし）が残ります。Mastodon の自動登録も同じ記録です。
- `thth admin tokens` と `doctor` に `auth_via`（`relay`／`paste`／`token_set`）と `auth_observed_at` が出ます。
- `thth auth <account> --by masaru --rehearse` は何も保存せず、預かり所を空で待つ経路だけを試します。

## 変わらないこと

承認の 2 段・digest・`--production`・読む口が SNS 台帳に書かない規律。認可が成功しても `production` は自動で true になりません。
