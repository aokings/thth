# 調べ: 日本の広告の API と、THTH がまだ扱わない媒体（2026-11-06）

THTH開発 第13 が Opus に頼んだ調べもの（読むだけ）。確かめた深さ: 「原文」＝公式の頁を読んだ、「二次」＝第三者の記事や検索の要約だけ、「未確認」。本番の API は叩いていない。

## 価値の見立て（高い順）

| 順 | 媒体 | 何ができる | 審査の重さ | 大きさ | 価値の理由 |
|---|---|---|---|---|---|
| 1 | LINE 公式アカウント（Messaging API） | 配信（一斉・絞り込み）と配信の数・友だちの数 | 軽い（API の審査の記述なし・通数でお金） | 中 | 日本で 92.9% が使う。読者に届ける力が最も大きい |
| 2 | YouTube（Data・Analytics） | 動画の投稿と再生の数・収益 | 中（Google の OAuth の確認・重さは未確認） | 中〜大 | 81.5% が使う。運営と収益の両方 |
| 3 | LINEヤフー広告 API（検索・ディスプレイ） | 広告の作成・変更・報告 | 中（法人のビジネス ID・日数は未確認） | 大 | 日本の出稿の柱。LINE 広告も統合済み（二次） |
| 4 | X Ads API | 広告の作成（PAUSED で作れる）と報告 | 軽い〜中（最大 3 営業日） | 中 | X はもう扱っている。日本で 44.7% |
| 5 | TikTok（投稿・広告） | 動画の投稿・数・広告 | 重い（監査まで非公開） | 大 | 伸びているが審査が重い |

## A. 広告

- **LINEヤフー広告 API**（旧 Yahoo!広告 API・原文 https://ads-developers.yahoo.co.jp/ja/ads-api/ ）
  - 法人管理権限のビジネス ID で申し込み・約款に同意・アプリを登録・運用権限のビジネス ID で認可（原文: https://www.lycbiz.com/jp/column/ly-ads/service-information/20230403/ ）。権限は企業単位・無料。個人で取れるかは未確認（取れない見込み・推測）。
  - 書く口 CampaignService・AdGroupAdService など、読む口 ReportDefinitionService。入金の口は無い。PAUSED で作れるかは未確認。
  - OAuth は認可コードフロー。JSON・OpenAPI の定義あり（urllib で呼べる）。版は年 3〜4 回（v21 が 2026-10-21）。作ったアプリを第三者に提供してよい。
  - 旧 LINE 広告 API は新規の受付が 2025-12-25 に終了（原文: https://www.lycbiz.com/jp/manual/line-ads/other_011 ）。2026-04-01 にディスプレイ広告へ統合（二次）。
- **X Ads API**（原文 https://docs.x.com/x-ads-api/introduction.md ）: アプリごとに申請・審査は最大 3 営業日。`entity_status` に ACTIVE・DRAFT・PAUSED。今の版 v12・移行期間 6 か月。OAuth 1.0a（依存なしで書ける）。sandbox あり。他人の口座の規約は未確認。
- **Microsoft 広告 API v13**（原文 https://learn.microsoft.com/en-us/advertising/guides/get-started ）: developer token 1 本で他人の口座も扱える。SOAP の終了 2027-01-31 は二次。日本では 2022-05 から直接買える。
- **TikTok Marketing API**: 公式の頁が読めず、すべて二次。

## B. まだ扱わない媒体

- **LINE 公式アカウント**（原文 https://developers.line.biz/ja/reference/messaging-api/ ）: reply・push・multicast・narrowcast・broadcast と insight（配信数・友だち数・属性・メッセージごとの反応）。料金は月 0 円で 200 通／5,000 円で 5,000 通／15,000 円で 30,000 通＋従量（原文: https://www.lycbiz.com/jp/service/line-official-account/plan/ ）。
- **YouTube**（原文 https://developers.google.com/youtube/v3/docs/videos/insert ）: videos.insert（1 日 100 回の枠）。確認していない project から上げた動画も非公開に制限されない、と今の頁にある。Analytics と Reporting の API あり。収益のスコープと OAuth の確認の重さは未確認。
- **TikTok**（原文 https://developers.tiktok.com/doc/content-posting-api-get-started ）: Direct Post（`video.publish`）は監査を通るまで非公開に制限。Display API で一覧。
- **note**: 一般向けの公式の投稿 API は無い（二次）。前の調べは [調べ_noteの代わりのAPIのある読み物の場_2026-10-20.md](調べ_noteの代わりのAPIのある読み物の場_2026-10-20.md)。
- **Pinterest**: Trial のピンは本人にしか見えない。Standard は画面の動画で審査（検索の要約）。
- **LinkedIn**: Community Management API は会社の Page と domain の確認・画面の動画。開発者アプリに載せる唯一の製品でなければならない（検索の要約）。

## 分からなかったこと
