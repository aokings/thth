## 設計から外れた点・解釈した点

1. **言えない理由を 2 つ足した**（`link_unrecorded`・`nearby_link_unrecorded`）。段のリンク先を控える前の連投（実行記録は本文を持たない）と THTH を通していない投稿は、そのリンク先が分からない（裁定 1 で、3.7.0 からの連投は段の `link_urls` で分かるようになった）。自分のリンク先が記録に無ければ `link_unrecorded`、前後 72 時間にリンク先の分からない投稿があれば「共有でない」と言えないので `nearby_link_unrecorded`（共有と決めつけて `url_shared_72h` とは言わない）。値の側の欠け（`window_open`・`daily_missing`・`clicks_by_url_unavailable`）も分けた。
2. **「前後 72 時間」だけで共有を判定**。2 本の 3 暦日の窓が重なるのは投稿日の差が 2 日以内のときで、そのとき時刻の差は必ず 72 時間未満——窓の重なりは取りこぼさない（`click_attribution` の docstring (b)）。
3. **プロフィールのリンクは台帳の任意項目 `profile_links`**（http(s) の URL・5 つまで・loader が形を検査）。道具はプロフィールを読みに行かない。書いていない account ではプロフィールのリンクを見分けられない。
4. **sent に `link_urls` を足した**（添付の link の `url`・text 添付の `link`。添付がある公開では空でも書く）。本文の URL は従前どおり `text` から読む。3.7.0 より前の記録で添付に link・text があるものは `link_unrecorded`。連投の段は裁定 1 で実行記録に `link_urls`（こちらは本文の URL も含む——実行記録は本文を持たないため）。
5. 1 本に複数のリンク先があれば、プロフィールのリンクを除いた全部の和。どれか 1 つでも共有なら投稿ごと `url_shared_72h`。
6. `--by goal` の click は `per_post` を null から要約（clicks_72h とクリック率の中央値・分母・理由ごとの本数）に、`cannot_say` を「投稿のうち言えなかった理由の一覧」に変えた。投稿ごとの結果は `posts`。1 本だけの日の日次の並べ方は従前どおり（観察の差）。
7. lint の知らせは同じ queue の置き場の単発の原稿だけを見る（束は段ごとの本文をここでは割らない）。時刻は `posted_at`、無ければ `publish_at`。
8. 週の表は月曜始まり（JST）。followers の増分は「前週の日曜の値」と「週の最終日（途中の週は昨日）の値」の差（account 日次は閉じた日の終わりの数なので、前週の日曜の値が週初の時点）。本数は実測の台帳の投稿（根と返信）。MCP には出していない。
9. B1 で held（承認済みで予定時刻を過ぎて出られない）を `thth account` に出すようにした。最初は「run を止めるもの」に入れたが、**裁定 2 で別の段**「出られない原稿（held）n 本: 名前」に移した（account は「投稿できます」のまま・数は board の `held_count` と一致）。遅れているだけの repo の `unverified_content` は held に数えない（次の run が取り込めば解ける）。
10. B2 の `since` は observe の節で `collection_stale_since` と呼んだ（同じ節に `window.since` があるため）。「最後に試した時刻」は台帳に残らないので言えない——text は「最後に取得できた（0 件を含む）のは…」と書き、失敗した試行を数えていないことを添えた。
11. B3 の控えの鍵は repo 内の相対パス。「本文の変更」は原稿ファイル全体の sha256 で見る（front-matter の変更でも外れる）。読み手は合わない控えを無視し、次の 1 段目で掃除する。3 時間は「publish_at まで 3 時間未満（過ぎたものを含む）」。運用通知は `notice` の状態で符丁 `confirm_due: n`・件名「承認の確定待ち」。1 段目は原稿を書き換えないが、state に控えを書くようになった。
12. B4 の読み替えは台帳の `queue_dir` がパスの途中に現れるときだけ。VM 側の古さは読み替えたときだけ `behind_remote()`（fetch する）で確かめる。切り出せたが VM に無ければ push と `thth pull` の案内で断る。MCP の lint は変えていない。
13. C の 3 つは CLI だけ（MCP `where_to_appear` には足していない）。`--aggregate` は tag の観測・自分の履歴・`you_and_them` を作らない。1 日あたりは `n / max(期間の日数, 1)`。`zero_or_filtered` は媒体が 0 件を返したときだけ（手元の絞りで 0 件になったときは付けない）。
