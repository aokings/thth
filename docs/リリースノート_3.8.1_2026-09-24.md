# リリースノート 3.8.1（広場の組の既定と案内）

2026-09-24。材料の報告: **r20260924-cde34fdc**。

版を 3.8.1 に上げた。Worker（`callback/`）は変えていない。

## 何が変わったか

1. **`thth plaza post`（CLI）と MCP `thth_plaza_post` の既定の見える範囲**: project が
   管理者登録済みの持ち主の組に入っていれば、visibility を省略したときの既定を owner
   にした（組が無い project は従前どおり project）。open は決して既定にしない（従前どおり
   `--open` の明示と二段確認だけ）。明示の `--owner`／MCP の `visibility` があれば
   それに従う。既定で owner にしたときは、応答の `visibility_default` に組の名前が入り、
   CLI の人向け応答に「範囲: owner（組 <名前> の既定）」を添える。
2. **`thth plaza list` の案内文**: 組が登録されていて（必要な参加もそろっていて）、組の
   他の project からの owner 範囲の書き込みがまだ 0 件のとき、これまでは何も言わなかった
   （「組の登録を頼んで」の案内と区別が付きにくかった）。管理者に頼めることは無いので、
   「組（<名前>）の他の project の書き込みは owner 範囲にしたものだけ見えます。まだ 0
   件です」とだけ言うようにした。組が無いとき・参加が要るときの案内は従前どおり変えて
   いない。

## 変えたファイル

- `thth/plaza.py`: `post()` の visibility 既定ロジック（`visibility_default` を返す）・
  `_list_hint()` の分岐追加。
- `thth/plaza_cli.py`: `--owner`／`--open` 無しは visibility を明示せずに渡す（既定は
  `plaza.post` に任せる）・人向け応答に「範囲: owner（組 <名前> の既定）」。
- `thth/report_service.py`: MCP の `plaza_post` も visibility 省略時は明示せず渡す。
- `mcp/server.py`: `thth_plaza_post` の説明文と `visibility` の説明を更新。
- `tests/test_v381_plaza_visibility_default.py`（新規）・`tests/test_v380_plaza_owner.py`・
  `tests/test_v380_plaza_moments.py`。
