# リリースノート 4.3.1（止めた口座では timer も返信を出さない）

2026-10-20。masaru 10/20「止めた口座では timer も返信を出さないように直して」。設計は [返信の扱い（4.3）](設計_上限と連投の柵_2026-10-17.md) の「4.3.1 の追記」。

## 直したこと

- 安全装置か持ち主が止めた口座（止めの印 `guard/stopped.json`・`thth account status` で見える）では、**timer も返信を出しません**。4.3.0 では承認の場の送りだけが止めの印を見ていて、timer は止めた口座でも時刻の来た返信を出していました（4.3 より前から同じ）。
- 出さなかった返信は queue に残ります（`publish_at` も指紋も変えない）。`thth account resume <口座> --by <名前>` で戻せば、次の timer で出ます。
- timer の log の 1 行は「返信を 0 本出しました・N 本は口座が止まっているので出していません（戻すのは thth account resume）」と言います。
- 返信の窓が作れず返信を投稿と同じに数える口座でも、返信は外します。
- 止めの印を置けない置き場（モードの緩い置き場など）では、運営者の CLI と同じく印を読みません（印はそこに無い）。

## 変わらないもの

- **投稿は今までどおり、timer は止めの印を見ません**（3.21.0 から。予約の投稿は承認と予約の時に数えている）。止めた口座の予約の投稿も止めるかは別に決めます。
- 承認の指紋・断りの符丁・Worker。Worker の deploy は要りません。
