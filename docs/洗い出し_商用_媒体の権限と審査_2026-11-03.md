# 洗い出し: 商用に出すときの媒体の権限と審査（2026-11-03）

masaru 11/03「洗い出して、今回は足らないものや、漏れがないようにしたいし、将来的につかいそうなものは使ってなくても含めて欲しい」。THTH開発 第11 が Opus の調べ役に頼み（読むだけ・一次資料を WebFetch）、その報告をここに置く。商用の全体（法務・課金・運用ほか）は別の書 `docs/洗い出し_商用_足りないもの_2026-11-03.md`（Fable）。

## 8. 外の人に出す順番（提案・推測を含む）

1. **Threads**（すぐ出せる）: 商用の terms・privacy の改訂（「毎回承認」・料金・保存期間）と、外の人が入る画面（招待 → `/activity`）を審査の時の形で保つ。足すなら Threads の webhook と share_to_instagram（新しく審査）。keyword_search の保存は許可された用途の範囲だけ。
2. **Bluesky・Mastodon**（審査なし）: Bluesky は OAuth に替える。Mastodon はサーバーの bot の規則を利用者が確かめる案内。
3. **FB ページ＋Instagram の App Review**: pages の 8 つと instagram の 6 つ。権限ごとに審査員が手で試せる画面を `/activity` に（ページを選ぶ・書いて出す・消す・コメントと返事・数）と録画。writer 2〜4 日＋判定 1 週間前後。publish_video と Public Content Access は使う機能ができてから。
4. **広告**（最後）: ads_read・ads_management の Advanced と Full Access。まず「利用者が自分で公式の広告 MCP につなぐ」を案内し、THTH は成績を読むだけにする道を推す。
5. **X は保留して照会**: 利用者が自分の X のアプリと鍵を持ち込む（BYO）か、X に照会して Enterprise か承認。BYO を推す。
6. **はてな**: 商用の内容を API で出すには、はてなの特別な許諾。外の人に出す前に問い合わせる。

## 9. 規約の上で危ないところ

| 論点 | 中身 | 深さ |
|---|---|---|
| 代わりに公開するときの同意 | Meta は事前の同意（devpolicy 1.7）。X はログインだけでは同意にならない・出す前に中身を見せる | 一次10/29・一次11/03 |
| 自動投稿 | Meta は一般には禁じない（高頻度 bot・エンゲージメントの売買は禁止）。X は重複・語起点の自動返信・AI 返信 bot が禁止か要承認。はてなは機械的な高頻度ブックマークが禁止 | 一次10/29・repo |
| データの保存期間 | Meta は要らなくなったらすぐ消す（3d）・削除の求め（4b）・90 日の期限。X は 24h 以内に消す | 一次10/29・一次11/03 |
| 別の AI に渡す | X は訓練禁止・第三者には id だけ。Meta は審査で「渡さない」と約束済みで未解放 | repo・一次11/03 |
| 集計・分析 | X は X の集計の数を計算しない。IG 6.2。Meta は人物像の作成・監視を禁止（3a） | 一次11/03・一次10/29 |
| 広告の代理運用 | Tech Provider と Advanced と Full。spend_cap に届くと全配信が止まる。お金の責任の分け方は terms に要る（推測） | 一次11/03 |
| はてなの商用 | API で宣伝・商用の内容を出すには特別な許諾 | repo |
| Bluesky の秘密の預かり | 口座の共有の禁止に近いかは未確認 | 未確認 |
| 権限の放置 | 28〜90 日使わないと止められうる。審査で取った権限を商用化の準備中に眠らせない | 一次10/29 |
