# THTH 5.31.0（2026-11-26）

理由と期限を付けて止めた原稿を、未承認の数えから外す版です（masaru 11/25 の決定・正本は media-hub の設計の書（h2d の要望の発展と設計・11/25）の決めること 6）。試しでわざと止めた原稿が、hub で毎日「未承認・急ぎ」として上がっていました。監査は `docs/監査_5.31.0_2026-11-26.md`（Fable・初め危ない 1 → 直して確かめ直し 危ない 0）。Worker（`callback/`）は変わりません。

| 件 | 中身 |
|---|---|
| `thth hold <原稿\|dir...> --until YYYY-MM-DD --reason "…" --by <名乗り> [--undo] [--json]` | draft を、その日の終わり（JST）まで止めます。期限は今日から 90 日まで、理由は 200 字までです。本文と repo には触らず、VM の `state/<口座>/holds.json` に記録します（承認の台帳とは別のファイルなので、古い版に戻しても承認はそのまま読めます）。承認すると止めは解けます。遠くの道（thth.me）では打てません |
| board の `held_soon` | 口座ごとに `{count, until_min, items:[{path, until, reason}]}` を出し、`unapproved_soon` の count からは止めた分を外します。期限が切れた原稿は、それから 3 日のあいだ未承認に数えます |
| 一段目の知らせ | まとめての `thth approve` で止めた原稿を拾うと「⏸ 止めています」と出します。止め直しは前の期限と理由を並べます |
| 予定の一覧 | `thth schedule`（thth.me の鍵と MCP の一覧も）の行に `held_until`・`held_reason` が出ます |
| 承認の台帳の読み | 知らない state の行があっても台帳ごと倒れず、その行だけ draft として読みます |
