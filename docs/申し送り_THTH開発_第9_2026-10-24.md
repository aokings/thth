## 触ってはいけないもの・決まり

- `CLAUDE.md` のとおり。release の push は `git push origin "${sha}:refs/heads/release"`。試験は rc を見る（パイプを挟まない）。release の前に CI の rc を読む。
- main への push は Claude がしてよい。release の枝・tag・Worker の deploy は、CI 緑のあと masaru の「出して」で押す（`hub approve record --replaces <頼みの番号>` → `hub approve verify` → push → `hub approve close --evidence`）。`hub approve gate` は今の hub に無い。
- **VM の state を書く操作は auto mode に止められうる**（10/23 に 1 回止められ、masaru の許しのあとに通った）。止められたら別の書き方で通さず masaru に聞く。書く前に `cp -a` で控えを取る。
- 共有の作業ツリーで reset・checkout --・stash・commit -a を使わない。`git add` はパスを明示する。同じ checkout で運用のレーンも動く。
- 全件の試験は約 8 分（10003 本）。`run_in_background` で回して終わりを待つ。
- 秘密は `~/.config/thth/`（Mac と VM）。値を出さない。
- `.claude/worktrees/` に書き手（サブエージェント）の worktree が 60 ほど残っている。どれも main に入れ終えたもの。片づけるかは masaru に聞く（消すと戻せない）。`agent-aa3a95a0a4782b9d7` には commit していない下書き `tests/test_v453_probe.py`（中身はコメント 1 行）がある。
