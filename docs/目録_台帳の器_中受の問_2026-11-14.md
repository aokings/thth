## 設計 §1 の読みと今の実物の食い違い

設計 142 行の読み（中受の問）と比べた。読みの骨は実物と合う（頁の頭の `ima`・期限で表を伏せる・行の締切・判定は build の時点・`{{koyomi:…}}`・分かれ道ごとの `konkyo`・`taishou`）。違う所と足りない所:

2. 「表の行ごとの締切も別に見る」は、**頁に `ima` があるときだけ**効く。`ima` の無い 2 枚の 11 行は締切を持っても外れない。
3. 「判定は build の時点」は問いの頁の話。**道具の頁（10 本公開）は見る人の端末で今日と比べて判定**する。器が作る材料の外。
4. 判定が build の時点なので、毎日の build が無いと期限も締切も効かない。毎日の build は推しとして文書にあるが、動いているかは確かめていない。

6. `{{koyomi:…}}` の道は「都県.欄」だけでなく、入れ子と並びの添字を含む（`chiba.kouritsu.0.kensa`）。
