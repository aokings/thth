## 何が変わったか

### 1. X に投稿できるようになりました

2.11 で入れた `thth auth`（PKCE・秘密は人も LLM も触らない）はそのままに、**X が
投稿できる媒体になりました**。

- 本文・返信・画像 4 枚・GIF 1 つ・動画 1 本・投票・返信制限・alt。
- 取り下げ（`thth retract`）と、自分の直近の投稿の一覧（`thth posts`）。
- **引用は出しません。** 公式が「Enterprise プランが要る」と書いており、自己サーブの
  tier では使えないからです。網羅表には
  `unsupported: provider_tier_enterprise_only` と**理由付きで**載せました
  （「API に無い」とは書きません）。

添付の送り方は公式の chunked upload そのままです（`initialize` → `append` →
`finalize` → 処理待ち → alt → 投稿）。**種類は混ぜられません**（画像と動画の同居は
要求を 1 本も出さずに断ります）。画像と GIF の alt は必須、動画の alt は可否が未確認
なので試して、断られたら警告として残します。

### 2. 投稿は「月に何本まで」の中でだけ出ます（既定 0）

X の書込みは tier ごとに月間の上限があります。thth は**自分が出した本数を数え**、
上限に達したら要求を 1 本も出さずに止めます。

```
thth admin budget x-posts --monthly 100 --by masaru
```

**既定は 0 です。入れるまで X には 1 本も出ません**（静的理由
`cannot_say: post_budget_exhausted` ／ 断り `x_post_budget_exhausted`）。読取予算
（USD・2.12）とは別の口です。

結果が分からなかった 1 本は「不明」として枠を使ったまま残り、**自動で投げ直しません**。
429 は待たずに次の run へ回します（reset の数字だけ記録に残します）。

### 3. release の commit に署名できるようになりました

VM の self-update は `git merge --ff-only origin/release` で自分自身を入れ替えます。
`THTH_REQUIRE_SIGNED_RELEASE=1` を入れると、**取り込む前に SSH 署名を確かめ**、
確かめられなければ取り込まずに古いまま走ります（止まりません）。

`thth board` の 1 行目が言い分けます:

- `署名: 未確認`（確かめていない・既定）
- `署名: 確認済み（SHA256:…）`（その鍵で確かめて取り込んだ）
- `署名: 未確認（取り込んでいません）`（配布 commit が無署名）
- `署名: 不正（取り込んでいません）`（鍵か commit が疑わしい・**人を呼んでください**）

手順は `docs/運用_配布_2.14.md` に 1 本にまとめました。**既定は今までどおり検証しません**
（いまの release は無署名なので、無条件に入れると次の配布で VM が古いまま止まります）。

### 4. 細かいところ

- `thth doctor` の添付の対応表に `x` の列が増えました（`thth board --json` の
  `tool.capabilities` と `docs/原稿_添付_2.13.md` の表も同じ 1 本から出ます）。
- X の本文の上限を 140 から **暫定 280 コードポイント**へ。公式に 280 の明記は無く、
  重み付き計数も実測していないので、lint が毎回
  `warning: x_length_weighting_unverified` を添えます（140 は 2017 年より前の数字で、
  いまの本文を不当に断っていました）。
- MCP の `thth_admin_budget_set` に `kind: x_posts` が増えました（管理者のみ・
  `by` 必須・金額の選択肢とは混ぜられません）。

## masaru にお願いすること（この順で）

1. **X の App を作る**（Developer Portal・Free tier で可）
   - callback: `https://thth.me/callback/`
   - User authentication settings: **Read and write**・Type: **Web App**
   - 追加された scope `media.write` を含む同意が要ります（添付を出すため）。
2. **client を入れる**（値は chat に出さない・tty から）
   ```
   thth app set x --by masaru
   ```
   `client_id` / `client_secret` / `client_type: confidential` /
   `redirect_uri: https://thth.me/callback/` の JSON を標準入力から。
   **`media.write` を足したので、2.11 で入れた client とは別のファイル**に入ります
   （旧ファイルはそのまま残り、本文の投稿は続けられます）。
3. **アカウントを作る**
   ```
   thth account add masaru-x --media x --project <名前> --handle <@なしのユーザー名> --by masaru
   ```
4. **認可する**
   ```
   thth auth masaru-x --by masaru
   ```
   出た URL を開いて承認し、戻り URL を貼ります（30 秒以内）。
5. **月に何本までかを入れる**（入れるまで 1 本も出ません）
   ```
   thth admin budget x-posts --monthly <本数> --by masaru
   ```
   本数は Developer Portal に出ている tier の上限を見て決めてください。

（署名は配布担当の作業です。やるときは `docs/運用_配布_2.14.md` の 1〜4 を順に。）
