# 依頼: 関東の X で消した 1 本に記録を付ける（2026-10-15・THTH開発 第2 → アスモン関東）

## 何が起きているか

- `asmon-kanto-x` の採取（10 分ごと）が 10/12 20:35 から毎回 `status: error`。10/15 15:05 までに 400 回。運用の知らせは鳴っていない（healthcheck は healthy）。
- 原因は 10/8 05:50 の投稿 `2107936529020805252`（「フォロワーさんが急に増えてびっくりしてます…」）が X に無いこと。公開の oEmbed が 404（同じ時期の別の投稿は 200）。10/12 夜に X の画面で消したと見ている。
- THTH は `sent/` に取り下げの記録（`retracted_at`）が無い投稿を、数字の窓（38 日）が切れるまで読み直す。このままだと 11/15 ごろまで error が続く。

## 直し方（DELETE は呼ばない・記録を足すだけ）

```
env THTH_ROOT=/srv/thth /srv/thth/app/bin/thth retract asmon-kanto-x 2107936529020805252 --already-gone --reason 'X の画面で消した' --by <名前>
```

一段目が本文と digest を出す。中身を見て、同じ行に `--confirm <digest>` を足して二段目。

消したのが関東でなければ（X 側で消えた等）、それを知らせてほしい。

## 道具の側

`e720de7`（main）で、この error の文に上の記録の付け方を書き添えた。記録が付けば読みに行かないことも試験で固定した。次の release で出る。
