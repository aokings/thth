# THTH 2.8.0 リリースノート（プロジェクトのセッション向け）

2026-09-19 深夜。VM の `thth` は 2.8.0 になっています（`thth board` の 1 行目で確認できます）。2.7.0 からの変更を、使う側の言葉でまとめます。設計は `docs/設計_2.8.0_タグと話題_BlueskyとMastodon_2026-09-19.md`。

## 一言で

**Bluesky と Mastodon でも `topic:` が効く**ようになりました。原稿の `topic: 個人開発` は、その媒体の流儀（末尾の `#個人開発`・Bluesky は tag facet 付き）で公開されます。Threads の topic の扱いは変わりません。

## 書く側で変わること

- **`topic:` が末尾のタグになる。** 原稿の本文は変えず、公開する本文の末尾に 1 行 `#語` が付きます。本文に同じ `#語` が既にあれば足しません。連投（`thth: 2`）は**先頭の段だけ**に付きます。
- **承認の一段目は「公開される本文」を見せ、指紋もその本文で取る。** 2.8.0 より前に承認した Bluesky／Mastodon の原稿で新たに末尾タグが付くものは `approval_stale` になり、**再承認が要ります**（タグが付かない原稿と Threads の承認はそのまま）。
- **タグの上限は既定 3 個**（末尾に足す分を含む・台帳の `max_hashtags` で変更）。超えると `thth lint` が止めます。
- **語の禁則は媒体ごと。** Bluesky は 64 文字（grapheme）まで・空白と `#` 不可。Mastodon は英数字・`_`・Unicode の文字のみ、数字だけの語は不可。Threads の 50 字上限は他媒体に持ち込みません。
- 台帳が `hashtags: false` のときは付けず、`topic:` があれば警告だけ出します（kopicha・masaru の 4 台帳は `hashtags: true`）。

## 読む側で増えたもの

```bash
thth where <account> <語> --json          # by_tag: その語のタグで人がどれだけ動いているか（24h の件数・投稿者の異なり数・一緒に付くタグ）
thth topics <account> --json              # 同じ by_tag が助言の材料に入る
thth analytics-report <account> --compare-previous --by tag --json   # 自分の投稿を tagged / untagged / unknown / #語 で層別
```

- Bluesky は `searchPosts` の `tag` 検索（複数語は AND・`q` 必須）。ページ数と cursor の有無を出力に添えます。**世間の総数ではなく取れた範囲の数**です。
- Mastodon は**その instance から見える**公開タグタイムライン（`observed_from` に instance 名）・トレンド・候補。他の instance の分は入りません。
- 採集は、投稿に**実際に付いたタグ**を API から読んで記録します（読めなければ `unknown`・空とは区別）。`--by tag` の `unknown` はその印です。

## しないこと

- Bluesky の `unspecced` トレンド API は使いません（存在はするが安定契約ではない）。
- タグを付けても、承認・投稿・台帳の書き換えの規律は変わりません。
