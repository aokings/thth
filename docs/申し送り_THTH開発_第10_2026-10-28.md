## 触ってはいけないもの・決まり

- `CLAUDE.md` のとおり。main への push は可。release・tag・Worker の deploy は CI 緑のあと masaru の「出して」（`hub approve record` → `verify` → push → `close --evidence`）。release の push は `git push origin "${sha}:refs/heads/release"`。
- 試験は rc を見る（パイプを挟まない）。**書き手を並べるときは `-n 4`**（10/28 に 2 体が `-n auto` を同時に回し Mac が load 184。本線から止めるよう頼まれた）。全件は 1 回にまとめる。
- `ssh wt` では `env THTH_ROOT=/srv/thth /srv/thth/app/bin/thth`。VM の state を書く前に `cp -a` で控える。
- git add はパス明示・reset／checkout --／stash／commit -a はしない。BrownHeron（同じ repo の別レーン）は見張らない。
- 秘密は `~/.config/<project>/`。外の AI には「ファイルを変更・削除・commit しない」と書く。
- 片づけ: `.claude/worktrees/` に 5.0 の書き手の worktree が 5 つ残っている（agent-a3a662…・agent-ae03e2…・agent-ad021c…・agent-afdd2e…・ほか）。中身は main に入った。`agent-ad021c2eea8d89778` には書き手が作った追跡外の `.claude/launch.json` がある（rm が権限で止められ、そのまま）。消すかは masaru に確かめてから。
