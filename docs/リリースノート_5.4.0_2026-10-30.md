# リリースノート 5.4.0（Meta 計画 段 4・段 6: 広告を読む・Webhook）

2026-10-30。「Meta API を THTH で使い倒す計画」（[設計_MetaAPIを使い倒す計画_2026-10-29.md](設計_MetaAPIを使い倒す計画_2026-10-29.md)）の段 4 と段 6 です。masaru 10/30「出して」。Worker が先・VM があと。

## 変わったこと（段 4・86b1818: 広告・読むだけ）

- `thth ads accounts|add|auth|doctor|show|insights|collect`。台帳は `adaccounts/<名前>.json`（`ceilings` の既定 0・`ads_enabled: false`・`production: false`）、状態は `adaccount_state/`。
- **Meta に書く命令は 1 つもありません**（命令の一覧・綴り・実際の要求が GET だけであることを試験で縛っています）。上限を上げる命令もありません。上げるのは VM の台帳を直接書くときだけです。
- `thth ads auth`: ユーザーの長い鍵を広告の口座の `.token` に保存。`/me/adaccounts` に台帳の `act_id` が無ければ保存しません。`--exchange` で鍵が延びるかを試せます。
- 金額は最小単位の整数で持ちます。通貨が JPY 以外なら、書く操作を断る印を台帳に残します。
- collect のたびに広告の口座を読み、events 9 種（とくに `ads_active_outside_thth`＝THTH の外で配信が始まった・`ads_spend_cap_unset`＝最後の柵が無い）。maintain・doctor・morning・dashboard に広告の鍵の期限（14 日）。
- IG の doctor に `connected_threads_user`（Threads 広告の下地・読むだけ）。

## 変わったこと（段 6・7afa626: Webhook）

- Worker に受け口 `https://thth.me/webhook/meta`（GET の確認は verify_token、POST は `X-Hub-Signature-256` を app secret で定数時間で照合、不一致は 403、重複は弾く、Durable Object `WEBHOOK_INBOX` に積む・7 日で消す）。Worker の secret は `META_APP_SECRET`・`META_WEBHOOK_VERIFY_TOKEN`。
- VM の `thth worker` が `/relay/v/webhook/meta/{pull,ack}`（署名つき）で 30 秒ごとに取りに来て、`state/<口座>/inbox/` に落とします。知らない id は捨てて数だけ残します。
- `thth webhook subscribe|pull|status`。FB は `feed,mention` を購読。IG は親のページの購読で mentions が届くかを試します（IG の comments は Advanced Access が要るので巡回のまま）。
- `thth replies` に `via: webhook` の行。届いている口座はコメントの巡回の刻みを伸ばします。`thth events` に `webhook_down`。
