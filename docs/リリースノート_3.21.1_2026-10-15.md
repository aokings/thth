# リリースノート 3.21.1（thth.me の鍵の道の send も --production が無ければ出さない）

2026-10-15。

- **thth.me の鍵で動く道（招待の口座）の `thth send` は、`--production` が無ければ出さず、lint だけ通して「出していません。出すなら同じ命令に --production」と言う。** 3.14.0 からこの道は「頼んだらその場で出す」作りで `--production` を読まず、`thth send --help` の「既定は乾式」と食い違っていた。キョンシーラボの口座で試すつもりの本文が本番に出た（#2477）。手元の道と同じ意味に揃えた（masaru「揃えて」）。`--confirm` は要らない。
- MCP の `thth_send_request` は今までどおり呼べば出す（中で `--production` を付けて CLI を呼ぶ）。
- [導入_招待されたら](導入_招待されたら.md) の例を直した。
