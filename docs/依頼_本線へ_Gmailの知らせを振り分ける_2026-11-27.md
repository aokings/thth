# 依頼: 本線が Gmail の知らせを受けて担当へ振り分ける（2026-11-27・THTH開発 第24 → 本線）

- 元: masaru 11/27「本線に繋げば、みんなで使える感じになるのかな。本線が知らせる、みたいな」「うん、本線に送って」
- 位置: 案。受けるか・決まりの形は本線と masaru が決める

## 困りごと

外からの知らせ（審査の返事など）が aokings の Gmail に来る。masaru はメールを見ない（11/05、止まりの知らせの届く先は hub）。今は masaru の転送待ちで、例えば Google ビジネスプロフィール API の審査（ケース 4-3446000042331、目安 11/27〜12/1）の返事に、担当（THTH開発）が気づけない。

## 案

1. masaru が Google 公式の Gmail のコネクタ（claude.ai の connector、`gmailmcp.googleapis.com`）をアカウントに 1 回つなぐ。
2. 受信箱を読むのは本線だけ、という決まりにする（コネクタはどのセッションでも有効にできるので、柵ではなく決まり）。
3. 本線は、決めた差出人・件名・ケース番号に当たるメールだけを読み、担当へ hub msg で回す（要点とメールの日時・件名。全文を写さない）。
4. 読む以外（下書き・転送・返信・フィルタ・ラベル）はしない。要るときは masaru に伺う。
