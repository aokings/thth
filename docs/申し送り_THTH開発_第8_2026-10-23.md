## 触ってはいけないもの・決まり

- `CLAUDE.md` のとおり。release の push は `git push origin "${sha}:refs/heads/release"`。試験は rc を見る（パイプを挟まない）。release の前に CI の rc を読む。
- main への push は Claude がしてよい。release の枝・tag・Worker の deploy は、CI 緑のあと masaru の「出して」で押す。**本線の委任では記録しない**（入口の文書の決まり。10/22 に本線が masaru に聞いて取り直した）。
- 公開の承認は台帳の番号と `--target`・`--what` を ask と同じ書き方にそろえる。長い sha を渡すと `digest_mismatch` になる。
- 共有の作業ツリーで reset・checkout --・stash・commit -a を使わない（ナイトシフト 4）。`git add` はパスを明示する。同じ checkout で運用のレーンも動く。
- 全件の試験は約 10〜15 分かかる。`run_in_background` で回し、終わりは Monitor で待つ（途中で寝ない）。
- 秘密は `~/.config/thth/`（Mac と VM）。値を出さない。
- コミットの署名は、そのときの system-reminder の指定に従う（途中で Opus 5.5 → Sonnet 5.5 に替わった）。
