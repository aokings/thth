# リリースノート 5.1.0（Facebook ページ）

2026-10-29。THTH から Facebook ページに出せるようになりました（masaru 10/28「全メディア FB ページ作る」・本線 #5818）。手順と経緯: [手順_FBページと広告_2026-10-28.md](手順_FBページと広告_2026-10-28.md)（§0-3・§0-4）。

## 変わったこと

- 新しい媒体 `facebook`。1 ページを 1 口座で扱い、台帳の `page_id`（= `handle`）がそのページの id です。
  - 例: `thth account add kopicha-fb --media facebook --project kopicha --handle 1361492233719922 --by <名前>`
  - `--handle` はページの「基本データ → ページの透明性」に出る「ページID」です。ページの URL の `profile.php?id=` の id（人の画面の id）ではありません（10/29 に例を直しました。手順 §0-5）。
- `thth auth <口座>` は Facebook ログイン for Business で認可します。
  - 戻り先は、ほかの媒体と同じ中継 `https://thth.me/callback/` です。
  - 長く使えるユーザーの鍵から、台帳のページの鍵を取ります。**保存するのはページの鍵だけ**です。
  - 許可されたページの中に台帳の id が無いとき、または鍵の指すページが違うときは保存しません。
  - 付いた権限と期限は `/debug_token` で記録します。
- app.env に `META_APP_ID`・`META_APP_SECRET`、任意で `META_LOGIN_CONFIG_ID` を置きます。構成の ID があれば `config_id`、無ければ `scope` で認可の画面を開きます。
  - Threads の 2 行とは別の組です。`thth app set`（Threads）で書き直しても、Meta の行は残ります。
- 口でできること: 文・リンクつきの文・返信・画像 1 枚の投稿、削除、最近の投稿、コメント、数、probe（`thth doctor`）。
  - いいね・シェアは「この媒体ではできない」と断ります。
  - 静かな時間・間隔・日の上限は、SNS の表がそのまま効きます。
