# THTH 5.16.0（2026-11-12）

自分で置く WordPress のサイトに、記事を出す口を足した版です。設計は [設計_ショップとWordPressの口_2026-11-12.md](設計_ショップとWordPressの口_2026-11-12.md) の §5（masaru 11/12「ショッピファイとワードプレスも進めましょう」「推しの通りで OK」）。

## 足したこと

- はてなブログと同じ道（queue の原稿 → 承認の指紋 → 二段の柵 → timer → 記録）で、WordPress の REST（`/wp-json/wp/v2/posts`）に出します。新しい道は作らず、口座の `media: wordpress` と主体の `kind: wordpress` で引きます。
- できるのは、作る・直す・下書きで出す（`send_as: draft`）・公開で出す、まで。予約・消す・アイキャッチ・WordPress.com は後の版です。
- 鍵は WordPress のアプリケーションパスワード。`thth principal auth <主体> --by <名前>` で、端末の隠した入力か `--stdin` の 1 行目だけから受け、`~/.config/thth/<主体>.token`（0600）に置きます。引数では受けません。消すのは `--forget`。
- `whoami`（`/wp/v2/users/me`）で役割を見て、管理者の鍵なら「編集者の利用者を作ってその鍵を」と勧めます（断りません）。
- 本文は Markdown の狭い部分集合（段落・見出し・強調・リンク・箇条書き・コード）だけを HTML にします。本文の見出しは 1 段下げます（`#` は `h2`。WordPress は記事の題を `h1` で出すため）。外れる記法は、黙って字のまま送らずに前向きに断ります。
- 題は、生の HTML の形があれば断り、`<`・`>`・`&` はエスケープして送ります。送る題そのものが承認の指紋に入ります。
- 指紋は `thth-wp-entry-1` を新しく足しました（サイトの入口・公開の状態・予約の時刻・送る題と HTML を含む）。はてなの `thth-hatena-entry-1` は変えていません。
- 外で手直しされた記事は上書きしません（`context=edit` の `content.raw` を読み戻し、初回の読み戻しを基準にする）。
- 1 日の上限は、はてなブログと同じ主体の数え方です。下書きを作るのも 1 回に数えます。
- 断りの目録に `wordpress_*` の符丁を足しました（REST が閉じている・Authorization が落とされる・https でない・セキュリティの部品が止めている、などを分ける。どれも なぜ・通すには・もっと良く の 3 つ）。WordPress の口座で、はてなの直し方の文は出ません。
- 下書きで出した配信は、告知（`announces:`）の先にできません（lint が前向きに断り、timer は待ちにする）。

## はてなブログで変わること

- はてなの原稿に `send_as:` があると、新しく断ります（前は読まずに公開していました）。はてなの口は公開だけです。

## privacy

「Blog articles on WordPress／WordPress の記事」の節を英日に足しました。施行日は 2026-11-12 のままです。`tests/test_privacy_matches_code.py` に柵を足しました。「認証にだけ使う」「転送に付いて行かない」は、崩れうる約束なので書いていません（転送の守りはコードの柵で縛っています）。はてなブログの節は、まだありません。

## 残したこと

- 本物の WordPress のサイトには、まだつないでいません。今の版の変換・鍵の違い・Authorization が落とされる場合の見分けは、偽のサーバでだけ確かめています。
- `thth leave` は、WordPress（とはてなブログ）の口座では最後まで進まない見込みです（`leave.py` の `revoke()` が記事の媒体を扱わない）。privacy にも leave のことは書いていません。次の版で直します。
- 内向きのアドレス（loopback の https・IP アドレスの形のサイト）を断る検査は、まだありません。VM で WordPress の口座を動かす前に足します。
- REST の入口と公開の URL のホストが違うサイトは、1 本めのあと conflict になりえます（doctor での知らせは後の版）。
- `thth principal` の説明の文に「はてな」とだけ書いてある所が残っています。

## 出すときに一緒にすること

- privacy を変えたので、**Worker の deploy が要ります**（`cd callback && npx --no-install wrangler deploy`）。Worker が先、VM があとです。
- Worker → release の枝 → tag `v5.16.0` の順に出します。出したら privacy の頁が 200 で、英日に WordPress の節が出ることを確かめます。
