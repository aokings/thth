# リリースノート 4.2.0（ブックマークの直し・タグの長さの柵・上限の設定の面とフィードバック）

2026-10-18。kopicha の頼み（こぴちゃ 第2・#2947・#2950・masaru の意向）と、上限と連投の柵の設計 [段 3・段 4](設計_上限と連投の柵_2026-10-17.md)。

## ブックマークの直し（`thth bookmark edit`）

- THTH が付けた自分の主体のブックマークの `comment` と `tags` を、2 段の承認で直す: `thth bookmark edit <口座> --url <URL>|--delivery <dl_…> [--comment …] [--tags …]`（1 段目は今の中身と直したあとの差分と digest・2 段目 `--confirm <digest> --by <名前> --production`）。
- はてなの POST は「既にあれば更新」なので、**新しく付けるのとは別の柵**。直せるのは `sent/bm:` に自分の主体の `confirmed` の行がある札だけ（手で付けたもの・別の主体のものは直さない）。付いていないページに送って新規追加になることは、2 段目の「今付いているか」の確かめで止める。日・同じホスト・自分の記事の枠は数えず、連投の窓と安全装置は当てる。結果が分からない直しは打ち直さず、`thth bookmark reconcile` が（はてなに付いていて値が違えば「効いていなかった」・404 なら「効いていなかった」）で解く。直しの履歴は `bm:` の行の `attempts[]`。
- まとめて直す: `thth bookmark batch` の札のファイルに `op: edit` の行（`url`・`comment`・`tags`）。
- 遠くの道（thth.me・MCP）の `bookmark_request` の `op` に edit。

## タグの長さの柵

はてなブックマークのタグは 31 バイトは通り、34 バイトは黙って切られた（kopicha 10/18 の観測）。`bookmark add`・`batch`・`edit` の 1 段目と lint で、31 バイトを超えるタグの札を**予告して断る**（`bookmark_tag_too_long`・どのタグが何バイトか・直す案内）。上限の正確な値（32・33 バイトで通るか）は確かめていない。台帳には観測（確かさ low）として足した。

## 上限と連投の柵（段 3・段 4）

- **台帳の `limits` と今の鍵の別名**: 口座・主体の台帳に柵の表の行の id で数を書ける（`thth account set <口座> post.daily 12`・`thth principal set <主体> bookmark.burst 20 10`）。今の鍵（`daily_max_posts` など）は別名として読み続ける。VM の台帳は何も書き換えずに同じ数で効く。`show` に行ごとの「効く数・使った数・どこから来たか・確かさ」の表。
- **最低線（`write.floor`）**: 持ち主が `--reason` つきで 10 分に 100 件まで上げられる（理由は記録に残り `show` に出る）。
- **断りの文に「根拠」と「通すには」**（ブックマークの断りと thth.me の本文）・承認の 1 段目のブックマークに「見立て」の節・`--json` の `assessment`。`thth media observations`／`observe` で、媒体に断られた・人間か確認、などの観測を集める。
- **まとめて承認の整理**: 終わったまとめのファイルを期限の 7 日後に timer が消す・状態の答えを畳む・止まったまとめと照合待ちの結果不明を `thth board`／`thth morning` に 1 行・**結果不明の札が出たら照合（`reconcile`）まで次の札へ進まない**。

## 変わらないもの

承認の指紋（追加・削除・記事・SNS）・SNS の口座の振る舞い・断りの符丁・今の `bookmark add`／`delete`。
