# リリースノート 3.20.1（X の画像の説明の送り方・止まった添付を解く口）

2026-10-15。

- **X に画像を付けた投稿が必ず 400 で止まっていたのを直した。** 画像の説明（alt）を `POST /2/media/metadata` に送るとき、X の一次資料（docs.x.com create-media-metadata）では `{"id": …, "metadata": {"alt_text": {"text": …}}}` の形だが、THTH は `alt_text` を `metadata` の外に置いていた。関東の X の 10/14 09:05 の画像つきの投稿が `media_describing_http_400` で止まり、28 時間 inflight に残った。試験用の偽の X も本物と同じく形が違えば 400 を返すようにした（直しを外すと 9 件が赤）。
- **添付の inflight のうち `held`（公開の POST より前で止めた、または公開が 4xx で確かに断られた）は、`thth inflight <account> resolve --not-published --by <名前>` で解けるようにした。** 出ていないことが確定しているため。控えは今までどおり残り、原稿は approved のまま次の run が出し直す（画像は上げ直す）。`held` 以外（結果不明など）は今までどおり断る。X 側に上げた画像は使われずに残る（自動では消さない）。
