# 洗い出し: THTH を商用に展開するために足りないもの（2026-11-03）

masaru 11/03「洗い出して、今回は足らないものや、漏れがないようにしたいし、将来的につかいそうなものは使ってなくても含めて欲しい」。THTH開発 第11 が Fable の相談役に頼み（読むだけ・法令と規約の原文を WebFetch）、その報告をここに置く。媒体の権限と審査は別の書 [`docs/洗い出し_商用_媒体の権限と審査_2026-11-03.md`](洗い出し_商用_媒体の権限と審査_2026-11-03.md)。

**印**: 【読】repo を読んで確かめた／【一次】法令・規約の原文を 11/03 に読んだ／【二次】検索結果や解説（原文未確認）／【推】推測。重さ: **必須**＝売る前／**早め**＝最初の有償利用者の前後 3 か月／**あと**＝規模が出てから。手間は書き手 1 体の日数の見立て【推】。

## 0. 先に結論（前提を疑った所）

1. **「商用」の定義を先に割る。** 売れる形は 3 つ: (a) 道具の利用料（利用者が自分の口座・自分の LLM で使う）、(b) 運用代行（gotoq が投稿・広告を回す）、(c) 横断のデータ（泉）。**(c) は Meta Platform Terms で成り立たない**（`docs/照合_MetaPlatformTerms_泉_2026-09-16_Codex.md`・masaru 09-16「利用者横断の泉はやめる」）【読】。(a) は同じ文書が「全ての有料 SNS ツールを禁止する結論でもない」と明記【読】。以下は (a) を中心に (b) を添える。
2. **利用規約が「無償」を約束している。** `callback/public/terms/index.html`「サービスは無償で、現状のまま提供します」【読】。お金を取る前に全面改訂が必須（準拠法・管轄・消費者契約法上の免責の限度・特商法の表示）。
3. **多人数で動かす作りは「設計はあるが実装していない」。** `docs/設計_v3_提供形態と分離.md` 末尾「…これらを未決のまま一般公開しない」【読】。本番は全口座が同じ OS ユーザー `wt`（`thth/systemd_gen.py:142,190,238,268`）【読】。
4. **X は商用の可否そのものが権限に縛られる。** X Developer Agreement III.L/M「試作・小規模を超えるなら Enterprise plan」【一次 2026-04-27 版】。X を商品に含めるなら Enterprise の見積が先。含めないなら Threads・Bluesky・Mastodon・はてな・FB ページで売る。
5. **価値の証拠がまだ無い。** 設計_効果測定 §7.1「本番で返信を測っている糸は 0 本」「kopicha queue 700 本のうち utm 8・thread 2」【読】。売る前の段に入れる。
