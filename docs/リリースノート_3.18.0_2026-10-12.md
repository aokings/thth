## 足したこと

- **A2 `where --aggregate --keep`**: 語ごとの件数・問いの形の数（「？」で終わる・含む）・lexicon の分類ごとの数を日付つきで残す。
- **A3 `where --also … --keep`**: 語ごとの「取れた・also に合った」の数を日付つきで残す（X と Threads の両方・他の媒体も同じ口）。
- **`thth where-log <project|account> [--since 14d] [--medium M] [--budget N] [--json]`**: 残した数を読む。期間の和の当たり率（両方の数が残っている日だけ）・日ごとの集計。`--budget N --medium M` は N 本を当たり率に比例して割った数（最大剰余・率の出ない語と 0 の語は 0 本・計算だけで、選ぶのは呼ぶ側）。
- **A5 絞り込み**（表示だけ・保存に触らない）: `--ja`（X は語に `lang:ja` を足して読む本数を減らす・既に `lang:` があれば重ねない・`query_sent`。他の媒体はかなのある本文だけ）・`--question`（検索語を外した本文に「？」か「?」）・`--no-replies`（返信の数が無いか 0・Threads は `has_replies` が真なら外す）。絞った数は `dropped`。X の検索に `tweet.fields=public_metrics` を足し、行に `reply_count`（呼び出し数・本数は不変）。
- **A6 JSON の欄の名前**（足すだけ・古い名前は**非推奨で残す**・4.0 で外す候補）: `thth posts --json` の `id` → `post_id` も。`thth thread` の `messages[].message_id` → `post_id` も。`thth who` の `they_replied_to_me` の `message_id` → `post_id` も（`i_replied_to_them` と揃う）。`thth replies --json` の行に返信自身の id の `reply_id`（Threads の `id`・Bluesky/Mastodon の `message_id` を揃える・`unanswered` と同じ名前）。

## 残し方の決まり（`thth/where_keep.py`）

- **既定は残さない**（`--keep` を付けたときだけ）。設計 3.7.0 §C3・3.9.0 §E の「表示だけ」を既定のまま保ち、privacy も「the owner's session may also keep」（任意）と書いているため。`--keep` は `--aggregate` か `--also` と一緒にだけ（rc=2）。
- 行は `where` の**出力の数**から作る（検索結果の行はこの口に渡らない）。許可リストの鍵だけ（書く前と読むときに検査）。本文・post_id・username・author_key・リンク・時刻は残らない。
- **5 未満の数は 0 も含めて欠測**（null）。件数が 5 未満の行は内訳も欠測（`small_sample`・0 件は `zero_or_filtered`／`no_posts_fetched`）。地図の世間の層は 0 件を 0 で残すが、この口は発注と privacy の「numbers below 5 are not kept」どおり 0 も残さない。
- 置き場は観測の地図と同じ `state/_map/<project>/where-<YYYY-MM>.ndjson`（0600・git の外）。同じ日・媒体・種類・語は最後の 1 回で置き換え。保持は地図と同じ日数（書くたびと `map collect` の prune で日単位に削る）。`thth admin map purge`（全体・期間）と退出（`purge_for_leave`）でも消える。account に `project` が無ければ残さず `cannot_say`。
- 候補（`--suggest`）は今までどおり残さない。MCP の `where_to_appear` には足していない（`--keep`・絞り込みとも CLI だけ）。
