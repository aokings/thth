# 手順: はてなの口座・試しのブログ・OAuth アプリの登録（masaru 向け）

2026-10-16・THTH開発 第3。[計画_4.0](計画_4.0_2026-10-15.md) §5 の 1。S2（はてなブログを実機で確かめる段）の前に要るもの。

公式の頁で確かめた所（10/16）と、ログインしないと見えなかった所を分けて書いた。見えなかった所は「画面で見て」と書いてある。

**秘密の値（consumer secret・API キー）は、どこにも貼らないでください**（会話にも、ファイルにも）。THTH に入れるのは S2 で作る `thth principal auth` で、そこで伏せ字で打ち込む形にします。今は登録までで止めてください。

## 1. はてなのアカウント（メイン 1 つ＋レーンごとのサブアカウント）

**10/16 夕に形を変えた**: メインのアカウントを 1 つ作り、レーンごとにサブアカウントを作る（[計画_4.0](計画_4.0_2026-10-15.md) §3.2）。レーンごとのブックマークで「こういうサイトを参照している」を示すため。

1. https://www.hatena.ne.jp/register でメインのアカウント（はてな ID）を作る（accounts.hatena.ne.jp に移る）。入力の欄とメールの確かめは、画面で見て進める（ログイン前の画面は確かめられなかった）。
2. メインでログインしたまま、はてなの「サブアカウント設定ページ」からレーンごとのサブアカウントを作る（規約 第 3 条 1 項「はてなが用意したサブアカウント設定ページから取得できます」）。**作れる数は規約に書かれていないので、設定ページで見てください**。足りなければ、どのレーンを先にするかをここで決める。
3. サブアカウントの はてな ID は、そのレーンのブログの既定の URL と AtomPub の URL に出る。レーンの名前に合わせて決める（例 kopicha 用・関東用）。
4. **守ること**: メインのアカウントを 2 つ作らない（規約 第 6 条 3 項 c）。同じページを 2 つ以上のアカウントでブックマークしない（メインとサブの使い分けも含めて禁止・ブックマークの FAQ）。THTH はこれを機械で断る（S4）。

## 2. ブログ（各サブアカウントに・試しのブログは 1 つ）

公式: https://help.hatenablog.com/entry/register ・ https://help.hatenablog.com/entry/dashboard/myblogs

1. **そのレーンのサブアカウントでログインして**「ブログを作成」の画面で、URL（サブドメインとドメイン）を決める。ドメインは hatenablog.com・hatenablog.jp・hateblo.jp・hatenadiary.com・hatenadiary.jp から選ぶ。**URL はあとで変えられない。**
2. 公開範囲は、試しのブログなら「自分のみ」。あとで変えられる。
3. 「私はロボットではありません」にチェックして「ブログを作成」。
4. 試しのブログは、どれか 1 つのサブアカウント（かメイン）に 1 つ作れば足りる。

**数の上限**: 無料は 1 アカウントに 3 つまで（Pro で 10）。サブアカウントごとに数えるか、メインとサブ合わせて数えるかは確かめていない（画面で見て）。

**記法を Markdown にする**（公式: https://help.hatenablog.com/entry/editing-mode）:
- 基本設定（https://blog.hatena.ne.jp/my/config）の「編集モード」で「Markdownモード」を選ぶ。ブログごとに設定する。
- **作った記事の編集モードはあとで変えられない**ので、記事を書く前に設定する。THTH は公開の前にブログの記法を確かめ、Markdown でなければ断る作りにする（計画 §3.3）。

## 3. OAuth アプリ（consumer）の登録

公式: https://developer.hatena.ne.jp/ja/documents/auth/apis/oauth/consumer ・ スコープ https://developer.hatena.ne.jp/ja/documents/auth/apis/oauth/scopes

1. **メインの**はてな ID でログインしたまま、https://www.hatena.ne.jp/oauth/develop （OAuth 開発者向け設定ページ）を開く。
2. 利用上の注意に同意し、必要事項を書く（欄の名前はログインしないと見えなかったので、画面で見て）。書く値の推し:
   - アプリの名前: `THTH`
   - 説明: `自分の記事をはてなブログとはてなブックマークに出すための道具（個人用）`
   - Web サイトの URL: `https://thth.me/`
   - コールバック URL の欄があれば: `https://thth.me/`（THTH は PIN の方式（`oob`）を使うので、ここには飛ばない）
   - ロゴは無くてよい。アプリの名前・URL・ロゴは、認可の画面に出る。正確に書く（偽りや誤解を招く内容は利用停止になりうる、と公式にある）
3. スコープは **4 つとも**有効にする: `read_public`・`write_public`・`read_private`・`write_private`。
   - はてなブログ AtomPub は、読むのに `read_private`、書くのに `write_private` が要る（公式）。
   - フォトライフとはてなブックマークで要るスコープは、文書に書かれていなかった。S2・S4 で試して確かめるので、今は全部付けておく。
4. 登録はその場で使える（審査なし・無料）。consumer key と consumer secret は同じ設定ページに出る。**写さずに、そのまま置いておいてください**（S2 の `thth principal auth` で伏せ字で入れてもらいます）。

## 4. 終わったら

新しいセッションに「はてなの登録できた」と、メインとサブアカウントの はてな ID（どれがどのレーンか）と、作ったブログの URL（試しのブログ・レーン用）だけ書いてください。サブアカウントを何個まで作れたかも。秘密の値は要りません。開発のセッションがレーンごとの主体の台帳（`principals/hatena-kopicha.json` など）と口座を作り、認可（PIN）の手順を出します。OAuth アプリはメインで 1 つ登録し、サブアカウントでも同じアプリを認可できるかは実機で確かめます。

## 参考: API キー（WSSE）について

はてなブログの詳細設定（https://blog.hatena.ne.jp/my/config/detail）に API キーがあり、OAuth の代わりに WSSE でも AtomPub を使える。ただし公式は「新規アプリケーションでは OAuth を」としているので、THTH は OAuth を使う。API キーは触らなくてよい。
