# THTH 6.0.0（出す日 2026-12-04 の予定・叩き台）

括り（workspace）の版です。1 台の VM の上で、持ち主ごと・プロジェクトごとに置き場を分け、外の AI のサービスから THTH をコネクタとして呼べるようにしました（リモート MCP）。Worker（`callback/`）も変わります。出すときは Worker の deploy が先、VM があと（入口の CLAUDE.md）。

- 日付は予定です。出す日がずれたら、この書の名と上の日付、privacy と規約の発効日（`tools/build_site.py` の `PRIVACY_EFFECTIVE`・`TERMS_EFFECTIVE`）を同じ日に直します。発効日は出す日まで空のまま（どちらかが空なら `release_gate` が止める）。
- 設計の正本: `docs/設計_THTHアカウント（括り）_叩き台_2026-11-26.md`（段 0〜6・§6.1 段 K・§10 作った形）。日ごとの目安: `docs/段取り_段Kを審査の前に_12月8日まで_2026-11-28.md`。

## 括り（段 0〜6）

| 段 | 中身 |
|---|---|
| 0・1 | 置き場の根を「括りの根」と「共通の根」に分けた。命令ごとの札（括りの中で動く・共通・手元）と `thth admin ws`。括りをまたいで読み書きしない柵 |
| 2 | レーンの鍵は 1 つの括りに結び付く（資格のファイルの外の括りの表）。Worker に括りの束、括りを選ぶ login（`thth login --lane`）。答えの括りが違えば `workspace_mismatch` で中身を出さない |
| 3 | 読む命令と書く命令（approve・revoke・withdraw・hold・reply pending／approve／ignore）を、鍵で括りの中に通す（VM の通り道 `ws_command`） |
| 4 | timer の run・collect・map は口座（project）の括りに入る（単位に `THTH_WS_FROM_ACCOUNT=1`）。maintain は全部の括りを回す。口座の名は括りをまたいで 1 つ。新しい括りの秘密は括りの `secrets/` の中だけ |
| 5 | 今の置き場を `ws/main` へ移す台本 `tools/ws_move_main.py`（check・move・back）。記録（承認・止め・送りかけ）の中の絶対の道も書き替え、書き替え損ねが残れば rc 1 で止めて back を案内する。夜の手順は `docs/手順_括りの段5_mainを移す夜_2026-11-27.md`。**移すのは 6.0.0 を出したあとの別の夜**（この版は移さない） |
| 6 | 名指しの印 `ws/.name-required`: 印があれば、VM の上で括りを名指ししない打ち方（`THTH_WS` も鍵も無い）を `workspace_name_required` で断る。timer の単位は main の口座でも `THTH_WS` を付ける。**印はこの版では置かない**（置くのはレーンを鍵に替えたあと・12/5 以降の作業） |

## リモート MCP（段 K）

| 件 | 中身 |
|---|---|
| `POST https://thth.me/mcp` | Streamable HTTP・状態を持たない・POST だけ。道具は通り道の表から作る（`thth/mcp_remote_tools.py` → `callback/src/mcp-tools.js`）と `thth_result` |
| 認可 | thth.me に自前の認可サーバ（`/oauth/*`・PKCE は S256 だけ・client の文書は CIMD）。持ち主が thth.me で sign in して、読むだけか書いてもよいかを選んで許す |
| 書く道具 | 2 段: confirm を省いた 1 段目の中身をこの接続に返したことを Connector に残し、2 段目はその控えが無ければ VM に頼まない |
| 止め方 | `https://thth.me/connectors`・RFC 7009 の取り消し・`thth logout --lane`。止めると VM のレーンの鍵の取り消しも置く |
| 鍵 | コネクタの鍵は thth.me が AES-GCM で預かる。Meta などの token は VM の外に出ない |

## 画面（MCP Apps）を 1 枚

- `thth_board` の結果を、画面に対応する client（initialize で `io.modelcontextprotocol/ui` の `text/html;profile=mcp-app` を言う client）にだけ画面 `ui://thth/queue` で見せる。stdio の MCP（`mcp/server.py`）とリモート（thth.me/mcp）で同じ HTML。
- 言わない client（Claude Code・古い client）には 1 字も変えない: initialize の能力・道具の一覧・`resources/*` が method not found。柵は `tests/test_mcp_ui_fence.py`（stdio）と `callback/test/connector.test.mjs` の screen の 2 本（リモート・4 通りの言い方）。
- リモートでは画面が答えの包み（`{command, rc, output, workspace}`）を開き、pending なら `thth_result` で 6 回まで待つ。下見の道具が無いので「開く」を出さない。部品は `tools/render_mcp_ui.py` が `callback/src/mcp-ui.js` に作る（ずれたら `tests/test_mcp_ui_remote.py` が赤）。
