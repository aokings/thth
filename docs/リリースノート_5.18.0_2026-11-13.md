# THTH 5.18.0（2026-11-13）

STORES の店を読む口を足した版です。BASE（5.15.0）・Shopify（5.17.0）と同じ `thth shop` の家族に、店の種類 `stores` を足しました。設計は [設計_ShopifyとSTORESの口_2026-11-12.md](設計_ShopifyとSTORESの口_2026-11-12.md) の §7（Fable。masaru 11/12 夜の言葉を受けて推しで決めた。朝に覆せる）。

## 足したこと

| 命令 | すること |
|---|---|
| `thth shop add <店> --kind stores --url <店の頁の URL> --project <p> --by <名前>` | STORES の店を台帳に足す。店の URL は STORES の応答に無いので、持ち主が入れる（https・ASCII の見える字だけ） |
| `thth shop token set <店> --by <名前> [--expires YYYY-MM-DD]` | STORES のプライベートアプリのクレデンシャル（1 行）を受ける。隠した入力か `--stdin` だけ。店の応答が通ったときだけ保存する |

`whoami`・`items`・`diff`・`draft`・`remove` は BASE・Shopify と同じ使い方です。

- STORES のプライベートアプリは、固定のクレデンシャルを `Authorization: Bearer` に載せるだけです（OAuth も鍵の取り直しもありません）。
- 読むのは `GET /retail/202211/store` と `GET /retail/202211/items`（引数は limit と offset だけ・100 件ずつ 5 頁まで）。
- 公開は `shown` だけ。予約販売と、販売の期間の前と後の商品は「売っている」に数えません。種類のどれかの在庫が null なら「在庫を数えない」とします。
- 鍵のファイルの形と店の種類が合わなければ、網に出る前に止めます（BASE の店に STORES の鍵を置いた、などの取り違え）。

## 守ること（柵にした）

- 網に出るのは `thth/shop/wire.py` だけ。STORES は定数のホスト・GET・2 つの道だけで、注文・入金の道は道の表にありません。リダイレクトは追いません。
- クレデンシャルは、引数・出力・ログ・記録・写し・下書き・断りに出しません（STORES が断りの本文に鍵を返しても出ません）。
- URL の検査で、行を分ける字（U+2028・U+2029）をまた断るようにしました（5.17.0 の寄せで崩れていた。5.17.0 は出していないので、出た版では崩れていません）。画像や商品頁の URL に `@`（ユーザー名や合言葉の欄）があれば断ります。

## privacy

「Online shops」の節に STORES の段を英日で足しました。「読まない」と書いたのは、道の表で縛ってある注文と入金だけです。STORES の鍵がどこまで読めるかは STORES の側のことなので言い切らず、THTH の事実だけを書いています。施行日は 2026-11-12 のままです。

## 確かめたこと

- 監査: [監査_5.18.0_stores_2026-11-13.md](監査_5.18.0_stores_2026-11-13.md)（Fable・作った者とは別・危ない 0）。直したほうがよい 1〜4 を 50049c5・2548857 で直しました。足した柵は、書き手がわざと壊して赤・戻して緑を見ました。
- BASE と Shopify の試験のファイルは、この版の範囲で 1 字も変わらず緑でした（監査）。
- 本物の STORES では、まだ 1 度も動かしていません。試験は公式の OpenAPI の例に沿った偽の応答です。

## 残したこと

- 値段の比べ方: STORES は種類の中でいちばん高い値（Shopify はいちばん安い値）で比べるので、高い種類が無くなっただけで「値下げ」の下書きができることがあります。下書きを出す前に人が見る前提です。次の版で、種類ごとに比べる形を考えます。
- 販売の前に写しに入った商品は、販売が始まっても違いが出ず、下書きを作れません（出しすぎない側）。次の版で「販売が始まった」を違いに足します。
- 鍵が違うときの HTTP の数・クレデンシャルの期限・種類の無い商品の形・販売の期間の時刻の形は、公式で確かめられず偽で作りました。本物の店で最初に確かめます（`preorder_sales` が false で返る形・形に合わない商品が 1 つあると読み全部が止まること・Python 3.10 での時刻の読みも）。
- 先に masaru の手が要ること: STORES の開発パートナーの登録（氏名・生年月日・住所など）と、その店のスタンダードプランの申込（有料）。試しの環境はありません。

## 出すときに一緒にすること

- 5.17.0（Shopify）をまだ出していないので、5.18.0 を出せば Shopify も一緒に出ます（tag は `v5.18.0` だけでよい。`v5.17.0` を先に出すかは masaru の判断）。
