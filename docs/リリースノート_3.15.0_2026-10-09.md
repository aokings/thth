## 足したこと

- `thth repost|unrepost|like|unlike <account> <post> --by <名前> [--json]`。`<post>` は id か URL。台帳に `production: true` が無ければ断る。
- 対応: Threads は再投稿と取り消しだけ（いいねは「Threads の API にいいねがありません」で断る）。Bluesky は再投稿・いいね・取り消し。Mastodon は再投稿と取り消し（いいねは `write:favourites` が要るので、認可し直すまで `scope_missing`）。X は再投稿と取り消し（いいねは `like.write` が要るので、認可し直すまで `scope_missing`）。
- 記録: `state/<account>/reactions/`（1 件 1 ファイル・0600）。同じ投稿にもう一度頼まれたら、SNS を呼ばずに記録を返す。取り消しは記録の id を使う。相手の本文は持たない。
- ガード: 反応は別の枠 `daily_max_reactions`（既定 50・`thth account set` で変える）。投稿の 1 日の上限と連投の停止には数えない。夜間（quiet_hours）は新しい再投稿にだけ掛ける。
- MCP: `thth_repost`・`thth_like`（取り消しは `undo: true`）。
- SKILL に 1 段落: 反応は会話への参加。持ち主に頼まれたとき、または持ち主の方針の範囲でだけ。いいねで返事の代わりにしない。
