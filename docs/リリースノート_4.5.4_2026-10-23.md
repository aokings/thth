# リリースノート 4.5.4（1 日の本数が減ったら知らせる・日ごとの数に「数えた時刻」）

2026-10-23（メディアハブ本線 第9 の依頼・案は `docs/案_枠ごとの在庫と日次の数えた時刻_2026-10-23.md`）。関東の Threads は 10/21 から朝・夜の枠の原稿が尽き、1 日 4〜5 本が 2 本に減りました。昼・夕の予約は 10/29 まであるので、4.5.2 の `schedule_low`（最後の予約が 48 時間より手前か）は鳴りませんでした。その穴を埋めます。

## 変わったこと

### 1. `thth events` に新しい種類 `schedule_thin`

続いている状態（`ongoing: true`）です。`schedule_low` の隣に並び、同じ約束で届きます（`ref` は `daily`・同じ口座では同じ `event_id`・`--after` でも毎回返る・足りれば消える）。

- **物差し**: 直近 7 日（JST の日で区切る・今日は入れない）に THTH で公開した根の投稿の、1 日あたりの平均。返信は数えません。
- **見る日**: 今日・明日・明後日。今日は「今日もう出た根の投稿＋今日の残りの承認済み予約」、明日・明後日は承認済み予約の本数です。予約も返信（`reply_to`・`reply_to_file` のあるもの）と待ちの行は数えません。下書きも数えません。
- **鳴る条件**: どれかの日が物差しの 6 割を切ったとき。
- **出さない口座**: 物差しが 2 本未満の口座・はてなブログ・直近 7 日に公開していない口座。
- **説明の 1 行**（最初の足りない日）: 「10/24 は 2 本（直近 7 日は 1 日 3.9 本）。空いた時間: 8 時台・19 時台・21 時台」。空いた時間は、直近 7 日に 3 日以上使った時間帯のうち、その日に予約（今日なら公開済みも）が無いものです。
- **付く欄**: `thin_days`（足りない日の全部・`{date, count}`）・`average_daily`（平均・小数 1 桁）・`floor_daily`（これを切ったら鳴る本数）・`window_days`（7）・`free_hours`（最初の足りない日の空いた時間帯・時の数の list）・決め打ちがあれば `stock_daily_min`。
- **決め打ち**: 窓口がわざと本数を減らしたときは `thth account set <口座> stock_daily_min <本数> --by <名前>` で物差しを固定できます。決め打ちがあれば平均を使わず、その本数を切った日で鳴ります（6 割はかけません）。`-` か `0` で外すと平均に戻ります。これは運営者の CLI だけで変えられます（MCP と thth.me からは変えません。安全装置の数値ではないため）。
- 定数は `events_cli` の上のほうにあります（`THIN_WINDOW_DAYS` 7・`THIN_RATIO` 0.6・`THIN_MIN_AVERAGE` 2・`THIN_HOUR_MIN_DAYS` 3・`THIN_LOOKAHEAD_DAYS` 3）。
- 読むだけです。何も書かず、媒体の API も呼びません。

関東に当てると: 10/16〜22 の平均は 3.9 本、6 割は 2.3 本。10/23〜25 の予約は 2・2・3 本なので、10/23 と 10/24 で鳴ります。説明は「10/23 は 2 本（直近 7 日は 1 日 3.9 本）。空いた時間: 8 時台・19 時台・21 時台」です（試験で同じ形を作って確かめた。VM の本物ではまだ動かしていない）。

### 2. `thth measured` の日ごとの数に「いつ数えたか」

- JSON の `account_daily` の各行に `collected_at`（台帳の行にもとからあった、数えた時刻）を出します。古い行で時刻が無いものは、欄ごと出しません（`tags` と同じ扱い）。
- 人向けの表示の日ごとの行に「数えた 10/23 00:03」を添えます。
- 日ごとの数は、閉じた前日を翌日 0 時台の最初の採取で 1 回だけ取ります。関東の 10/22 の 1,153 は 10/23 00:03 に数えた値で、朝に取り直しても同じでした（Meta がそう返している数）。

## 受け取る側（h2d・各窓口）

- 既存の events の読み方のままで届きます。`schedule_low` と同じく、`event_id` で 1 度だけ扱い、消えたら解消として読んでください。
- `schedule_low` と `schedule_thin` は同時に出ることがあります（予約が 48 時間より手前で尽きていて、しかも本数も少ない口座）。

## 前提が変わったら

窓口が本数を週ごとに大きく変える運用になると、7 日の平均は遅れて追いつきます（決め打ちが無いと、減らしたあと 3〜4 日鳴り続ける）。そのときは決め打ちを既定にするか、平均を 3 日に縮めます。代償は、急に減ったのを見逃しやすくなることです。
