## 日誌（`記録/`）

`docs/記録/` は運用日誌。接頭辞は 依頼・検収・発注・回答・レビュー・レビュー依頼・
使用報告・相談・監査・申請・訂正・仮説（露出と反応率を除く）。誰かとのやり取りの
記録であり、読まなくても使い方・設計は分かる。
