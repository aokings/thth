# THTH 5.29.2（2026-11-24）

Instagram のストーリーズを IG の口座から直接出す版です。監査は `docs/監査_5.29.2_2026-11-24.md`（Fable・危ない 0）です。Worker（`callback/`）は変わりません。

| 件 | 中身 |
|---|---|
| `thth send <IG の口座> --story` | 写真 1 枚（`--media`＋`--alt`）をストーリーとして出します。ストーリーかどうかは確認の番号（digest）に入ります。IG でない口座・返信・タイアップなどとの組み合わせは `story_unavailable` で、なぜ・通すには・もっと良く を添えて断ります。11/24 に Threads からの共有（`crossreshare_to_ig`）は媒体が成功と返しても作られないと分かり、IG から直接出す道を足しました |
| 縦横の比 | ストーリーは 9:16（1080×1920）です。そうでない写真は一段目で切れる側を言い、Pillow のある機械では上下（左右）に余白を足した 1080×1920 の絵を送ります。元の写真は変えません |
| 文字のカード | 写真なしの `thth send <IG の口座> --story --text "…"` は、本文を 1080×1920 のカードの絵にして出します（おおむね 350 字まで・`story_card_unavailable`）。Pillow と日本語の書体が要ります（`pip install 'thth[image]'`。書体は `THTH_STORY_FONT` か Noto Sans CJK・IPAex・ヒラギノを探します） |
| 共有の言い方 | Threads のストーリーズ共有で媒体が成功と返しても言い切らず、IG のアプリで確かめる・手で共有できる、と添えます |
| 遠くの道 | thth.me の道と MCP では `--story` を断ります（黙ってフィードに出しません）。通すには Worker の口が要ります |
