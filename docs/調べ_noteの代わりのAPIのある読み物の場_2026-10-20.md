## 4. 推し

### 推し 1: はてなブログを本線に据える（新しく足すものではない）
- 理由: 日本語の一般読者に読まれる・API で公開まで出せる・規約に道具からの投稿を禁じる条がない、の 3 つを満たすのは、調べた中でここだけ。はてブの人気エントリーと検索の流れがあり、調査メモの長文と相性がよい。
- 代償: 読まれるかどうかは、はてブで拾われるか次第。セルクマ以外の作為（複数アカウント・依頼）は禁止（前回の調べ `docs/調べ_はてなブログとはてなブックマーク_2026-10-15.md`）。有料記事は API で作れない。

### 推し 2: X の記事（Articles）の口を足す
- 理由: 日本語の読者が最も多い場の、長文の置き場。API は 2026-06-11 に出たばかりで、下書き作成と公開の 2 本【読】。既存の X の口（認証・承認ページ）をそのまま使える。
- 代償: 書く人が Premium 等の契約者でないと出せない【読】。API の料金と回数の上限は資料に無い【未】。更新・削除の API が無いので、直しは画面で（画面で編集すると一度非公開に戻る【読】）。本文を DraftJS の形に直す手間がある。kopicha の X の口は 10/14 から API の投稿が 403（x_not_permitted）で止まっており、記事の API も同じ扱いになるかは未確認。
- 足す前に確かめること: 出すアカウントが Premium か、記事の API が今の X の鍵で 403 にならないか、を 1 本の下書きで試す。

### 推し 3: Threads の長文添付を、既存の Threads の口に足す
- 理由: 欄を 1 つ足すだけで 1 万字まで出せる。Threads の日本語の読者に流れる。
- 代償: 添付の中身は Google に載らず連合もしない（TechCrunch 2025-09-04 の報道、公式の資料には書いていない）。リンク 5 本まで・投票と同時に使えない・本文にリンクの添付があると添付の中にリンクを置けない【読】。装飾は太字・斜体などだけで、見出しや画像は無い。だから「本体ははてなブログ、Threads には要約と全文の添付」という使い方が向く。

### 前提が変わったら
- **技術記事に限る**なら: Zenn（git に置くだけ・技術者の読者が厚い）と Qiita（REST で出せる）が推し 2・3 より上に来る。ただし Zenn は「機械により自動生成された文章」を禁じているので、THTH は「人が書いた原稿を承認して出す」形を崩さないこと。
- **英語の読者**なら: WordPress.com か Ghost（どちらも API と ActivityPub がある）。Medium と Substack は API で出せない。
- **Bluesky の読者を厚くしたい**なら: Standard.site（Leaflet 等）の記録を書く口。2026-05 から Bluesky のアプリで拡張表示されるが、日本語の読者の数は分からない。
- **note が API を開いたら**（ヘルプに「記事の公開・更新…も広がる予定」とある）: 個人の契約でも使えるかを見て、note を推し 1 に戻す。今は法人の note pro と提携先だけ。
