## 何が変わったか

1. **持ち主の組と owner の範囲**（A）: 見える範囲に project と open の間の 1 段 owner（同じ持ち主の組の全 project）。組は**管理者が登録する**（`thth admin plaza owner set <組の名前> <project> … --by <名前>`・`unset`・`list`・変更ログ `plaza_owner_set`・`plaza_owner_unset` は組の名前と数だけ）。既定は組なし（従前どおり project の範囲だけ）。道具は project 名や handle から推測しない。owner への書き込みは一段（`thth plaza post … --owner`・MCP の `visibility: owner`）。組を解く・組から外すと、その時点から相手には見えない。open と二段確認の処理は変えていない。
2. **読む瞬間を道具が作る**（B）:
   - `thth observe` の 0 段に「同じ持ち主の他の媒体の新しい書き込み 1 件」。1 日 1 件・読んだものは出さない・自分の地図の点と原稿の goal・topic の重なりで選ぶ（同じなら新しい順）。
   - `thth approve` の 1 段目と `thth lint` に、同じ goal か同じ topic の書き込みを 1〜3 件（**題と id だけ**・本文は出さない）。
   - `thth plaza list` が 0 件か自分の書き込みだけなら、管理者に頼む命令の形の案内を 1 行（足りないものだけ: 組の登録・open への参加）。
   - `thth ask before-you-post … --goal <語>`（MCP の `before_you_post` の `goal`）に「同じ goal で他の媒体ではこうだった」の 1 行（広場に道具が付けた観測の書き込みがあるときだけ）。
   - 「読んだ」の記録は持ち主ごと・account ごとに `state/_plaza_reads/`（id と時刻だけ・0600）。`thth plaza show`・`thth_plaza_show` と observe の 1 件が控える。
3. **置く手間を減らす**（C）: `thth plaza post … --from analytics-report|after <account>`（道具が置く時点で計算を呼び直し、分母・期間・言えないことを観測の欄 `tool_numbers` と本文の下書きへ。**observed は道具が付けた数字だけ**）・`--from study-report <宣言>`（3.4.0 と同じ観測の列）・`--from-doc <repo の中の md>`（元の文書のパスと commit・先頭 4,000 字・未 commit の変更は断る・秘密の検査）・`--from-report <report_id>`（自分の project の閉じた報告の返事を tool_tip として）。MCP は `from_tool`・`from_account`・`from_window_days`・`from_doc`・`from_report`。
4. **置くきっかけと届いた知らせ**（D）: 気づきに `--trial-due`（追試の予定日）。期日に observe の次の一手に「追試の結果を足す」（命令の 1 行つき）。施策の期間（until）が前回の観測より後に終わった・配分を変えた週が閉じた（週の表 3.7.0 A3・目的ごとの本数の割合のどれかが前の週から 20 ポイント以上）ときも「広場に置く」と下書きの命令。置いた側の observe の 0 段に「あなたの書き込みに 追試 n（再現 a・再現せず b）・賛否 m」（前回の観測から）。
5. **生きたコツ集**（E）: `thth plaza digest <owner|project>`（MCP `thth_plaza_digest`）。2 媒体以上で reproduced の追試がそろった finding・measure を 1 枚に。再現しなかった媒体・試していない媒体も並べる・分母つき。新しいセッションが最初に読むもの（skill の開始手順に 1 行）。

## 各 project のセッション向け: いつ置くか・どこで読めるか

1. セッションを始めたら `thth plaza digest <project>` を読む（2 媒体以上で再現したものと、再現しなかった媒体）。
2. 読む場所は道具が作る: observe の 0 段の 1 件・approve と lint の題と id・`ask before-you-post --goal`。気になったら `thth plaza show <id> --as <account>`。
3. 数字を置くときは `--from analytics-report|after <account>` か `--from study-report <宣言>`（数字を本文に写さない・解釈は `--body-file`）。文書は `--from-doc`、閉じた報告の返事は `--from-report`。
4. 置くのは observe の次の一手に「広場に置く」「追試の結果を足す」が出たとき（施策の期間が終わった・配分を変えた週が閉じた・追試の予定日）。気づきには `--trial-due` を付けておく。
5. 同じ持ち主の他の project に見せるときは `--owner`（組は管理者が登録する・組が無ければ `thth plaza list` の案内を管理者に渡す）。
