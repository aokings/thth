# 調べ: 3 つの道での命令の意味の差（2026-10-15・main 589b438＝3.22.0）

きっかけは #2477（遠くの道の `thth send` が `--production` を読まずに出た件・3.21.1 で直した）。同じ種類の食い違い（help や名前が言うことと、道ごとの実際が違う）を全部拾った。

**確かめた深さ: 読んで確かめただけ。** 動かしてはいない（本番に触る命令なので）。直す前に、各項目は試験で再現するのがよい。

## 0. 3 つの道の呼び方と入口

| 記号 | 道 | 入口 | 中身 |
|---|---|---|---|
| (a) | 手元・VM の CLI | `thth/cli.py` の各 `cmd_*`（台帳が手元にある） | `core.send_once`・`retract_cli`・`reaction_cli` など |
| (b) | 遠くの道（thth.me の鍵） | `thth/remote.py`（`route` が台帳の有無で振り分け・`remote.py:461`）→ Worker `callback/src/api.js`（中身は見ず運ぶだけ）→ VM `thth/server_writes.py`・`server_reads.py` | 書く命令は `direct_send`・`direct_retract`・`schedule`・`held_send`（`server_writes.py:229-389`） |
| (c) | MCP | `mcp/server.py` | 手元の stdio（`TOOLS`＋`REACTION_TOOLS`）／ログイン済み stdio（`REMOTE_CLI`＝(b) の CLI を呼ぶだけ・`server.py:1001-1018`）／サーバ型（`server_call`→`server_writes.execute` を直接） |

振り分けの規則（`remote.py:461-483`）: 台帳が手元にあれば (a)。台帳が無く `remote.json` があれば (b)。`--remote` で (b) を強制できる。`COMMANDS` にも `UNSUPPORTED` にも無い命令は、台帳が無ければ (a) がそのまま「台帳が無い」と断る。

## 1. 書き込みの命令ごとの比較

凡例: 「乾式」＝出さずに見せるだけ。「確認」＝ digest／`--confirm`。「安全装置」＝ `guard`（止まり・最短間隔・1 日の上限・夜間・burst）。「猶予」＝ `hold_minutes`。

食い違い:

1. **`--confirm` の help（`cli.py:4096-4097`「これが一致しないと送らない」）は (b) で偽。** (b) は `--confirm` を読まず捨てる。`--production --confirm 古い番号` でも出る。
2. **`--production` の help（`cli.py:4094`「台帳に無ければ dry-run のまま」）も (b) では違う。** (b) は dry-run のままにせず `production_disabled` で断る（安全側だが言い方が違う）。
3. **(b) は一部の旗を黙って捨てる。** `fields`（`remote.py:622`）は body・topic・reply_to・media だけ。`--goal`・`--community`・`--found-by`・`--reply-to-root`・`--reply-to-author-key`・`--wait` は parser が受けるのに渡さない。**`--community <id>` を付けても、コミュニティでなく通常のタイムラインに出る。**
4. (b) の乾式は (a) の乾式と別物。(a) は digest・本文・字数・inflight・`publish_held` を見せる。(b) は `draft_put` を呼ぶので、**queue に下書きを 1 本置き、managed repo に commit と push までする**（`server_writes.py:142-198`）。「出さずに lint の結果だけ」（`remote.py:904-905`）と言うが、痕跡が残る。しかも inflight・guard・production・publish_hold は見ないので、乾式で「通りました」でも本番で断られうる。
5. (a) は `--dry-run` と `--production` の同時指定を rc 2 で断る（`cli.py:3266`）。(b) は黙って乾式にする（安全側）。
6. `--json` の形が違う。(a) は `{account, mode, action, post_id, permalink, digest, error}`（`cli.py:3328`）、(b) は `{account, status, post_id, permalink, via}`（`server_writes.py:281`）。設計 3.14.0 の「`--json` の形は同じ」（`設計_3.14.0…md:84`）と合わない。
7. `--media` の意味が違う。(a) は repo 相対のパス、(b) は手元の機械のファイル（`remote.py:560-607`）。send の `--media` の help（`cli.py:4099`）は (a) の意味のまま。schedule の help だけは「遠くの道:」と書き分けてある。

| 1 | `remote.py` に「命令ごとに (b) が読む旗の表」を持たせ、表に無い旗が既定値以外で付いたら `invalid_request: --community は thth.me の道では使えません` で断る（`route` の `run(args, account)` の前・1 か所）。 | 今それらの旗を付けて (b) を叩いている呼び手だけ（そもそも効いていない）。試験は `tests/` の遠くの道の試験に旗の拒否を足す。MCP は旗を渡さないので影響なし。**一番小さく、1〜4 のうち 3・2・4 を同時に止める** |
