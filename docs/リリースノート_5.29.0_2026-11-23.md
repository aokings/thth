# THTH 5.29.0（2026-11-23）

持ち主の依頼で消す版と、Meta の審査に向けて鍵の道を足した版です。監査は `docs/監査_5.29.0_2026-11-23.md`（Fable・2 回・危ない 0）です。

Worker（`callback/`）と privacy の頁は変わりません。Worker の deploy は要りません。

| 件 | 中身 |
|---|---|
| 自分の投稿なら記録が無くても消せる | `thth retract` は、THTH の記録（queue・`sent/`）が無い投稿も、その口座の鍵で 1 件読んで自分の投稿と確かめられれば消します（Threads・X・Mastodon・Bluesky・Facebook・Instagram）。他の人の投稿・読めない投稿は消しません。設計 `docs/設計_持ち主の依頼で消す_2026-11-23.md`（11/23 masaru「アカウントホルダーであれば当然できる依頼を出来ないのはおかしい」） |
| 二段確認 | 記録の無い投稿は、手元・thth.me・MCP のどの道でも二段です。一段目で本文・日時・URL と確認の番号を見せ、番号には媒体から読んだ本文の指紋が入ります。THTH が出した投稿の MCP の削除は今までどおり 1 回です |
| 記録と数え | 消した物は `state/<口座>/retracted_outside/` に残り（`sent/` には入れない）、1 日の削除の上限と連投の止めに数えます。thth.me の `/activity` に「消した」と並びます |
| 反応の取り消し | X・Mastodon の再投稿といいね、Instagram のいいねは、記録が無くても元の投稿の id で取り消せます |
| 古い CLI | 5.28.1 までの CLI を thth.me につないで記録の無い投稿を頼むと、`confirm_required` で断ります（消えていないのに「取り下げました」と言わないため・監査 D1）。thth を新しくしてください |
| Meta の口を thth.me の鍵の道に | `dm event`・`brand`（creators・promote・ads-permissions・content）・`creators search`・`shop`（eligibility・catalogs・products・tags・tag）・`webhook subscribe|status` を `thth login` のあとの鍵の道から打てます。書く口は二段です。MCP には出しません |
| Threads の消えた投稿 | 消えた id を読んだときに「threads_basic が無い」と誤って案内していたのを、「見つかりません」に直しました |
| Meta 申請 | 口の無い 3 つ（pages_utility_messaging・instagram_creator_marketplace_messaging・commerce_manage_accounts）を申請から外しました。審査員の手順（貼り紙 §9）の命令が、どれも鍵の道で打てる形になったことを試験で見ます |

確かめたこと・残した点:

- 11/23 に本物のこぴちゃの Threads で、記録の無い投稿を新しい `thth retract` の二段で消し、媒体に読み直して消えたのを確かめました。
- Threads から IG に共有したストーリーズは、IG の API の一覧（`/stories`）に出ません。THTH からは消せず、IG のアプリで消します。
- 本物の Meta での削除は Threads だけ確かめました。Facebook・Instagram の投稿の削除と、Instagram の `owner` の欄はまだです。
- 監査の軽い 9 件のうち L4・L9 を直し、残りは残しました（監査の書に）。
