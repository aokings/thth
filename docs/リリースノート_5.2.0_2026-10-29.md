# リリースノート 5.2.0（Meta 計画 段 0・段 1）

2026-10-29。「Meta API を THTH で使い倒す計画」（[設計_MetaAPIを使い倒す計画_2026-10-29.md](設計_MetaAPIを使い倒す計画_2026-10-29.md)）の段 0（下ごしらえ）と段 1（FB の仕上げ）です。masaru 10/29「出して進めて」。

## 変わったこと（段 0・1ee5106）

- ページ id が許可されたページに無いとき、断り文に許可されたページの名前と id が並びます。`thth account add --handle` の案内も「ページの透明性」の「ページID」を使うように直しました。
- `.token` の `data_access_expires_at` を `thth maintain`・`thth doctor`・`thth events` が読みます。残り 14 日未満で `data_access_expiring`、過ぎたら `data_access_expired`（maintain の rc 1）。出たら `thth auth <口座> --by <名前>` をやり直します。
- FB の文字数は THTH の線として 5,000 字（公式の上限は未確認）。台帳の `char_limit` で上げられます。
- 添付の表・性質の台帳（`media_traits/facebook.json`）・シナリオ・ダッシュボード・MCP・skill が facebook を知るようになりました。
- 媒体名の表 21 本を 1 か所の宣言（`thth/media_registry.py`）と照らす試験を足しました。
- `thth auth` のログは `$THTH_ROOT/state/_auth/<口座>-<日時>.log` に自動で残ります。

## 変わったこと（段 1・a3f9d3a）

- 写真 2〜10 枚の投稿（未公開で上げてから `/feed` の `attached_media` でまとめる）。
- ページの日次（7 つの指標）を `thth collect` が採り、`thth account` に出します。取れない指標は 0 で埋めず「媒体が返さない」と出します。`thth doctor` に指標ごとの probe の行。
- `thth edit <口座> <post_id>`: THTH で出した投稿の本文を直す（2 段の digest）。
- `thth reply hide|unhide|delete`: コメントを隠す・戻す（1 段）・消す（取り下げと同じ 2 段）。記録は `state/<口座>/moderation-<年月>.ndjson`（本文は残さない）。
- 新しい口はすべて停止の柵（`leave_gate`）の中です。
