# 外部レビュー: THTH 4.0 の計画（2026-10-16 受領）

masaru が外部のレビューから受け取り、THTH開発 第2 に貼ったもの。要点だけをここに置き、計画書 §7 で指摘ごとに「どう直したか」を書く。

## 結論（レビューの言葉の要約）

方向は採用。ただし、今の案のまま 4.0 の中身と公開の条件を決めるのは勧めない。記事を単位に配信と反応を結ぶのは、主に「配信の管理・計測・訂正」を良くする仕組みで、反応ゼロを破るには、誰に・どの発見の経路で・何を届けるかを別に確かめる必要がある。4.0 は「新世代のブログツールの完成」ではなく、まず「記事と配信を安全に結ぶ版」として定義し直す。

先に固める 3 つ: 下書きを作る者が公開までできてしまわないこと、記事ごとの数字が意味を失わないこと、予約や更新の途中の状態を取り違えないこと。
