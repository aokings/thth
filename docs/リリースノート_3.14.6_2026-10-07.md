# リリースノート 3.14.6（台帳がどこまで見ているかの書き方）

2026-10-07。3.14.4・3.14.5 の続き。VM にだけ出す（masaru の了承 10/7）。tag は Meta の判定のあと。

## 直したこと

- `unanswered` の件数の後の一行を、1 つの時刻で言い切らない形にした: 「最後に採ったのは <時刻>（N 時間前）。返信は投稿ごとに 1・6・24・72・168 時間後に採るので、その間に付いた返信と、168 時間を過ぎた投稿への返信は数えていません。今採るなら --refresh」。
- 3.14.4 は「いちばん古い根の最後の取得」を出して 422 時間前、3.14.5 は採集の日数（14 日）の内に絞って 334 時間前と出た。返信の刻みは 168 時間で終わるので、どう絞っても最後の刻みを済ませた根の時刻になり、見落としの目安にならなかった。
- 3.14.5 で足した JSON の `seen_until`・`seen_until_hours` は外した（出して 30 分・読み手なし）。
