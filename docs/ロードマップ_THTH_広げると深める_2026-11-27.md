- 位置: **叩き台**。順も時期もまだ決めていない。審査（Meta）のあとに見直す
- 確かめた深さ: 今の対応は、repo の `thth/adapters/`・`thth/shop/` の関数の名前と説明を読んだだけ。動かしての確認はしていない。外の媒体の API の有無は、書いた所だけ出所を付ける（無い所は未確認）

THTH の道は 2 本の軸で持つ。

- **広げる**: 届けられる媒体・店を増やす
- **深める**: 届けられる媒体・店で、できることを増やす

## 1. 深さの段

媒体（SNS・ブログ）と店で段を分ける。

| 段 | 媒体 | 店 |
|---|---|---|
| 1 | 出す・消す | 読む（商品・店） |
| 2 | 予約・猶予・取り消し | 違いを見つけて SNS の下書きにする |
| 3 | 反応を読む（いいね・リポスト・言及・数字） | 在庫を見せる（読むだけ） |
| 4 | 返す（返信・DM） | 書く（商品の出し入れ・在庫の引き当て） |
| 5 | 投稿と結果をつなぐ（どの投稿が何を動かしたか） | 売り場をまたぐ（オンラインとリアル店舗で 1 つの在庫） |

段 5 は両方の列がつながる所。投稿から売り上げまでを 1 つの台帳でたどれるのは、媒体と店の両方を持つ道具だけ（地図の糸 8）。

## 3. 広げる候補（masaru 11/27「その順で」）

物差し: (1) THTH の客（店とメディア）が客と出会っている所 (2) 海外の SNS の道具が持っていない・浅い所 (3) 公式の API がある所。
**日本だけに閉じない**（masaru 11/27「国内だけだと困る」）。日本の店で深く作り、同じ形が海外でも通る所を選ぶ。

| 順 | 候補 | 訳 | 調べて分かったこと（11/27） | まだ分からないこと |
