# THTH 2.9.0 リリースノート（プロジェクトのセッション向け・管理者向け）

2026-09-20 未明。VM の `thth` は 2.9.0 になっています（`thth board` の 1 行目）。2.8.0 からの変更を、使う側の言葉でまとめます。設計は `docs/設計_2.9.0_管理者の視点_2026-09-19.md`。

## 一言で

**「誰が・いつ・何を変えたか」が台帳に残り、管理者がそれを読める**ようになりました。投稿・承認・採集の使い方は変わりません。

## 各セッションで変わること（1 語だけ増える）

次の 4 つは **`--by <あなたの名前>` が必須**になりました。無いと何も書かずに止まります（黙って `unknown` にはしません）。

```bash
thth account add <account> --by kopicha --media bluesky --project ... --handle ...
thth auth <account> --by kopicha
thth token set <account> --by kopicha --stdin
thth token revoke <account> --by kopicha      # 新設: ローカルの token を消すだけ（媒体側の認可は取り消さない）
```

- `account add --force --by …` で既存台帳を上書きできます。最初に作った人の来歴（`provenance`）は保たれ、変更は差分として記録されます。
- これらの変更は `state/_admin/accounts.ndjson`（追記のみ・600）に 1 行ずつ残ります。token・env・通知先は**有無だけ**が記録され、値は残りません。
- account の追加・production 化・token の設定と失効は、管理者に 1 通通知されます（台帳の `notify_admin_on_change: false` で止められます）。
- 承認（`thth revoke`）はこれまでどおりで、`--by` は要りません。

## 管理者の読み口（masaru 向け）

すべて読み取り専用。秘密の値は出ません。

```bash
thth admin diff --since-last-read --json                 # 前回読んだときからの変化（account の増減・production・token の期限・inflight・timer・版）
thth admin diff --since-last-read --mark-read --by masaru # 読んだ位置を保存（これだけが書く）
thth admin inventory --json                              # 全 account を 1 行ずつ: 台帳・来歴・token のメタ・queue・採集・通知・timer・最後の変更
thth admin account <name> --json                         # 1 account を仔細に（runs・変更ログ・通知の履歴）
thth admin log [--since …] [--account …] [--event …] --json
thth admin tokens --json                                 # 期限順
thth admin timers --json                                 # VM 上で systemd を読み、観測を state/_admin/timers.json に残す
thth admin release --json
```

- `permissions` は `--probe` を付けたときだけ API を叩き、その結果を `state/<account>/doctor.json` に残します。`thth doctor <account>` も同じ記録を残します。付けなければ前回の記録、無ければ `null`。
- **記録が無いものは `null` と理由コード**（`recorded_before_2.9.0`・`permissions_not_recorded`・`systemd_unavailable` など）。`null` は「正常」の証拠ではありません。
- 存在しない account 名は `ledger_missing`（終了コード 2）。壊れた台帳は `ledger: "unreadable"` の行として残ります。

MCP からは `thth_admin_inventory`・`thth_admin_account`・`thth_admin_log`・`thth_admin_tokens`・`thth_admin_release`・`thth_admin_diff` の 6 道具。`serve-reports` の資格情報に `"scope": "admin"` を持つ token を `THTH_REPORT_CREDENTIALS`／`THTH_REPORT_TOKEN` で渡した MCP だけに現れます。HTTP／MCP からは `--probe` も `--mark-read` もできません（timer は VM で記録した最後の観測を読むだけ）。skill は `skills/thth-admin/SKILL.md`。

## しないこと

- 管理者にも承認・投稿・台帳の書き換え・token の入れ替えは開けません。
- 削除コマンドはありません。
