# THTH 5.13.0（2026-11-08）

5.12.6 からの 2026-11-05〜11-08 の開発をまとめて出す版。中心は 3 つある。Meta の全部盛りの申請に向けた口（計画 Meta 全部盛り M1〜M6）、広告の資格と遠くの道、Google 広告と Search Console を読む口。運用で見つかった不具合の直しも入る。新しい断りの符丁 113 個の `since` は、この版で "5.13.0" にそろえた（5.12.6 のときに出したものは無く、全部この版で初めて出る）。

## 新しい口

- **Google 広告を読む**（`thth gads auth|accounts|keywords|report`・e8c7a1c・f325bc3）: キーワードプランナーと同じ「キーワードの案と月平均の検索数・競合・入札の幅」と、キャンペーンの成績を読む。読むだけで、作る・止める・支払う口は無い。認可は端末のアプリの形（PKCE・ループバック）、スコープは `adwords`、鍵は `~/.config/thth/google-ads-token.json`（600）。Cloud の段は Basic。
- **Search Console を読む**（`thth gsc auth|sites|query|compare|inspect`・6289975）: プロパティの一覧、語・頁ごとのクリック・表示・CTR・順位、前の期間との差、URL 検査。スコープは `webmasters.readonly`、鍵は `~/.config/thth/google-gsc-token.json`（600）。認可の流れは gads と共通の `thth/google_oauth.py` にまとめた。
- **Meta の全部盛り**（M1〜M6）:
  - 招待の道を Facebook・Instagram・広告に広げた（VM・Worker・文書。24e268a・24bbc94・72a533b）。
  - Webhook で Threads の通知と IG の comments・story_insights を受ける（ccee7cd・8d6905d・ac3446c）。
  - 読むだけの最小の口（M3・2ba0e2b）と書く最小の口（M4・7f6cfb8）。権限の不使用の見張り（M5・a3fd619）、審査の台本の生成と提出の前の点検（`thth admin appreview script|check`・ac34b9c）。
  - 遠くの道（`--remote`）に Meta の口（doctor・dm・live・page cta・like・edit・reply hide・44c1091）。
- **広告の資格**（44d78c7〜e2f9cf2）: 行の口座を台帳の置き場で見分け、`adaccounts/` も同じ門で検査する。遠くの道の広告の口（VM の server_ads と `thth ads --remote`）、`thth ads leave`。
- **Threads を広告の出し先に**（3ea8999）: `thth ads boost --platforms instagram,threads`・creative の `threads_user_id`。広告の鍵に `threads_business_basic`。**本番の kopicha-ads の鍵は再認可するまで Threads に出せない。**
- **Threads の返信の管理**（de8ebe0）: `reply hide|unhide` と承認待ちの返信の `pending|approve|ignore`。
- **X の自分の投稿の非公開の数**（c8511ae）: 30 日以内はリンクのクリック・プロフィールのクリック・engagements・動画の再生も記録する。
- **未承認で時刻が近い原稿**（8396e94）: `thth schedule --unapproved [--window]`・board の口座ごとの `unapproved_soon`・`thth withdraw [--undo]`。
- **observe の返信の窓**（9175f59）: 取り直しの窓（live_posts・follow_last_at/hours）。

## 直したこと

- **`thth account set … --dry-run` が台帳を書いていた**（c6823f8・運用 #7177）: `--dry-run` は migrate だけの口で、set・resume・leave は読まずに書いていた（11/06 asmon-kanto-fb・11/08 kopicha-ig の scheduled）。migrate 以外で付いたら、何も書かずに断る。
- **収集の取り残し**（bea3fff・運用 11/07）: push に失敗して取り消した分が、次の回が同じファイルを触らないと commit されなかった。未 commit の実測・返信・受信箱の `.ndjson` を次の回の commit に入れる。VM の asmon に残る 2 本は、この版の最初の収集で送られる見込み。
- **`report file --body-file` が読めないファイルを空と言っていた**（880868f・運用 #7040）: `report_file_unreadable` で断る。
- **置き場の中で移した原稿を古いパスで approve した**（4b5f613・運用 #7040）: 移った先を添えて断る。
- 審査の台本の小さな直し 5 点（b56b4d8）、where --project の IG のタグの枠（758499a）、試験の偶然の赤（cd259d5）。
