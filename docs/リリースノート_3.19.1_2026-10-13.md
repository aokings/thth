# リリースノート 3.19.1（失敗の原因の符丁を runs に・OpenSSL 4）

2026-10-13。

- `thth community search`・`thth trends`・`thth counts` が失敗したとき、runs の error に原因の**静的な符丁だけ**を足す（例 `community_search_failed: x_read_failed TimeoutError`・`trends_failed: x_trends_http_403 x_unknown_refusal`）。語・detail の文は残さない。10/13 朝、両レーンのコミュニティ検索の最後の 1 回が `community_search_failed` だけで、応答が読めなかった（予算の台帳は uncertain）原因を追えなかったため。
- 応答が読めなかったときの文面に例外の種類（TimeoutError・URLError 等）を入れる。
- relay の openssl の検査が OpenSSL 3 だけを受けていた。Homebrew が 10/11 に既定を 4 に上げ、手元で鍵の作成と署名が `openssl_3_required` で落ちていた。4 も受ける（実際の RSA 署名の試験まで通る）。断りの符丁の名前は変えない。
- README・llms.txt に headlesson の THTH の試用記録への 1 行（記録は 3.15.0 の導入と `--help` まで・同じ運営）。
