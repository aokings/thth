# リリースノート 3.21.0（取れるものは取る・使える口を広げる・VM の send にも安全装置）

2026-10-15。masaru「THTH の仕様は Meta の目を必要以上に恐れて絞りがち。取れるものはとる、やれることはやれるように」を受けた点検（[点検_絞りすぎ_2026-10-15](点検_絞りすぎ_2026-10-15.md)）の実装。媒体の原文が禁じていない絞りを外した。**他人の投稿を保存しない**決まりは変えていない（表示と受け渡しだけを広げた）。

## 本文を全文で

- **検索の本文を全文に**（`topics --search`・`where`）。画面・`--json`（`posts[].text`）・thth.me の道・MCP のどれも全文。それまでは画面に先頭 60 字、`--json` には本文なし（THTH 自身の設計で、Meta の権限の許可された用途は「公開の投稿とその会話の木を見せる」）。`where` の `preview`（1 行の抜粋）は残した。
- `thread`（120 字）・`mentions`（60 字）・`unanswered`・`list show` の画面も全文（改行を保つ）。毎朝の一枚と observe は題の 1 行のまま。
- **X の長文（280 字超）の全文を取る**: 読み取りで `note_tweet` を頼み、ある行はそちらを本文に使う。費用は変わらない（件数の課金）。
- 招待の口座（thth.me の道）の `topics --search` で各行の本文が空だった不具合も直った（キョンシーラボ #2410）。
- プライバシーの文の「first 60 characters」を「full text」に。

## 取れる欄を取る

- Threads の返信・会話の欄に `media_type`・`is_quote_post`・`quoted_post`・`is_reply_owned_by_me`・`hide_status`・`is_verified`。`thread` の画面に `[IMAGE・引用・HIDDEN・認証]` の印。返信の台帳には写さない。
- Threads の検索に `--since`・`--until`・`--media text|image|video`（`where`・`topics --search`。thth.me の道でも渡る。Threads 以外は断る。`--keep` とは一緒に使えない）。
- `where --aggregate` に仮名の上位（`author_keys`）と `you_and_them`。
- Threads の口座の指標に `follower_demographics`（100 フォロワー以上の口座だけ）。
- `location search` に緯度・経度・郵便番号。自分の投稿の欄（`media_type`・引用・再投稿・リンク）。

## 使える口を広げる（thth.me の鍵・MCP）

- thth.me の道で `thread`・`where`・`who` が動く（それまで `thread` は `remote_unsupported`）。サーバ型の MCP にも同じ 3 つ。長い答えは thth.me の 1 件の上限の内に後ろから落とし、続きの `--since` を言う。
- thth.me の道で `mentions --since`・`topics --recent`・`schedule <口座>` の一覧・`send`／`schedule` の添付（`--media`・`--alt`）。
- 手元の MCP に `thth_trends`・`thth_counts`・`thth_community_search`（X の読み取り・月の予算の中）と `thth_doctor`。

## VM の `thth send` にも安全装置

- 最短間隔・1 日の公開の上限・急な連投が、thth.me の道だけでなく VM で打つ `thth send` の本番にも掛かる（music-research-threads が 5 分に 7 件出た #2426）。返信に間隔は掛けない。timer の予約の原稿には掛けない（数には入る）。止めの印を置けない置き場（モード 775 など）では、口座を止めずにその 1 件を断る。`account status` に掛かる所を書いた。当たりそうな口座は [知らせ_thth_sendに安全装置](知らせ_thth_sendに安全装置_2026-10-15.md)。

## 小さな直し

- `thth account set <口座> handle <名前> --by …`: 認可の前（トークンが無いとき）だけ handle を直せる。Threads の `account add` で `--handle` を省くと既定と直し方を出す。認可が handle の食い違いで断るときは直す命令を出す。
- `thth account add` に `--dry-run` を付けたら何も書かずに断る（それまで黙って台帳を書いていた）。
- X の自分の投稿の数字で、X の画面で消した投稿が「応答に無かった」と 10 分ごとに出るとき、`thth retract … --already-gone` での記録の付け方を同じ行に書く。

## 出し方

Worker（thth.me のプライバシーの文と入口）を先に deploy し、VM はあと。thth.me の新しい口は VM の release で動く（古い VM に新しい CLI から頼むと `unsupported_operation`）。
