## 裁定・仕様の変わり目（3 つ）

1. **layer 00 の MPEG header は「壊れた MP3」でなく AAC。** `test_v213_mastodon_mp3.py` の 1 例の期待を `invalid_attachment_structure` から `unsupported_attachment: aac_adts` へ変えた。
2. **Worker の包括 catch は 503 を配らない。** R2・alarm・SQLite の合成故障 7 件が `503 media_unavailable` から `500 media_internal` になる。VM 側の分類（4xx＝確定・5xx＝不明）は変わらないので運用の挙動は同じ。
3. **`geo` は `geometry` 様の key にも当たる。** 除外を置かず fail closed。良性の key を断るのは作者が直せるが、見落とした key は漏れた座標になる。

## 判断を書き残すもの

- **FLAC の走査は短くしない。** 先頭 N frame で止めれば残りが未検査になり、未検査の byte こそ隠し payload の置き場になる。上限（1 GB）は Worker が raw source upload に既にかけている天井の再利用で、新しい方針の数字は発明していない。
- **`PYTHON_FOR_TESTS` は文書化した（橋渡しは直さない）。** 橋渡しの script は repo の `thth` を import するだけで pytest を持つ module に触らないので、この machine の `/usr/bin/python3`（3.9.6）で 90 件全通過する。`callback/README.md` に節を足した。
- **ASF の GUID は byte literal で書く。** `bytes.fromhex('…')` だと .py に 32 字の hex 連続が出て repo の秘密 grep に当たる。正規表現は緩めない。
