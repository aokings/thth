# THTH 3.0.0 リリースノート（招待の道が 1 本通った記録）

2026-09-23。masaru の裁定「3.0.0 を今の状態で tag して締める」（同日朝）。**新機能は無い。** 中身は 2.14.1 と同じで、変わったのは版と文書だけ。設計は `docs/設計_3.0_クローズドのサーバ型_2026-09-20.md`、材料は `docs/残件_3.0_2026-09-20.md`。

## 一言で

**招待された人が、VM もアプリも git も持たずに、自分の LLM セッションから投稿を出せる。** 2.11.0（認可）→ 2.12.0（書く口と退出）→ 2.13.0（画像と動画）→ 2.14.0（X の adapter）→ 2.14.1（umask・lint の理由・承認ページの Origin）で積んだものが、09-23 の朝に 1 人分の通しで確かめられたので、ここで 3.0 と呼ぶ。

## 09-23 に実測したこと（kopicha・Mastodon・サーバ型）

1. `thth auth` の URL を本人が開いて承認を押す（別のアカウントで開くと `mastodon_identity_mismatch` で何も保存されないことも確かめた）。
2. 本人のセッションに資格情報 1 つを置き、MCP の `thth_draft_put` で原稿を置く。
3. 承認ページ（thth.me）を本人が開いて承認を押す。実ブラウザで `forbidden` になった P1（`Referrer-Policy: no-referrer` で Origin が落ちる）は 2.14.1 で直した。
4. `thth-approval-worker` が拾って投稿する。https://mastodon.social/@kopi_chaba/117316855393426037 が出た。
5. 予約投稿（`publish_at` 09:00 JST）を本人が承認した。timer が拾って出すのは tag の時点ではまだ先で、結果は 3.1.0 のノートに書く。
