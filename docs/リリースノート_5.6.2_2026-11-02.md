# THTH 5.6.2（2026-11-02・下書き）

11/01〜02 に本番の口座 kopicha-ads で試しの広告を 1 本、作る→始める→延ばす→読む→止めるまで通した。そこで分かったことを直し、足りなかった道具を足した。

## 直したこと

- **`thth ads stop` が「止まったと確かめられません」で終わっていた。** pause の直後、Meta は広告を `IN_PROCESS`（処理中）で返す。1 分後には全部 PAUSED だった。`IN_PROCESS` だけが残っているときは 5・10・15 秒待って読み直すようにした（量の制限では待たない）。待ち切っても残る物は、読み直した木で上のキャンペーンか広告セットが止まっていると読めたときだけ「止まった」と言う。ACTIVE のままの物があれば、今までどおり待たずに「確かめられない」と言う。
  - あわせて、THTH の止めの印を pause の直後（待つ前）に書くようにした。待ちの途中で落ちても印は残る。
- **`stop` の `spend_cap` を下げる所が断られていた。** 使った額（608 円）ちょうどへ下げると Meta が code 100 で断った。下げる先を使った額＋余白（使った額の 10%・切り上げ）にした。余白は 1 操作の上限（`lifetime_budget_max`）を越えない（口座の通算の支出が大きくなっても余白が膨らまない）。断られたときは、理由の符丁・code・subcode・Meta の文（鍵を伏せたもの。鍵らしい値が残りそうなら文ごと残さない）を記録に残す。
  - `spend_cap` の変更は Meta の決まりで 1 日 10 回まで。同じ日に何度も stop を打つと、spend_cap の段だけ断られる（止めることは止める）。
  - Meta の公式の文書には、下げられる下限の決まりが書かれていない。「使った額の 10% より上」は第三者の説明で、本番では未確認。
- **`thth ads extend` の 2 段目に「hub の番号 None」と出ていた。** 記録には入っていた。表示にも出すようにした。
- **`thth ads insights --preset last_7d` で今日の分が出なかった。** Meta の last_7d などは昨日までで、今日を含まない。今日を含まない期間で行が無いときは、そう一言添えるようにした。

## 足したこと

- **`thth ads watch <名前> <campaign_id>`**: キャンペーンの成績（全期間・今日を含む）を決まった間隔で読み、`--stop-at-spend <額>` か `--stop-at-impressions <数>` に達したら `stop` と同じ止め方で止める（承認なし）。指定が無ければ「配信が始まったら知らせて終わる」。`--until` は既定 6 時間後・48 時間まで（無限に回らない）。読めなかった回を数えて出す。`--json` も。
  - 閾値を付けたときに、読めない回（読みの失敗や、額・表示数が数として読めない回）が 3 回続いたら、止め損なわないよう止める（結果 `stopped_on_unreadable`）。閾値が無ければ止めずに終わる（rc 3）。終わったら記録に 1 行残す。
- **配信の診断**: `thth ads show` と `doctor` が、ACTIVE の広告セットごとに残りの予算・Meta が返す配信の問題・届く人数の見込みを読み、「予算が丸ごと残ったまま表示 0 が 2 時間以上」を警告する（読むだけ）。
- **`thth ads insights`** に `--preset maximum`（全期間）と `--since YYYY-MM-DD [--until YYYY-MM-DD]` を足した。
- **`thth ads boost --objective reach`**（なるべく多くの人に表示）。Meta の目的の対応表どおり、OUTCOME_AWARENESS と REACH で作り、`destination_type` は送らない。traffic と reach は本番で未確認（engagement だけ確かめてある）。
- **`thth ads resume <名前>`（止めた印を外す・masaru 11/02 の承認による例外）**: 2 段。1 段目は今の印（理由・時刻・止めた人）と口座の木・ACTIVE の物を出して digest を返すだけ。2 段目は `--confirm <digest> --approval <hub の番号>` が必須で、印か木が変わっていれば断る。外すのは THTH の印だけで、広告は PAUSED のまま（始めるのは activate）。`spend_cap`・上限・旗には触らない。理由が owner 以外の印（非常の止め・読めない印）と、最後の stop が確かめられていないときは断る。MCP には出さない。外したことは変更ログ（admin_log の `adaccount_resumed`）にも残る。止めた直後は Meta の状態が「処理中」から PAUSED に変わる途中で digest が変わることがあるので、そのときは少し待って 1 段目から。
