件名: はてなブログ AtomPub・フォトライフ・はてなブックマークの API を、自分の事業の記事の配信に使うことについて

はてな ご担当者様

個人で SNS 投稿の道具（THTH・オープンソースのコマンドラインの道具）を作り、自分の事業の発信に使っている青木と申します。はてなブログとはてなブックマークの API を使う前に、Developer Center 利用規約の扱いを確かめたく、ご連絡しました。

■ やりたいこと
1. 自分のはてなアカウント 1 つで、はてなブログを複数（事業ごとに 1 つ、2〜4 個の予定）持ち、それぞれの事業の記事を AtomPub で公開・更新・削除する。画像はフォトライフの API で上げる。
2. 記事は自分で書き、公開の前に毎回自分で承認する。自動で記事を作って出すことはしない。公開の頻度は各ブログで 1 日に数本までに抑える。
3. 自分の記事のうち、選んだものだけを、自分のアカウントではてなブックマークに登録する（全記事に機械的に付けることはしない。サブアカウントは使わない）。
4. 記事ごとに、はてなブックマークの件数とコメントを API で読み、自分の記事の反応として記録する。表示のアルゴリズムを調べたり、その結果を公開したりはしない。

事業の内容: （masaru が記入。例: 喫茶の店の発信・教育の情報の発信 など）

■ 伺いたいこと
1. Developer Center 利用規約 第 4 条第 1 項第 14 号の「宣伝や商用を目的とした内容」に、上の使い方は当たりますか。当たる場合、特別な許諾をいただく手続きはありますか。
2. はてなブログの個人営利利用ガイドラインの範囲で、1 つのアカウントで複数の事業のブログを持ち、それぞれで宣伝を含む記事を出すことは認められますか。法人向けのプランが要る場合は、その条件を教えてください。
3. 上の 3 のように、自分の記事を選んで自分のアカウントでブックマークすることは、スパムに関するヘルプの「自身が運営するウェブサイトを自身のアカウントでブックマークする行為」として問題ない範囲でしょうか。避けるべき頻度や形があれば教えてください。

お手数をおかけしますが、よろしくお願いいたします。

（お名前）
