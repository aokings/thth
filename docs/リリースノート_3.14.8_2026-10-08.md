# リリースノート 3.14.8（毎朝の一枚の「返信の取得」の行）

2026-10-08。VM にだけ出す（masaru「毎朝の一枚の取得の古さの行も直して」10/7）。tag は Meta の判定のあと。

## 直したこと

- `observe`／`morning` の返信の段の「返信の取得」の 1 行を、いちばん新しい取得から始め、刻みでしか採らないことを書く形にした:
  「返信の取得: いちばん新しい取得は N h 前・返信が 1 件以上取れたのは M h 前。返信は投稿ごとに 1・6・24・72・168 時間後に採るので、その間に付いた返信と 168 時間を過ぎた投稿への返信は数えていません（今採るなら thth unanswered <account> --refresh…）」
- 3.14.7 までは先頭に「いちばん古い根投稿の最後の取得」を出していた。最後の刻みを済ませた根の時刻なので数百時間前になり、取りこぼしの目安にならなかった（`unanswered` の 1 行を 3.14.6 で直したのと同じ）。
- JSON の欄（`collection_stale_*`・`last_fetch_*`）は変えない。
