## VM で打ってみる 1 行

```bash
thth morning kopicha --json --no-mark
```

**まず `--no-mark`** で（栞を進めずに）形を見てください。よければ `--no-mark` を外した 1 回が「今日の 1 枚」で、栞が `morning` の名前で進みます。

監視語を入れる前は 3 段（世間）が `no_watch_words` で飛びます。入れるなら:

```bash
thth admin watch set kopicha-threads コーヒー 自家焙煎 --by masaru
thth admin watch show kopicha-threads
```

人向けの画面で見るなら `--json` を外してください（6 段が縦に並びます）。
