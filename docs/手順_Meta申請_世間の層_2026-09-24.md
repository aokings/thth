## 4. 録画の台本

**実行はまだしない（台本だけ）。** 撮るのは masaru。VM に `ssh wt` で入った端末と、ブラウザ 1 枚。字幕は英語で 1 行ずつ（話す要点も同じ）。

前提:

- project は `masaru`（account 名 `masaru-threads` を渡してもその project に解決される・`thth/map_store.py` の `project_accounts()`）。**masaru の台帳の実名で置き換える**（`masaru` という project 名は未確認）。
- `thth map collect` は project の中の Threads・Bluesky・Mastodon の account をそれぞれ 1 本使って検索する（`thth/map_world.py` の `WORLD_MEDIA`）。project に Bluesky・Mastodon の account があれば、その行も画面に出る。
- 語は話題の語で、検索に 5 件以上・5 人以上が出そうなもの（5 未満は欠測 `small_sample` になる。それも見せてよい）。例: コーヒー・ラーメン・読書。
- `THTH_MAP_WORLD=1` は**その 1 行の頭にだけ付ける**（`export` しない）。`thth map show` も同じ変数が無いと世間の層を見せない（`thth/map_view.py` の `_world_cell()`）。
- 同じ日に撮り直すと 2 回目の collect は `already_collected_today` になる。撮り直す前に `thth admin map purge masaru --world-only --by masaru` で行だけ消す。
- 置き場は `/srv/thth/state/_map/masaru/`（`$THTH_ROOT/state/_map/<project>/`・ファイルは 0600）。

### 場面 0: privacy の該当の段落

- 画面: ブラウザで `https://thth.me/privacy/` の「Observation map (daily keyword aggregates)」と、保持の一覧の「Observation map daily figures」の行。
- 字幕: "Our privacy policy states what the daily keyword aggregates contain, what is never stored, and that they are kept for at most 180 days."

### 場面 1: 既定では何も叩かない

```sh
thth map collect masaru
```

- 画面: 「世間の層は無効です（world_layer_disabled）。媒体は叩いていません」。
- 字幕: "The daily collection is off by default: without the operator's switch, THTH makes no search calls."

### 場面 2: 人が話題の語を登録する

```sh
thth admin map node add masaru コーヒー --by masaru
thth admin map node add masaru ラーメン --by masaru
thth admin map node add masaru 読書 --by masaru
thth admin map node add masaru @someone --by masaru
```

- 画面: 3 語は「点「…」を足しました（n/20）」。4 行目は断り `node_handle`。
- 字幕 1: "A person registers topic keywords for the project, at most 20; THTH never picks keywords from other people's posts."
- 字幕 2: "Handles, URLs and personal names are refused, so the map cannot be used to watch a specific person."

### 場面 3: 1 回だけ集める

```sh
THTH_MAP_WORLD=1 thth map collect masaru
```

- 画面: 「masaru <日付>: 検索 3 回・行 n 行」（Threads だけの project の場合。媒体が増えれば語の数×媒体の数）と、媒体ごとの `collected`。
- 字幕: "For this one run the switch is on: THTH calls threads_keyword_search once per keyword, counts the results in memory, and discards them."

### 場面 4: 集計だけが見える

```sh
THTH_MAP_WORLD=1 thth map show masaru
```

- 画面: 語ごとの「世間 threads（…）: 件数 n/25  異なり …  上位 3 の占有率 …  直近 …」と共起の行。本文・投稿者名・リンクが無いこと。欠測の語は「理由 small_sample」。
- 字幕 1: "The map shows only counts, distinct authors, the top-3 share and a rounded age of the latest post — no post text, usernames or links."
- 字幕 2: "Any number below 5 is stored as missing, so no row points to a single post or person."

### 場面 5: 保存ファイルの中身

```sh
ls -l /srv/thth/state/_map/masaru/
cat /srv/thth/state/_map/masaru/*.ndjson
python3 -c 'import json,sys; print(sorted({k for f in sys.argv[1:] for l in open(f) for k in json.loads(l)}))' /srv/thth/state/_map/masaru/*.ndjson
```

- 画面: `map.json` と `<YYYY-MM>.ndjson` が `-rw-------`。1 行ずつ `date`・`medium`・`node`・`n`・`requested`・`distinct`・`with_username`・`top3_share`・`latest_age_bucket`・`search_type`・`window_hours`・`reason`（共起の行は `edge`・`co`・`denominator`）。3 行目の出力が項目の一覧で、`text`・`post_id`・`username`・`author_key`・`permalink`・`timestamp` が無い（`thth/map_world.py` の `NODE_KEYS`・`EDGE_KEYS`）。
- 字幕 1: "The stored file is owner-only, outside Git, and holds one line per keyword, platform and day."
- 字幕 2: "These are all the fields it contains: aggregates and the fixed search settings, nothing from individual posts."

### 場面 6: 消す

```sh
thth admin map purge masaru --by masaru
```

- 画面: 「masaru: 地図を丸ごと消しました（ファイル n）」。
- 字幕: "On a deletion request, or when the project leaves, the operator deletes the whole map with one command; the deletion is logged without the keywords."

### 場面 7: 消えたことを見せる

```sh
ls /srv/thth/state/_map/
THTH_MAP_WORLD=1 thth map show masaru
thth map collect masaru
```

- 画面: 一覧に `masaru` が無い。`map show` は「点がありません」。最後の collect は `world_layer_disabled`。
- 字幕: "The map and its figures are gone, and the daily collection stays off until review is complete."
