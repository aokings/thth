## 1. 今の公開の約束（事実・11/12 に読んだ）

- サイト全体: 「thth.me の頁は第三者の script・フォント・分析を読み込まない」（`tools/build_site.py` 674 行・日本語 1056 行）

## 2. 決まり

1. **thth.me は今のまま。** 庭は thth.me と別の登録ドメイン（か持ち主のドメイン）で配る。だから今の privacy は直さずに Meta の束を出せる。庭の章は、庭を出す版で privacy と terms に書く（無い機能を公開の約束に書かない）
2. **庭の来訪者をどこまで知るかは持ち主が選ぶ。**
   - 段 0（既定）: どこにも人が残らない数。数えるのは回数・utm の類の印・店の商品頁へ進んだ数だけ。再訪も人数も数えない。`fbclid`・`gclid` など人に結びつく ID は保存しない。参照元の URL は全文を残さない。案の振り分けは要求ごとの乱数（同じ人が別の案を見ることは受け入れる）。基盤（Cloudflare）の記録は保証しない、を今の privacy と同じ言い方で
   - 段 1: 庭の中だけの印（同じ人に同じ案・再来の数え）。期間に上限を持ち、privacy に数で書き、コードと突き合わせる柵を付ける
   - 段 2: 持ち主が選んだ外の会社（Meta・Google など）へ送る計測
3. **段 1 と段 2 は、THTH が出す決まった差し込み口・同意の帯・「この頁の計測について」の知らせで行う。** 持ち主は計測の ID を入れるだけで、送り先は THTH が許した先に限る。持ち主の任意の script は止めたまま（庭は静的・`script-src` を閉じる monban §14.3 の理由は崩さない）。同意の帯は段 1 にも段 2 にも出せ、出すかは持ち主が来訪者の地域で選ぶ
4. **役割**: 来訪者の扱いを決めて責任を持つのは持ち主、THTH は持ち主の指示で預かる者（日本法の委託元と委託先・EU の管理者と処理者に当たる見込み【知識・未確認】）。来た人の求めの窓口は持ち主で、THTH は手伝う。漏れたら THTH が持ち主にすぐ知らせ、当局と本人への知らせを雛形つきで手伝う
5. **THTH が守る線**: 売らない。THTH 自身の広告の的にしない。庭どうしを結ばない。**SNS の API で読んだ人のデータ（DM・リード・言及・コメントの相手）と庭の来訪者を結ばない**。`thth leave` と消す求めで持ち主の分を消す。置く期間の上限を数で書く
6. **THTH が自分の目的で持つのは**、宣伝枠の押された数（人を見分けない・庭の側の外向きのリンクで数える。thth.me の着地では数えない）と、運営に要る最小（濫用止め・流量・障害・請求）だけ
7. **無料版の庭には「THTH の案内」と表示した静的な枠を 1 つ、決まった場所に置く。** 有料版では消える。publish の見本に枠込みの姿を見せる（持ち主が承認する姿と出る姿を同じに）。案の入れ替えは枠の中だけ。外の広告の網（AdSense など）は入れない。terms に、無料版の対価であること・枠から THTH へ人が流れること・参照元として店の URL が渡ることを書く

## 3. 覚悟の中身（引き受けること）

- 庭を出す版で privacy と terms に庭の章を書き、「売らない・広告の的にしない」を明文にする
- EU の人を相手にする持ち主との処理の契約（GDPR 28 条）を terms に入れる形【知識・未確認】
- 漏れたときに一番困るデータを預かる。置く期間・消す手順・漏れたときの知らせを最初から作る
- 段 2 の当事者は持ち主（Meta の Business Tools Terms など）。terms に「段 2 は持ち主が媒体の決まりを守る」と書き、差し込み口の説明に前向きな断りの型で添える
- 宣伝枠は「THTH の案内」と出す（持ち主が勧めているように見えると、ステマの決まりに触れうる【知識・未確認】）

## 4. 作るまでに確かめる（原文）

- 個情委のガイドラインと Q&A（個人関連情報・タグの設置・委託・漏えいの報告）。段 2 のピクセルは「THTH のサーバーを来訪者のデータが通らない」前提の整理で、サーバーから Meta へ送る形（web の Conversions API）を足すと前提が変わる
- 総務省の外部送信規律の解説（場を貸す THTH が対象に当たるか・自分のサイト内の印の除外）
- EDPB の ePrivacy 5 条 3 項の指針と CNIL の計測の免除（A/B を含むか）
- GDPR 3 条 2 項・28 条・33 条、CJEU の Fashion ID 判決
- Meta の Platform Terms（禁じられた使い方・他者の代わりに処理する者）と Business Tools Terms
- 消費者庁のステマの運用基準
