# リリースノート 3.5.0（観測の地図）— 下書き

2026-09-23。設計は `docs/設計_3.5.0_観測の地図_2026-09-23.md`（§1〜§8）、規約の照合は `docs/照合_観測の地図_集計の定点観測_2026-09-23.md`（§6 の 11 項目を条件として採った）。

版は据え置き（3.4.0 のまま）。**世間の層は実装したが既定で無効**です。有効にする条件は、Meta への説明の申請（Dashboard の説明を運営者の VM・検索・集計の保存という実態に合わせる）と `https://thth.me/privacy/` の書き直しのあと。外部の LLM に渡る口（MCP・observe）に世間の層を出すなら Service Provider の条件も満たしてから（照合 §6-8・§6-9）。

## 何が変わったか

話題を選ぶ材料が、自分の数字・広場・世間とばらばらでした。3.5.0 の約束は 1 行です。**話題を「点」、話題どうしのつながりを「線」として、同じ点に自分の投稿・広場の書き込み・（有効にしたときだけ）世間の日ごとの集計を重ねる。本文・投稿 ID・投稿者は 1 つも残さない。**

1. **点と線は人が足す**: `thth admin map node add|remove <project> <語> --by <名前>`・`thth admin map edge add|remove <project> <狭い語> <広い語> --by <名前>`。点は project あたり 20 まで。@名前・16 桁の仮名（author_key の形）・URL・個人名らしき語（「〇〇さん」「〇〇先生」・「名 姓」のラテン文字）・秘密らしき値は点にできません。包含の線は両端が既にある点で、輪は作りません。点を消すと、掛かる線とその点の集計の行も消えます。道具が他人の投稿から語を拾って点を増やすことはしません。
2. **自分の層**: その話題（topic）で出した投稿の数（分母は同じ窓の投稿の数）と、views・likes・replies の中央値と n。計算は既存の口のまま（`measured` と `analytics-report --by topic` と同じ 24 時間の刻み・根の投稿・min_n 5）。account をまたいで足しません。
3. **広場の層**: title か scope（媒体・企画の範囲）に点の語を含む書き込みを、その点に結びます（**語の一致**。広場の記録に欄は足していないので、3.4.0 で置いた書き込みもそのまま結べる）。施策・気づき・問いの数、施策の判定、追試の数（再現した・しなかった・試していないを同じ重さで）。読めるのは広場の見える範囲のまま（自分の持ち主と、参加していれば open の写し）。
4. **見方**: `thth map show <project> [--node <語>] [--since 30d] [--json]`・MCP `thth_map_show`（読むだけ・サーバ型は credential の project だけ）。`thth observe` の 0 段に「地図: 伸びた点・強まった線」（候補の列挙だけ）。
5. **世間の層と共起（既定で無効）**: `thth map collect <project>`（timer 用）。管理者が `THTH_MAP_WORLD=1` を入れたときだけ、点ごとに媒体の検索を 1 日 1 回だけ呼び、件数／要求数・異なり投稿者・上位 3 の占有率・直近の投稿までの時間の丸めと、点 A の検索結果に点 B の語が含まれる本数（共起）を日ごとに残します。
   - 保存行は許可リストの項目だけ（本文・post_id・username・author_key・permalink・時刻の生値は入らない・項目が多い行は書かない）。
   - 小標本（n・distinct・co が 5 未満）は null と `small_sample`。0 件は `zero_or_filtered`。異なり投稿者が 5 未満の点からは線を作りません。
   - 問い方は固定して行に記録（RECENT・25 件・直近 24 時間）。共起は同じ検索結果から数えて捨てる（追加の検索なし）。
   - Threads はアダプタの API（keyword_search）だけ。Mastodon の件数は「そのサーバで検索に出た数」と表示。X は叩きません。
   - 世間の層は project の中だけ（広場の open・他の持ち主・横断の集計には出さない）。
6. **保持と削除**: 置き場は VM の私有 `state/_map/<project>/`（0600・git の外）。保持は日単位で既定 180 日（`thth admin map retention <project> <日数> --by`・1〜180）。`map collect` は世間の層が無効でも毎回古い行を削ります。削除の依頼は `thth admin map purge <project> --by`（既定は地図を丸ごと・`--from`／`--to` は期間の行だけ・`--world-only` は行だけ）。変更ログは `map_node_added`・`map_node_removed`・`map_edge_added`・`map_edge_removed`・`map_retention_set`・`map_purged`（presence-only・点の語は残さない）。
7. **退出**: `thth account leave` で、その project の最後の account なら地図を丸ごと、他の account が残るならその媒体の集計の行を消します（止める前に消す。地図の置き場が壊れていれば何も止めずに `map_cleanup_incomplete`）。

## 各 project のセッション向け

1. 話題を選ぶ前に `thth map show <project>`（MCP `thth_map_show`）を読む。
2. 点が足りない・つながりが見えたら、候補を人に出す（足すのは管理者の `thth admin map node|edge add`）。
3. 施策や気づきを広場に置くときは、title か `--scope` に点の語を入れると、その点に結ばれる。
