# THTH 2.13.0 リリースノート（配布前・masaru と各セッション向け）

2026-09-21。**未配布。** 全 10 段が main に揃い、独立監査と直しを終えた状態。配布は masaru の一言で（release → tag → PyPI・registry・VM・thth.me の Worker と R2）。設計は `docs/設計_2.13.0_画像と動画の投稿_2026-09-20.md`、原稿の書き方と媒体ごとの表は `docs/原稿_添付_2.13.md`。

## 一言で

**投稿できるものは全部 thth で投稿できる。** 画像・動画・音声・投票・引用・リンクカード・GIF・字幕・親 thumbnail・spoiler・返信制御・ghost まで、3 媒体（Mastodon・Bluesky・Threads）の公式 API が 1 投稿に付けられるものを、**承認の対象**として扱う。添付も digest に入り（元 sha・公開 sha・alt・順序・型付きの値）、承認ページは画像そのものを見せる。人が見ていないものは承認させない。

## 原稿に書けるもの

```yaml
media:
  - file: docs/photos/tea.jpg
    alt: 白いカップに注いだ緑茶        # alt 必須（2000 byte まで）
attachments:
  - type: poll                        # poll / quote / link / text / gif（媒体ごとに可否）
    options: ["温かい", "冷たい"]
post_options:
  visibility: public                  # 媒体ごとの許可表・全値が承認に入る
captions:
  - {media_index: 1, file: docs/ja.vtt, lang: ja}
```

- **画像**（JPEG/PNG/WebP）: 位置情報・XMP・IPTC・MakerNote・サムネイル・コメントを落とし、Orientation と ICC と描画構造は保持。**縮小も再圧縮もしない**。上限を超えたら lint で断る。
- **動画**（MP4/MOV）と **音声**（WAV/FLAC/MP3/Ogg/WebM/BMFF 音声）: bytes は変えない。位置情報の box や検査できない拡張は理由付きで断る（`location_metadata_present`／`location_metadata_unverifiable`）。埋め込みの cover 画像は必ず検査する。生の AAC（ADTS）と ASF は理由付きで未対応（m4a に入れ直す）。
- **媒体ごとに何が出せるか**は道具が持っている: `thth doctor`、`handoff-report --since-last-read` の `tool.capabilities`、`docs/原稿_添付_2.13.md` の表。値は `supported`／`unsupported: 理由`／`unverified: 理由`／`ascii_only: 理由`／`body_only`。**「未確認」を「非対応」とは書かない**。

## 各セッションが変わること

- **添付を付ける前に `tool.capabilities` を読む。** lint の理由 `unsupported_attachment: <媒体>/<key>` の key は表と一致する。
- **Mastodon は再認可が要る**（`write:media`）。`thth auth <account> --by <名前>` を一度。旧 token は新しい認可が成功するまで触らない。
- Threads の装飾（`text_with_styling_info`）と spoiler の offset は **本文が ASCII のときだけ**指定できる（単位が公式に無く、実機で確定するまで）。
- `analytics-report --compare-previous --by attachment_kind` で添付の種類ごとに比べられる（1 本が複数の種類に数えられる・記録の無い投稿は `unknown`）。
- 招待者（サーバ型）は MCP の `thth_media_upload_url` → curl で PUT → `thth_media_complete` → `thth_draft_put` の `media: [{media_id, alt}]`。URL は応答に一度だけ出る。サーバが読み戻して sha を照合し、sanitize してから repo に置く。

## 承認ページ

画像は preview capability（`/m/<cap>`・承認 session と同じ寿命）で表示。動画・音声・字幕は「動画 01:12 · sha 先頭 12 · alt」の文字。型付き添付と公開設定は JSON。**画像が 1 枚でも表示できない状態なら承認フォームを出さない。** 承認・失効・受領で preview は失効する。

## 管理者に増えたもの

- `thth admin media gc <account> --by`: 参照されない公開ファイルを 1 日後に commit で消す。
- `thth admin media cleanup-retry <account> --by`: R2 の掃除の再開（削除だけ・再投稿しない）。doctor に未確認・失敗の件数が出る。
- Worker: R2 bucket `thth-media`・DO `MediaObject`・rate limit 4 本（`/m/*` 120/IP、control 600/IP、upload 240/subject・120/IP）。掃除は 60 秒間隔・最大 10 回、結果不明は保持し時間で確定しない。bucket の lifecycle（`media/`・24h）は独立の backstop。
