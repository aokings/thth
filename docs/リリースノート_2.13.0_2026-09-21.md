実装・検証中です。版の配布、タグ作成、本番の媒体投稿はまだ行っていません。

- 添付の原稿、公開用 bytes の準備、alt・元/公開 SHA を含む承認を追加。第2段は Mastodon の対応画像・MP4/MOV の upload と処理待ちまで。第3段では Bluesky 画像の同一bytes upload・CID照合・images/gallery投稿を追加。他の媒体機能、ブラウザーの添付承認、残る型付き API 機能は後段です。

- MP4/MOV の未知 box／uuid と、非0 payload を持つ free/skip を拒否。repo_dir の祖先 symlink、添付型の重複、字幕言語の表示理由を明確化しました。

instance の実上限、実 upload の処理待ち、媒体での実表示は配布担当による本番実測が必要です。詳細は [添付原稿の手順](原稿_添付_2.13.md) を参照してください。

Mastodon は添付のために `write:media` を含む再認可が必要です。旧client/tokenを保全するscope世代別保存を追加し、旧pendingはやり直しを求めます。
