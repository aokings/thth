# 旧導入ガイドからの案内

現行の手順は [導入: 承認を押すだけ](導入_承認を押すだけ.md) に統合しました。招待した利用者は masaru が始めた URL を開いて承認し、アプリ・サーバ・台帳は masaru が管理します。利用者ごとに VM や Meta アプリを作る手順は案内しません。

Threads/Mastodon/X の主経路は `thth auth <account> --by masaru`。X は認可のみです。Bluesky は App Password の `token set --stdin` で、OAuth ではありません。手入力の逃げ道、媒体差、管理者設定、観測の限界は統一ガイドを参照してください。

このファイル名は古いリンクのために残しています。[2.10 当時の旧文書](https://github.com/aokings/thth/blob/61f3c51541f1027904b35c996c880c0c53628dd0/docs/導入_Mastodon_2026-09-13.md) は当時の設計・測定の記録で、現在の導入手順ではありません。
