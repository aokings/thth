## 0. 先に結論

- ショップが要るのは `instagram_shopping_tag_products`（投稿に商品タグ）の録画のため。`catalog_management`・`commerce_account_read_settings` も、ショップとカタログがあると録画が中身のあるものになる。
- **関門が 1 つある: こぴちゃは自分では物を売っていない。** こぴちゃはほかの店の商品を集めて比べる観測のサイト（kopicha の CLAUDE.md「国内ロースター・生豆卸・茶葉ECの公開情報を機械収集する定点観測基盤」）。Meta のショップは、自分の事業が自分のドメインで売っている物を載せる形で、ほかの店の商品を並べる形は通らない見込み【推】。
- だから最初に決めることは **「どの事業の、何を、どのサイトで売るか」**。ここが決まれば、masaru の手は 1〜2 時間、そのあと Meta の承認待ちが数日〜1 週間ほど【推】。

## 1. Meta が求めること（原文）

- コマース機能の利用要件【一次・Meta ビジネスヘルプ 2347002662267537・11/08 に原文を見た】: Meta のポリシーに準拠していること／**該当するビジネスとドメインを表していること**／所在地がコマース機能を利用できる国であること／信頼性を示すこと／正確な情報を提供すること。
- 日本はショップの国に入っている（オープンベータ・商品のタグ付けを含む）【一次・ヘルプ 549256849084694・精査の書 §1.11】。
- 2025-09 から、支払いは Meta の中でなく自社のサイトで行う形になった【一次・要約・精査の書 §2】。つまり**商品を実際に買えるサイト**が要る。
- 商品タグの API の前提: 承認済みの Instagram ショップと、商品の入ったカタログ。アプリの利用者が、ショップを持つビジネスの管理者であること【一次・product-tagging・精査の書 §1.11】。
- デジタルの品は載せられない: コマースポリシー「ダウンロード可能なデジタルコンテンツ、デジタルサブスクリプション…の売買」を禁じる【一次・facebook.com/policies_center/commerce・11/08】。こぴちゃのデータや THTH の利用権は品にできない。

## 2. 選べる道

| 道 | 中身 | 得 | 失 |
|---|---|---|---|
| A こぴちゃが自分の物を売る | こぴちゃの名前で物の品（例: 豆のセット・グッズ）を、こぴちゃのドメインの通販（BASE・Shopify など）で売る | masaru 11/05「ショップはコピチャで作る」の線のまま。通販の事業の芽になる | 仕入れ・発送・特定商取引法の表示・決済の口座が要る。提出の 2〜3 週間に間に合うかは masaru の段取り次第 |
| B もう売っている事業で作る | masaru の事業のうち、既に物を自分のサイトで売っているものがあれば、そこでショップを作る | 前提が一番早くそろう | どの事業が当たるか、私には分からない（masaru に聞く） |
| C 商品タグだけ 2 回目へ | `instagram_shopping_tag_products` だけ、ショップができてから出す（1 権限・判定は 1 週間前後） | 提出の律速が外れ、ほかは 2 週間ほどで出せる | masaru の「後から出すなら一緒」に反する。ただ、ショップの準備は Meta の外の都合で、THTH の作りの都合ではない |

推し: **B があれば B。無ければ A を始めつつ、ショップの承認が提出の日に間に合わない場合だけ C にする。**
- 前提: 提出の日を、ほかの準備（WhatsApp・口づくり 4〜5 日）が揃う日に置く。
- 前提が変わったとき: A の準備が数日で揃うなら、C は要らない。代償は、ショップの承認待ちの分だけ提出が遅れること（1 週間前後【推】）。

## 3. 手順（売る事業と品が決まったあと・masaru の手）

1. 売る物のサイト（自社のドメイン）で、その品を買える状態にする。
2. Meta のビジネス（THTH のアプリを結んでいるビジネスと同じものが楽）で、Commerce Manager を開き、ショップを作る。
3. カタログに品を 1 つ以上入れる（サイトの商品の URL・値段・在庫）。
4. ドメインの確認（ビジネス設定の「ドメイン」）をする。
5. Instagram の口座（録画に使うもの）をショップに結び、Instagram ショッピングの審査を出す。
6. 承認が来たら THTH開発に一言。THTH開発が `shopping_product_tag_eligibility` を引いて、録画に使えるかを確かめる。

手の時間は 1〜2 時間。待ちは商品の審査と IG ショップの承認で、数日〜1 週間ほど【推】。1〜5 の各画面は、そのとき内蔵ブラウザで一緒に見て案内する（1 行ずつ出さず、詰まったら現物を見る）。

## 4. 確かめていないこと

- ほかの店の商品を並べる形（アフィリエイト）が、本当にショップの規約で断られるか。コマースポリシーの原文はまだ読んでいない。
- 承認待ちの日数（Meta は日数を約束していない）。
