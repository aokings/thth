## 2. 貼る文

### 2.1 共通の前置き（各権限の説明の先頭）

欄: App Review の各権限の用途説明の欄（09-15 に前置き＋本文を貼った欄・**欄名は未確認**）。

> THTH is an open-source tool for drafting, approving and publishing social media posts. The operator (gotoq) runs it on an operator-managed server for invited users and for the operator's own accounts; invited users do not run their own server or Meta app. Every post, reply and deletion goes through human approval before it is sent. The data THTH keeps (drafts, post history, metrics, replies and mentions) is stored on the operator's server in the account's own records; for invited users it is deleted when the account leaves. Privacy policy: https://thth.me/privacy/

訳: THTH は SNS の投稿を下書き・承認・公開するためのオープンソースの道具です。運営者（gotoq）が、招待した利用者と運営者自身のアカウントのために、運営者の管理するサーバで動かしています。招待された利用者は自分のサーバや Meta アプリを持ちません。投稿・返信・削除はすべて、送る前に人の承認を通ります。THTH が保存するデータ（下書き・投稿の履歴・実測・返信・言及）は運営者のサーバのそのアカウントの記録に置き、招待された利用者の分は退出で削除します。プライバシーポリシー: https://thth.me/privacy/

### 2.2 `threads_keyword_search`

欄: 同上（前置きの後に続ける）。

> The user's session can search public posts by keyword before choosing a topic: on request (`thth topics <account> --search <word>`), or in the observation summary, which uses up to 5 keywords the operator sets for the account. THTH shows aggregates (number of posts, distinct authors, share of the most frequent authors, latest post time) and, for individual posts, the author, a link and the first 60 characters, so the user can decide where to join the conversation; any reply goes through human approval. Results are shown for that request only: post text and authors are never saved. When the user works through their own AI assistant, the results shown are passed to that assistant.

訳: 利用者のセッションは、話題を選ぶ前に公開投稿を語で検索できます。求めたとき（`thth topics <account> --search <語>`）か、観測の一枚（運営者がアカウントに設定した最大 5 語を使う）のときです。THTH は集計（件数・投稿者の異なり数・多く投稿している人の割合・最新の投稿時刻）と、個々の投稿の投稿者・リンク・先頭 60 字を出し、利用者がどこで会話に加わるかを決められるようにします。返信は人の承認を通ります。結果はその求めに対してだけ表示し、本文と投稿者は保存しません。利用者が自分の AI アシスタントを通して使うときは、表示した結果がそのアシスタントに渡ります。

### 2.3 `threads_manage_mentions`

欄: 同上。

> THTH's scheduled collection retrieves public mentions of the user's own Threads account and saves them (username, text, time, link) in that account's records on the operator's server, so the user can see who is talking to them and decide whether to answer. `thth mentions <account>` shows them on request. Any reply goes through the same human approval as a post; THTH never replies automatically. For invited users the records are deleted when the account leaves.

訳: THTH の定期の採集は、利用者本人の Threads アカウントへの公開の言及を取得し、運営者のサーバのそのアカウントの記録に保存します（ユーザー名・本文・時刻・リンク）。誰が話しかけているかを見て、答えるかを決めるためです。`thth mentions <account>` は求められたときに表示します。返信は投稿と同じ人の承認を通り、THTH が自動で返信することはありません。招待された利用者の記録は退出で削除します。

### 2.4 `threads_profile_discovery`

欄: 同上。

> When someone replies to or mentions the user, the user can look up that person's public profile (`thth profile <account> <username>`) to understand who is taking part in the conversation. Only the public fields Meta returns are requested. The result is shown for that request and is not saved.

訳: 誰かが返信や言及をしてきたとき、利用者はその人の公開プロフィールを参照し（`thth profile <account> <username>`）、会話に加わっているのがどんな人かを把握できます。要求するのは Meta が返す公開の項目だけです。結果はその求めに対して表示し、保存しません。

### 2.5 `threads_location_tagging`

欄: 同上。本文は 09-15 の文とほぼ同じ（前置きの差し替えが主）。

> A draft may name a place. `thth location search <account> <name>` looks up candidate places and their location_id; the user writes the chosen place into the draft, the approval step shows the place name before publishing, and only an approved post carries the tag. THTH never infers a location. Search results are shown for that request and are not saved.

訳: 下書きに場所を書けます。`thth location search <account> <名前>` が候補と location_id を探し、利用者が選んだ場所を下書きに書きます。承認の段で公開前に場所名を表示し、承認された投稿にだけ場所が付きます。THTH は場所を推測しません。検索結果はその求めに対して表示し、保存しません。

データの取り扱いの質問に答えるための事実（どれも privacy に書いたもの）:

- Platform Data を扱う先: 運営者の VM（事業者名は masaru が記入）、Cloudflare（thth.me の Worker・Durable Objects・R2。認可コード・承認ページの本文・添付・削除依頼）。
