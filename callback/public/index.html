THTH

THTH は、AI と一緒に SNS の投稿を作成・管理するためのコマンドラインツールです。Threads、Bluesky、Mastodon に対応しています。

自分の Git リポジトリで運用する場合は、いつものエディタや AI エージェントで下書きを作ります。内容を確認して承認すると、予約した時刻に投稿されます。原稿も投稿後の記録も、そのリポジトリで管理できます。

pip install thth

自分のリポジトリから投稿する

下書きは Markdown ファイルに保存します。本文のほか、投稿先のアカウントや予約時刻、トピックなどを指定できます。

まず、投稿する内容を確認します。

thth approve docs/sns/queue/2026-09-14-oolong.md

本文と投稿先などが表示されます。この段階では、まだ承認されません。

内容がよければ、表示された確認コードと承認者の名前を付けて、もう一度実行します。

thth approve docs/sns/queue/2026-09-14-oolong.md --confirm <確認コード> --by gotoq

承認した下書きは、タイマーを設定しておけば自動で投稿されます。承認後に本文や投稿先、予約時刻などを変更した場合は、あらためて承認が必要です。

投稿したあとの管理も

投稿が完了すると、原稿に投稿 ID が記録されます。返信や閲覧数も取得して、同じリポジトリに保存できます。投稿の履歴をたどったり、次の原稿を考えるときの資料として使えます。

招待された方へ

招待された利用者は、招待リンクを開いて Threads を認可します。続けて pip install thth、thth login を実行し、ブラウザでこのデバイスを許可します。利用者が VM や Meta アプリを用意する必要はありません。

以後は thth send、thth posts、thth replies、thth measured、thth retract で自分のアカウントを動かします。最短間隔、1 日の上限、急な連投で止めるガードはオーナーが決めます。AI アシスタントが変えられるのは、厳しくする向きだけです。アクティビティで、オーナーが確認・停止・キーの発行を行えます。

AI エージェントから使う

MCP サーバーと Claude Code 用のスキルを同梱しています。コマンドラインから直接使うほか、AI エージェントとやり取りしながら下書きや投稿の記録を扱えます。

運営者の使い方

Mastodon の auth は expires_in または refresh_token を返す非標準実装に未対応です。手動 token set も期限・更新情報を受け取らず期限なしとして保存するため、その回避策にはなりません。

運営者（gotoq）がサーバー側で thth auth <account> --by gotoq を開始し、利用者が URL を開いて承認します。Threads・対応 Mastodon・X の共通入口です。X は投稿・削除・自分の最近の投稿の読み取りに対応し、利用は運営者設定の範囲内です。返信とインサイトの取得には対応していません。Bluesky は App Password の stdin 入力です。

English

THTH is a command-line tool for drafting and publishing social media posts with AI. It supports Threads, Bluesky, and Mastodon.

For an operator-managed queue, review and approve a draft, then let the timer publish it. Drafts, published post IDs, replies, and view counts are stored in that repository.

An invited person opens an invitation link, authorizes Threads, installs thth, and runs thth login to allow their device in the browser. They then use thth send, posts, replies, measured, and retract for their own account. The owner sets safety limits; an AI assistant can only tighten them. The owner uses Activity to review, stop, and issue keys. The operator (gotoq) runs the server. X can publish, delete, and read the account's recent posts within the operator's configured scope; it does not collect replies or metrics.
