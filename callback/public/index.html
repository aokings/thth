THTH

AI が書いた下書きを、人が読んで承認してから投稿する道具です。Threads・Bluesky・Mastodon に対応しています。画面はなく、コマンドと MCP で動きます。

しくみ

  1. エージェントが下書きを書きます。置き場はあなたの repo の中です。
  2. あなたが本文を読んで承認します。承認していない本文は出ません。
  3. THTH が投稿し、投稿の ID・返信・閲覧数を同じ repo に記録します。

約束

  • 承認していない本文は 1 文字も出ません。承認は、本文を見せてから、その本文の指紋を渡す 2 段です。承認のあとに本文が変わると、出しません。
  • 出したものは全部あなたの git に残ります。THTH のサーバはありません。
  • 何も外に送りません。共有の機能は既定で切れていて、入れても送り先はまだありません。
  • DM は読みません。定型文で自動返信もしません。返信の下書きも同じ承認を通ります。
  • 数字には件数と期間が付きます。分からないことは分からないと言います。
  • 1 回の実行で出すのは 1 件。静かな時間帯と最短間隔を守ります。

入れ方

pip install thth
thth account add my-threads --media threads --project my-project
thth doctor my-threads

Threads は自分の Meta アプリで使います。初回の設定は 導入の手引きを見てください。Bluesky と Mastodon は Bluesky・Mastodon の手引きがあります。

MCP サーバと Claude Code 用の skill は pip install thth に同梱です。MCP registry では io.github.aokings/thth です。

English

THTH publishes an LLM-drafted post only after a person has read and approved it. It works with Threads, Bluesky and Mastodon, has no dashboard, and runs from the command line or as an MCP server. Everything it posts and collects is recorded in your own git repository. Nothing leaves your machine. See README.en.md.
